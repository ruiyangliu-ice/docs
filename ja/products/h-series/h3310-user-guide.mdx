## 用語と動作原理

### 基本用語

| 用語 | 説明 |
| --- | --- |
| ベースライン | 2つのステレオ撮像ユニットの光学中心間の水平方向距離。 |
| 深度 | 各ピクセルからカメラまでの距離を表すデータ。 |
| FOV | 水平・垂直・対角方向の角度を含む視野角。 |
| IRカメラ | 近赤外線撮像に使用するカメラ。 |
| RGBカメラ | カラー撮像用カメラ。 |
| 深度カメラ | 深度データを出力する撮像システム。通常、投光、撮像、深度処理ユニットで構成されます。 |
| SoC | 画像処理、深度計算、アプリケーションアルゴリズムに使用するシステムオンチップ。 |

## 製品概要

H3310は重量400 gの産業用RGB-D構造化光カメラです。複合ロボットまたは小型ロボットアームに搭載できます。300～600 mmの動作距離で高精度な深度・RGBデータを出力し、アプリケーションアルゴリズム用の演算プラットフォームを統合しています。

<Frame>
  ![H3310カメラ](/images/products/h-series-h3310-user-guide-h3310-camera.avif)
</Frame>

### 特長

- アプリケーションアルゴリズム向けの6.0 TOPS演算プラットフォームを統合。
- 深度、RGB、振幅画像を出力。
- ロボットアームおよびモバイルロボット統合向けのオープンインターフェース。

## 使用と安全

<Warning>
  カメラを分解、改造、修理しないでください。レンズを遮ったり、落下、強い機械的応力、直射日光にさらしたりしないでください。外観上の損傷があるカメラには通電しないでください。
</Warning>

## よくある質問

<AccordionGroup>
  <Accordion title="上位アプリケーションでカメラを開けない">
    ホストのファイアウォールが接続を遮断していないことを確認してから、カメラの電源とネットワーク接続を確認してください。
  </Accordion>

  <Accordion title="デバイス一覧に複数のIPアドレスが表示される">
    LAN上に検出可能な複数デバイスが存在する場合があります。対象カメラに割り当てられたIPアドレスを選択してください。
  </Accordion>

  <Accordion title="データストリームが不安定">
    ギガビットEthernetケーブルを使用してください。100 Mbpsネットワークでは、初期ストリームが不安定になることがあります。
  </Accordion>

  <Accordion title="インストール後にソフトウェアを実行できない">
    ソフトウェアがアクセス制限されたディレクトリにインストールされている場合は、ファイルおよびプログラム実行の権限を確認してください。
  </Accordion>
</AccordionGroup>
