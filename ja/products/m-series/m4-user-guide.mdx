## 製品概要

本書は、浙江迈尔微视科技有限公司が開発した M4 カメラについて、仕様、特長、操作手順を説明します。

M4 製品ファミリーには M4 Lite と M4 が含まれます。これらの ToF 製品は、ギガビット Ethernet 通信インターフェースと 24VDC 電源を使用します。

### 製品の特長

- 外部 CPU を必要とせず動作する 1Tops の演算能力を内蔵
- RGB-D に対応
- スタンドアロンでの障害物回避、ドッキング、自己位置推定、軟包装荷物の把持、保管ロケーション検出、体積計測
- ギガビット Ethernet ポート

### 使用条件

**使用時は以下の要件を守ってください。**

- 製品のラベルを剥がさないでください。
- 製品を分解しないでください。分解すると損傷するおそれがあります。
- 強磁場内で製品を使用しないでください。
- 100 kLux を超える強い日光下で製品を使用しないでください。
- 筐体の清掃には、精製水またはアルコールでわずかに湿らせた柔らかい糸くずの出ない布を使用してください。
- 元の梱包材を保管し、輸送時には可能な限り使用してください。

## 動作原理と仕様

### ToF 測距原理

M4 カメラは Time of Flight（ToF）方式で測距します。光を照射してから物体で反射した光を受信するまでの時間を測定し、物体とカメラ間の距離を計算します。

M4 カメラは深度を直接取得し、最小限の演算リソースで高品質な深度情報を提供して、高フレームレートで深度シーンを構築します。LiDAR と同様に、ToF カメラはパルス ToF（P\_ToF）または連続波変調 ToF（CW\_ToF）を使用できます。P\_ToF は通常不可視の光パルスを照射し、その往復時間から距離を計算します。CW\_ToF は変調された連続光を照射し、照射光と戻り光の位相差から距離を計算します。

## 精度と複数カメラの導入

### 4.1 正確さ

キャリブレーションでは、センサー測定値と実測値の間にある固定オフセットを、両者の対応付けにより除去します。M4 カメラをキャリブレーションするには、レールに取り付けて白い壁に向けます。各ピクセルの測定値をカメラと対応する壁面領域との距離に対応付け、その対応関係で測定値を補正します（図 4.1）。

<Frame>
  ![M4 キャリブレーションのセットアップ](/images/products/m-series-m4-user-guide-m4-calibration-setup.avif)
</Frame>

図 4.1. キャリブレーション

M4 はアクティブ測距を使用するため、多くの要因が精度に影響します。不適切な設置はマルチパス効果を生じさせ、測定値を歪める可能性があります。

この影響は、高反射物体の隣に低反射率の対象物がある場合に特に顕著です。理想的には光は青い経路を通ります。壁面で反射した光が、緑の経路で対象物に到達してカメラへ戻ることもあります。隣接する高反射物体から直接反射した光が、赤い経路でカメラに入射することもあります。光学的な不完全性によってこの光はグレアとなり、図 4.2 のように測距へ干渉します。

<Frame>
  ![M4 設置と反射光路](/images/products/m-series-m4-user-guide-m4-installation-and-reflection-paths.avif)
</Frame>

図 4.2. カメラ設置

### 4.2 再現性

再現性は通常、単一点のばらつき（1-σ）を指します。光電子計測デバイスである M4 は、ADC 変換、信号対雑音比、システムノイズの影響を受けます。図 4.3 は測定の再現性と信号強度の関係を示します。

<Frame>
  ![測定の再現性と信号強度](/images/products/m-series-m4-user-guide-measurement-precision-and-signal-intensity.avif)
</Frame>

図 4.3. 測定の再現性と信号強度

M4 は光電子アナログ信号をデジタルデータに変換します。ADC 変換中、アナログ値は最小分解能のステップに丸められるため、ノイズが生じます。1.1V の信号は 1V と表されて 10% の誤差、10.1V は 10V、100.1V は 100V と表され、それぞれ約 1% の誤差が生じる場合があります。このため、ADC 変換は低い信号レベルほど多くのノイズと誤差を導入します。ToF カメラの信号対雑音比は一般に SNR∝1/√t に従います。ここで `t` は積分時間です。積分時間を長くすると信号強度が上がります。

## 複数カメラの干渉

### 5.1 平行干渉

2 台のカメラを平行に設置すると、各カメラは自身の反射光と他方のカメラからの光の両方を受信し、深度データに干渉する可能性があります。平行干渉とは、2 台の M4 カメラが同一方向を向いたときに測定誤差が増加する現象です。

<Frame>
  ![平行カメラの干渉](/images/products/m-series-m4-user-guide-parallel-camera-interference.avif)
</Frame>

平行干渉を避けるため、カメラは水平面に対して角度を付けて設置してください。水平面に対して 0° で設置する必要がある場合は、MRDVS へカスタム構成をご相談ください。

<img src="/images/products/m-series-m4-user-guide-sdk-output-order.avif" alt="SDK の出力順序" />

SDK は、設定解像度の深度データと振幅データを各 1 フレーム出力します。各フレームは 1 次元配列として保存され、左上ピクセルから始まり、左から右、上から下へ進みます。図 6.1 は x 軸方向の出力の後に y 軸方向の出力が続くことを示し、次の順序になります。

(x,y):(0,0)(0,1)(0,2)(0,…)(1,0)(1,1)(1,2)(1,…)(2,…)(3,…)(…,…).

各深度画像ピクセルは、測定対象物からカメラ平面までの距離を表す 16 ビット符号なし short です。

各振幅画像ピクセルは、戻り信号の強度を表す 16 ビット符号なし short です。

### 6.3 IP アドレス

M4 カメラの既定 IP アドレスは 192.168.100.82 です。IP アドレスの変更または DHCP の有効化には、MRDVS が提供するデモアプリケーションを使用します。

### 6.4 デモアプリケーション

### 6.4.1 IP 設定

電源ケーブルを接続し、次に Ethernet ケーブルでカメラをコンピューターへ接続します。カメラの工場出荷時 IP アドレスは 192.168.100.82 であるため、コンピューターはサブネットマスク 255.255.255.0、IP アドレス 192.168.100.x（100.82 を除く）に設定します。**設定** → **Ethernet** → **アダプターのオプションを変更する** を開きます。**Ethernet** を右クリックして **プロパティ** を選択し、**インターネット プロトコル バージョン 4（TCP/IPv4）** を選択します。たとえば、IP アドレスを 192.168.100.20、サブネットマスクを 255.255.255.0 に設定します。

### 6.4.2 アプリケーションを開く

ソフトウェアをダウンロードしてインストールし、LxCameraViwer デモアイコンをダブルクリックします。カメラが 1 台接続されている場合、上位機アプリケーションは起動後にカメラを検索して開き、自動的に取得を開始します。

**注: 初回起動時は、システムによってアプリケーションのファイアウォール通過を許可する必要があります。**

アプリケーションには、基本操作、画像選択、カメラ設定、カメラ情報が含まれます。カメラ情報には、IP アドレス、ID、MAC アドレス、シリアル番号、ソフトウェアおよびアルゴリズムのバージョンが含まれます。中央パネルに表示するには、深度、振幅、RGB、または点群のチェックボックスを選択します。

### 6.4.3 画像を保存する

**Save** を選択すると、選択した画像がインストールディレクトリの `./data` フォルダーへ保存されます。端末にもパスが表示されます。例: `save path= ./data/<camera-ID>`。

保存後、`_a` は振幅画像、`_d` は深度画像、`_r` は RGB（MONO）画像を示します。`.pcd` は点群を示します。深度画像と振幅画像は PGM、RGB 画像は PNG、点群は PCD 形式です。

### 6.4.4 IP アドレスを変更する

必要な IP アドレス（例: 192.168.10.199）を入力します。サブネットマスクには 255.255.255.0、ゲートウェイには 192.168.10.1 を入力します。ゲートウェイは必要な IP アドレスと同じサブネット上にある必要があり、最後のオクテットを 1 に設定します。変更を確定した後、カメラの電源を入れ直します。

### 8.2 正しい操作

M4 カメラは 24V DC 電源を使用します。電源投入前に電源ケーブルを接続してください。正負の端子を逆接続すると製品を損傷するおそれがあるため、逆接続しないでください。

### 8.3 動作温度

周囲温度は表 2-1 に示す範囲内に保ってください。放熱性を高め、最適な性能を得るため、金属ブラケットなど熱伝導性のある部品に製品を取り付けてください。
