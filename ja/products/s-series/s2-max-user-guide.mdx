## 製品概要

本書は、浙江迈尔微视科技有限公司が開発した S2 Max カメラについて、仕様、特長、操作手順を説明します。

S2 Max は、ギガビット Ethernet 通信インターフェースと 24V DC 電源入力を備えた MRDVS ToF カメラです。

### 1.1 特長

- 1 TOPS の演算能力を統合し、外部 CPU が不要
- RGB-D 出力
- スタンドアロンでの障害物回避、ビン検出、体積計測
- ギガビット Ethernet

### 1.2 使用条件

**使用時は以下の要件を守ってください。**

- 製品のラベルを剥がさないでください。
- 製品を分解しないでください。損傷するおそれがあります。
- 強磁場内で製品を使用しないでください。
- 100 kLux を超える直射日光下で製品を使用しないでください。
- 筐体は、少量の精製水またはアルコールで湿らせた柔らかい糸くずの出ない布で清掃してください。
- 元の梱包材を保管し、可能な限り輸送時に使用してください。

## 測距原理と仕様

### 測距原理

S2 Max は Time of Flight（ToF）方式で距離を測定します。光を照射してから、物体で反射した光を受信するまでの時間を測定します。

S2 Max は深度撮像に直接測距方式を用い、最小限の演算リソースで高品質な深度データを生成し、高フレームレートで深度シーンを構築します。LiDAR と同様に、ToF カメラはパルス ToF（P\_ToF）と連続波 ToF（CW\_ToF）に分類されます。P\_ToF は通常不可視の光パルスを照射し、その往復時間から距離を計算します。CW\_ToF は変調された連続光を照射し、送信光と戻り光の位相差から飛行時間を計算します。

## 精度、再現性、複数カメラの干渉

### 4.1 正確さ

キャリブレーションでは、センサー測定値と実測値の間にある固定オフセットを除去するため、両者の対応関係を確立します。S2 Max では、カメラをレールに取り付けて白い壁へ向け、各ピクセルの測定値をカメラと撮像した壁面領域との距離に対応付けます。この対応関係で測定値を補正すると、図 4.1 のようにより正確な距離値が得られます。

<Frame>
  ![キャリブレーションのセットアップ](/images/products/s-series-s2-max-user-guide-calibration-setup.avif)
</Frame>

図 4.1. キャリブレーション

S2 Max はアクティブ測距を使用します。設置条件などによりマルチパス干渉が発生し、精度が歪む場合があります。

この影響は、高反射物体の隣に低反射率の対象物がある場合に特に顕著です。理想的な測定では青い経路を通りますが、光は壁面で反射して対象物へ到達し、カメラに戻ることがあります（緑の経路）。また、近傍の高反射物体からの光が直接カメラへ入射することもあります（赤の経路）。光学的な不完全性によってグレアが生じ、図 4.2 のように測距へ干渉します。

<Frame>
  ![カメラ設置時の光路](/images/products/s-series-s2-max-user-guide-camera-installation-light-paths.avif)
</Frame>

図 4.2. カメラ設置

### 4.2 再現性

再現性は通常、単一点のばらつき（1-σ）を意味します。光電子計測デバイスである S2 Max は、AD 変換、信号対雑音比、システムノイズなどの影響を受けます。図 4.3 は再現性と信号強度の関係を示します。

<Frame>
  ![再現性と信号強度](/images/products/s-series-s2-max-user-guide-precision-and-signal-strength.avif)
</Frame>

図 4.3. 再現性と信号強度

S2 Max は光電子アナログ信号をデジタルデータに変換します。ADC は最小分解能でアナログ信号を量子化するため、ノイズが生じます。たとえば、1.1V の信号が 1V と読まれれば誤差は 10%、10.1V が 10V と読まれれば誤差は 1%、100.1V が 100V と読まれれば誤差は 0.1% です。このため、AD 変換は低い信号強度ほど相対的に大きなノイズと誤差を生じさせます。ToF カメラの信号対雑音比は通常、積分時間 t と SNR∝1/√t の関係にあるため、積分時間を長くすると信号強度が上がります。

### 複数カメラの干渉

### 5.1 平行干渉

2 台のカメラを平行に設置すると、各カメラが自身と他方のカメラの両方から戻る光を受信し、深度データに干渉します。平行干渉とは、2 台の S2 Max カメラが同一方向を向いたときに検出誤差が増大する現象です。

<Frame>
  ![平行設置カメラの干渉](/images/products/s-series-s2-max-user-guide-parallel-camera-interference.avif)
</Frame>

平行干渉を避けるため、カメラは水平面に対して角度を付けて設置してください。0° で設置する必要がある場合は、MRDVS へカスタム構成をご相談ください。

### 6.1 SDK

SDK を使用して、カメラの初期化と開始、データ取得、カメラの終了を行います。Linux または Windows 以外のプラットフォームでは、カメラアプリケーションの移植時に SDK ソースを参考にしてください。

### 6.2 SDK の出力順序

<Frame>
  ![SDK の出力順序](/images/products/s-series-s2-max-user-guide-sdk-output-order.avif)
</Frame>

図 6.1. SDK の出力順序

SDK は、設定した解像度の深度データと強度データを 1 フレームずつ 1 次元配列として出力します。左上ピクセルが原点で、出力は左から右、上から下へ進みます。図 6.1 は、x 軸方向の出力の後に y 軸方向の出力が続くことを示します。

(x,y):(0,0)(0,1)(0,2)(0,…)(1,0)(1,1)(1,2)(1,…)(2,…)(3,…)(…,…).

各深度ピクセルは、測定対象物からカメラ平面までの距離を表す 16 ビット符号なし short です。

各強度ピクセルは、戻り信号の強度を表す 16 ビット符号なし short です。

### 6.3 IP アドレス

S2 Max の工場出荷時 IP アドレスは 192.168.100.82 です。MRDVS デモツールを使用して、IP アドレスの変更または DHCP の有効化を行います。

### 6.4 デモソフトウェア

### 6.4.1 IP 設定

電源ケーブルを接続し、次に Ethernet ケーブルでカメラをコンピューターへ接続します。工場出荷時のカメラ IP は 192.168.100.82 であるため、コンピューターはサブネットマスク 255.255.255.0、IP アドレス 192.168.100.x（100.82 を除く）に設定します。**設定** → **Ethernet** → **アダプターのオプションを変更する** を開き、**Ethernet** を右クリックして **インターネット プロトコル バージョン 4（TCP/IPv4）** を選択します。たとえば、IP アドレスを 192.168.100.20、サブネットマスクを 255.255.255.0 に設定します。

### 6.4.2 ソフトウェアを開く

ソフトウェアをダウンロードしてインストールし、LxCameraViwer デモアイコンをダブルクリックします。カメラが 1 台接続されている場合、上位機ソフトウェアは起動後にカメラを検索して開き、自動的に取得を開始します。

**注: 初回起動時は、システムによってファイアウォールアクセスを許可する必要があります。**

ソフトウェアは、基本機能、画像選択、カメラ設定、カメラ情報を提供します。カメラ情報には、カメラの IP、ID、MAC アドレス、シリアル番号、ソフトウェアおよびアルゴリズムのバージョンが含まれます。対応する画像を表示するには、**Depth**、**Intensity**、**RGB**、または **Point cloud** を選択します。

### 6.4.3 画像を保存する

**Save** をクリックすると、選択した画像がソフトウェアのインストールディレクトリ内の `./data` フォルダーへ保存されます。端末にもパスが表示されます。例: `save path= ./data/camera ID`。

保存ファイルでは、`_a` は強度画像、`_d` は深度画像、`_r` は RGB（MONO）画像、`.pcd` は点群です。深度画像と強度画像は PGM、RGB 画像は PNG、点群は PCD を使用します。

### 6.4.4 IP アドレスを変更する

必要な IP アドレス（例: 192.168.10.199）を入力します。サブネットマスクには 255.255.255.0、ゲートウェイには 192.168.10.1 を入力します。ゲートウェイは必要な IP アドレスと同じサブネット上にあり、通常は末尾が 1 です。変更を確定した後、カメラの電源を入れ直します。

### 8.2 正しい操作

S2 Max カメラは 24V DC 電源を使用します。電源投入前に電源ケーブルを接続し、正負の端子を逆接続しないでください。逆極性接続は製品を損傷するおそれがあります。

### 8.3 動作温度

周囲温度は製品仕様（表 2-1）の範囲内に保ってください。放熱性を高めて最適な性能を得るため、金属ブラケットなど熱伝導性のある部品に製品を取り付けてください。

### トラブルシューティング

表 9-1. トラブルシューティング

| 番号 | 問題 | 対処方法 |
| --- | --- | --- |
| 1 | 起動時にカメラが応答しない | ファイアウォールが無効になっていることを確認します。 |
| 2 | 上位機ソフトウェアが複数の IP アドレスを検出する | LAN 上の別のデバイスが同じ IP を使用しています。必要な IP アドレスを選択してください。 |
