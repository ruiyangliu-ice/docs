## 製品概要

### 目的と適用範囲

本書では、製品を統合して使用する開発者向けに、S10 カメラの仕様と主要な設計情報を説明します。

### 用語

| RGB-D カメラ | 同期され、空間的に整列した RGB 画像と深度画像を出力するカメラ |
| --- | --- |
| 深度 | カラーまたはモノクロ映像と同様のストリームで、各ピクセルがカメラからの距離を表します。 |
| FOV | 視野角。カメラが捉えるシーンの角度範囲で、水平（HFOV）、垂直（VFOV）、対角（DFOV）の視野角を含みます。 |
| IR カメラ | 赤外線カメラ。本製品では主に近赤外帯域を取得します。 |
| RGB カメラ | カラーカメラ。 |
| 深度カメラ | 深度モジュールが通常、ドットプロジェクター、IR カメラ、深度プロセッサーで構成され、カラーモジュールが通常 RGB カメラであるカメラ。 |
| SoC | 画像処理、深度計算、アプリケーションアルゴリズムに使用する System on a Chip。 |
| dToF | Direct Time of Flight による深度センシング技術。 |

### 動作原理

本製品は、長距離、高精度、強い干渉耐性、安定したデータ出力を特長とする dToF 方式の 3D 深度カメラです。統合された RGB モジュールがカラー画像を取得し、カメラ内部で RGB 画像と深度画像を整列させます。

### 製品の詳細

この小型産業用 RGB-D カメラは、0.3–8 m の深度データを提供します。RGB 画像と深度画像を空間的・時間的に整列させます。統合 SoC は、深度、強度、RGB、点群、障害物検出結果を出力します。Ethernet に加え、I/O 入力 2 点と出力 2 点により、4 つの障害物回避ゾーンを切り替え、非常停止、減速、安全状態の信号を出力できます。

## 初回使用

### 接続テスト

1. カメラを 24 V / 2 A の DC 電源に接続します。青色の電源インジケーターがゆっくり点滅すれば、正常に電源が入っています。
2. Category 6 Ethernet ケーブルでカメラをコンピューターに接続します。
3. カメラの工場出荷時 IP アドレスは `192.168.100.82` です。
4. コンピューターの IP をカメラと同じサブネットに設定し、コンピューターのファイアウォールを無効にします。
5. ホストソフトウェアを実行してカメラ画像を確認します。
6. ホストソフトウェアの入手については、MRDVS の営業またはテクニカルサポートにお問い合わせください。

### I/O配線

| インターフェース | 種別 | 備考 |
| --- | --- | --- |
| IN1 | 入力 | High アクティブのディスクリート入力。24 V / オープン入力に対応。 |
| IN2 | 入力 | High アクティブのディスクリート入力。24 V / オープン入力に対応。 |
| OUT1 | 出力 | GND / オープンのディスクリート出力。24 V プルアップに対応。 |
| OUT2 | 出力 | GND / オープンのディスクリート出力。24 V プルアップに対応。 |
| COM | GND | ディスクリート出力の共通グランド。IN1 は IN\_COM1 と組み合わせて使用。 |

### トラブルシューティング

| No. | 問題 | 対処方法 |
| --- | --- | --- |
| 1 | カメラを開いても応答しない | ファイアウォールが無効になっていることを確認します。 |
| 2 | ホストソフトウェアで複数の IP アドレスが検出される | LAN 上の別のデバイスが同じ IP を使用しています。必要な IP アドレスを選択してください。 |
| 3 | カメラを開いた後にデータが不安定になる | Gigabit Ethernet ケーブルを使用してください。Fast Ethernet では、初期のデータが不安定になることがあります。 |
| 4 | ソフトウェアのインストール場所 | C ドライブへの既定インストールは、権限設定の影響を受けることがあります。 |
