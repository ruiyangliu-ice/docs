## 製品概要

### 目的と対象範囲

本書は、S2 Max 2.0 カメラを統合・使用する開発者向けに、仕様および主な設計情報を説明します。

### 用語

| RGB-D カメラ | 時間的・空間的に整合した RGB 画像と深度画像を同期出力するカメラ |
| --- | --- |
| 深度 | カラーまたはモノクロ映像に類似した映像ストリームで、各ピクセルがカメラからの距離を表すもの |
| FOV | 視野角。カメラが取得するシーンの角度範囲で、水平（HFOV）、垂直（VFOV）、対角（DFOV）の視野角を含む |
| IR カメラ | 赤外線カメラ。本製品では主に近赤外線帯を取得する |
| RGB カメラ | カラーカメラ |
| 深度カメラ | 深度モジュールが通常、ドットプロジェクター、IR カメラ、深度プロセッサーで構成され、カラーモジュールが通常 RGB カメラで構成されるカメラ |
| SoC | 画像処理、深度計算、アプリケーションアルゴリズムに使用する System on a Chip |

### 動作原理

本製品は間接 Time of Flight（iToF）方式で距離を測定します。カメラがレーザーパルスを照射し、受信側が受信波形と送信波形を比較して位相差とパルス飛行時間 Δt を計算します。

対象物までの距離は、distance = speed of light \* Δt / 2 で計算します。

</Frame>

### 製品の詳細

このコンパクトな産業用 RGB-D カメラは SONY CW iToF カメラを統合し、0.2 m～5 m の深度データと 3 チャンネルのトゥルーカラー RGB 画像を出力します。RGB 画像と深度画像を空間的・時間的に整合し、4 つの障害物回避ゾーンを切り替え、緊急停止、減速、安全状態の信号を出力します。

### 特長

- 外部 CPU を必要とせず、障害物回避アルゴリズムを実行する 1.0 TOPS 演算プラットフォームを統合
- 柔軟で目立たない統合に適したコンパクトなフォームファクター
- 高い環境適応性: 100 kLux の太陽光に耐え、暗所から明所まで屋内外で動作
- 0.2～5 m の広い測定範囲
- スタンドアロンでの障害物回避、ビン検出、体積計測
- RGB-D 出力

### カメラの検出範囲

図 4.1 は S2 Max 2.0 の検出領域を示します。水平検出角は 81°、垂直検出角は 61° です。検出距離は光出力に依存します。光出力と対象物の反射率が高いほど近距離側の不感帯は大きくなり、遠距離側の不感帯は小さくなります。光出力と反射率が低いほど近距離側の不感帯は小さくなり、遠距離側の不感帯は大きくなります。反射率 10%~~90% の対象物に対する S2 Max 2.0 の測定範囲は 0.2~~5m です。5m を超えると、反射信号強度の低下と環境光干渉により、測距誤差が大きくなります。

### 光学座標系と原点座標系

**光学座標系:**

- 光学座標系には、カメラ座標系（CCS）とワールド座標系（WCS）があります。
- カメラ座標系は 2D 深度画像の座標系で、原点は光学中心です。
- ワールド座標系は 3D 点群の座標系です。
- カメラ内部パラメーターを使用して、深度画像座標を 3D 点群座標へ変換します。SDK のサンプルを参照してください。

<Frame>
  ![光学座標系](/images/products/s-series-s2-max-2-user-guide-optical-coordinate-system.avif)
</Frame>

**カメラ原点は次のように定義されます:**

1. X 座標の原点は製品の X 軸に一致します。
2. Y 座標の原点は製品の Y 軸に一致します。
3. Z 座標の原点はカメラ前面にあります。

<Frame>
  ![カメラ原点](/images/products/s-series-s2-max-2-user-guide-camera-origin.avif)
</Frame>

## 初回使用

### 接続テスト

<Frame>
  ![接続テスト](/images/products/s-series-s2-max-2-user-guide-connection-test.avif)
</Frame>

1. カメラを 24V/2A の DC 電源へ接続します。青色の電源インジケーターがゆっくり点滅すれば、正常に起動しています。
2. Category 6 Ethernet ケーブルでカメラをコンピューターへ接続します。
3. 工場出荷時のカメラ IP アドレスは 192.168.100.82 です。
4. コンピューターの IP アドレスをカメラと同じサブネットに設定し、コンピューターのファイアウォールを無効にします。
5. 上位機ソフトウェアを起動し、カメラ画像を表示します。
6. 上位機ソフトウェアの入手については、MRDVS の営業または技術サポートへお問い合わせください。

## 安全とよくある質問

### レーザー安全クラス

| <img src="/images/products/s-series-s2-max-2-user-guide-laser-safety.avif" alt="レーザー安全" /> | レーザー安全 |
| --- | --- |
| 本製品は動作中に不可視レーザーを照射します。目をビームにさらさないでください。レーザーは EN60825 に定める Class 1 に適合し、通常の使用では人体に害はありません。 |  |

### 正しい操作

S2 Max 2.0 カメラは 24V DC 電源を使用します。電源投入前に電源ケーブルを接続し、正負の端子を逆接続しないでください。逆極性接続は製品を損傷するおそれがあります。

### 動作温度

周囲温度は製品仕様（表 2-1）の範囲内に保ってください。放熱性を高めて最適な性能を得るため、金属ブラケットなど熱伝導性のある部品に製品を取り付けてください。

### トラブルシューティング

| 番号 | 問題 | 対処方法 |
| --- | --- | --- |
| 1 | 起動時にカメラが応答しない | ファイアウォールが無効になっていることを確認します。 |
| 2 | 上位機ソフトウェアが複数の IP アドレスを検出する | LAN 上の別のデバイスが同じ IP を使用しています。必要な IP アドレスを選択してください。 |
| 3 | 起動後のカメラデータが不安定 | ギガビット Ethernet ケーブルを使用してください。Fast Ethernet では初期データが不安定になる場合があります。 |
| 4 | ソフトウェアのインストール先 | C ドライブへの既定インストールは、権限設定の影響を受ける場合があります。 |
