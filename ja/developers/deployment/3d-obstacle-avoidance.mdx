3Dビジュアル障害物回避は、ターゲット検出、地面適応、障害物状態出力をカメラ上で実行します。カメラの外部パラメータと領域を設定すると、障害物回避のパラメータグループを切り替え、上位アプリケーション、API、対応フィールドバスから結果を取得できます。

<Info>
  このガイドの値は設定項目間の関係を示す例です。実際の値は車両、設置位置、作業エリアに応じて決まります。設定を送信する前に、必ず現場で検証してください。
</Info>

## 導入の準備

### カメラの設置

| 車両タイプ | 設置のガイドライン |
| --- | --- |
| 潜り込み型AMR | 進行方向の前面にカメラを取り付けます。取付構造が視野を遮らないようにしてください。S10を推奨します。 |
| フォークリフト | レンズを約`30°–55°`下向きにしてマストへ取り付けます。視野の端が車両前方に届くようにします。可能な場合は設置高さを`2 m`以下に保ってください。S10を推奨します。 |

### カメラを接続する

<Steps>
  <Step title="ホストのネットワークを設定する">
    出荷時のカメラアドレスは`192.168.100.82`です。コンピューターのEthernetアダプターを同一サブネットに設定します。
  </Step>
  <Step title="接続して映像を確認する">
    **LxCameraViewer**を開き、カメラを検索して開きます。深度マップと点群が正しく表示されることを確認してください。
  </Step>
  <Step title="必要に応じてカメラアドレスを変更する">
    **Other tools → Network → IP configuration tool**でIPアドレスを変更します。変更後、カメラは再起動します。別のサブネットへ移動する場合は、コンピューターのEthernetアドレスも更新してください。
  </Step>
</Steps>

<Warning>
  本番ネットワークでファイアウォールを恒久的に無効化しないでください。管理されたデバッグネットワークでは、セキュリティポリシーに従い、必要なアプリケーションとポートのみを許可してください。
</Warning>

### 画像を調整する

**3D settings**と**Filter settings**で画質を確認します。従来の障害物回避設定では、高露光`650`、低露光`200`、低信号しきい値`10–20`を開始値にできます。S10では通常、グレアレベル`1`のみが必要です。標準外の設置では、導入前に技術サポートへ設定を確認してください。

## 障害物回避アルゴリズムを設定する

<Steps>
  <Step title="アルゴリズムを有効にする">
    **Application algorithm**で常時有効モードを選択します。S10では**Obstacle avoidance algorithm**を、その他の対応モデルでは**Obstacle avoidance algorithm 2.0**を選択します。
  </Step>
  <Step title="領域タイプを選択する">
    車両に合わせて長方形または扇形の領域を選択します。S10は扇形領域に対応しておらず、使用すると誤った結果になる可能性があります。
  </Step>
  <Step title="外部パラメータと領域を設定する">
    先にカメラの外部パラメータを設定し、その後で障害物回避領域を設定します。外部パラメータを変更すると、他の領域も新しい値を使用します。
  </Step>
  <Step title="送信して検証する">
    パラメータを送信し、点群ビューと出力状態で警告、アラーム、シールド領域を確認します。
  </Step>
</Steps>

### カメラの外部パラメータ

| パラメータ | 例 | 説明 |
| --- | --: | --- |
| Roll（X軸） | `180°` | カメラの向き。標準的な直立設置の例です。 |
| Pitch（Y軸） | `90°` | カメラの向き。標準的な垂直設置の例です。 |
| Yaw（Z軸） | `90°` | カメラの向き。 |
| X位置 | `430 mm` | 車両の前後軸に沿ったカメラ位置。 |
| Y位置 | `0 mm` | 車両の左右軸に沿ったカメラ位置。`0`は中心を示します。 |
| Z位置 | `120 mm` | 地面からのカメラ高さ。 |

先に設置高さを設定し、点群ビューで地面が水平になるまでrollとpitchを微調整します。完了後に**Send parameters**を選択してください。

### 障害物回避領域

| パラメータ | 例 | 用途 |
| --- | --: | --- |
| 警告距離（遠方X） | `2000 mm` | この距離より遠い領域はクリアとみなします。アラーム距離までが警告・減速ゾーンです。 |
| アラーム距離（中間X） | `1500 mm` | シールド距離までがアラーム・停止ゾーンです。 |
| シールド距離（近傍X） | `600 mm` | 近端の死角です。このゾーンの障害物は障害物回避の対象外です。 |
| 左右範囲（Y） | `−810 / 1270 mm` | 車両中心線の両側における検出限界。 |
| 下限・上限高さ（Z） | `10 / 1500 mm` | 検出に含める高さ範囲。 |

<Tip>
  X値は車両中心を基準とします。実際の保護距離にはカメラのXオフセットも考慮してください。たとえば、警告距離からカメラの前後オフセットを引きます。
</Tip>

対応する領域グループ数は切り替え方式によって異なります。

| 切り替え方式 | 対応グループ |
| --- | --: |
| S2 / S2 Max 2.0 I/O | `0–3` |
| SDK、UDP、RS485、CAN | `0–19`（モデル依存） |

検証済みの値は`Tools\\params\\<camera ID>\\avoidance.json`へバックアップします。同一タイプの別車両には、**Load configuration from file**でこのファイルを適用できます。

## 通信と状態出力

フィールドバスまたはネットワークプロトコルを使用する前に、上位アプリケーションで障害物回避領域と外部パラメータを設定してください。APIを除くほとんどの通信方式はパラメータグループを切り替えるものです。詳細なパラメータ設定には上位アプリケーションまたはAPIを使用します。

| カメラ | 対応通信 |
| --- | --- |
| S2 | API, UDP, I/O |
| S2 Max | API, UDP, CAN |
| S2 Max 2.0 | API, UDP, I/O, CAN |
| M4 Pro | API, UDP, RS485 |
| M4 | API, UDP, CAN |
| M4 Mega | API, UDP, I/O, CAN |

<Note>
  I/Oの優先度が最も高くなります。I/Oが有効な間、他の方式では現在のパラメータグループを変更できませんが、デフォルトまたは一時パラメータは更新できます。上位アプリケーションとAPIはデフォルトパラメータを、UDP、CAN、RS485は通常一時パラメータを設定します。電源断後の動作は、最新設定の保存方法に依存します。
</Note>

### API

Windows、Linux、ARMアプリケーションは、SDKを通じて障害物回避APIを呼び出せます。Windows用上位アプリケーションのインストール後、SDKとサンプルはそのインストールディレクトリにあります。障害物回避サンプルは`Sample\\C\\application_obstacled`にあります。S10でAPIを使用してパラメータグループを高頻度に切り替えないでください。UDPまたはI/Oを使用します。

### RS485（M4 Proのみ）

推奨ボーレート`9600`のModbus RTUを使用します。現在の障害物回避結果を取得するには、ファンクションコード`0x04`でアドレス`108`（`0x6C`）から2つの入力レジスタを読み取ります。パラメータグループを切り替えるには、ファンクションコード`0x06`でアドレス`106`（`0x6A`）に1レジスタを書き込みます。

| ピン | 信号 | 線色 |
| --: | --- | --- |
| 1 | GND | 青 |
| 2 | RS485\_A | 灰 |
| 3 | RS485\_B | 白 |
| 4 | VIN\+ | 茶 |
| 5 | VIN− | 黒 |

### UDPとTCP

メッセージは16進フレームで送信されます。UDPでは、最初に接続確立メッセージを送信します。接続確立後、カメラは画像フレームレートで結果を送信します。

| 方向 | フレーム | 意味 |
| --- | --- | --- |
| カメラ → コントローラー | `ACED0410XX000000` | 障害物なし。`XX`は現在のパラメータグループです。 |
| カメラ → コントローラー | `ACED0410XX000001` | 警告・減速。 |
| カメラ → コントローラー | `ACED0410XX000002` | アラーム・停止。 |
| コントローラー → カメラ（UDP） | `ACED040000000000` | UDP接続を確立します。 |
| コントローラー → カメラ | `ACED041A00000000`～`ACED041A00000013` | パラメータグループ`0–19`を切り替えます。 |
| コントローラー → カメラ | `ACED041B00000000` | 現在のグループをデフォルトグループとして保存します。 |

デフォルトのリモートUDPポートは`6688`です。パラメータの切り替えには読み込み時間が必要です。画像フレームレートや結果の更新レートが低下する可能性があるため、急速な切り替えは避けてください。

### CANとI/O

CANは対応モデルでパラメータグループを切り替えられます。I/O出力は、クリア、減速、非常停止の状態を通知します。出力タイプはプッシュプルまたはオープンドレインです。配線前にコントローラーの入力タイプを確認してください。

| プッシュプルOUT1 | プッシュプルOUT2 | 状態 |
| --- | --- | --- |
| `24 V` | `24 V` | 障害物なし |
| `24 V` | `0 V` | 減速 |
| `0 V` | `24 V` | 非常停止 |
| `0 V` | `0 V` | 無効、初期化中、または障害 |

<Warning>
  S10では、`24 V−`をコントローラーの電源グランドへ、`IN_G`と`OUT_G`をコントローラーの信号グランドへ接続します。コントローラーがこの2つのグランドを区別しない場合は、現場で承認された共通グランド方式を使用してください。コントローラーがPNPまたはNPN信号のどちらを使用するか確認し、テスターで配線を検証してください。
</Warning>

## トラブルシューティング

| 現象 | 確認項目 |
| --- | --- |
| 黒色または低反射率の物体を見落とす | 点群のカバー範囲を確認し、積分時間と低信号しきい値を調整します。必要に応じて黒いフォーク先端へ反射面を追加します。 |
| 低い物体を検出しない | Z下限を確認し、検証のために一時的に`0`へ設定します。改善しない場合は、設置高さと点群のカバー範囲を確認します。 |
| パラメータが反映されない | パラメータが送信されたことを確認します。パラメータの有効性、ネットワーク接続、パラメータグループの優先度を確認してください。 |
| データが異常 | 取付構造による遮蔽、レンズ保護フィルム、追加の保護ガラスを確認します。 |
