PalletProは、Mシリーズカメラのパレット認識およびドッキング用パラメータを設定します。アルゴリズムはカメラ上で動作します。PalletProではカメラ接続、撮像確認、外部パラメータ校正、認識領域の調整、結果の取得を行えます。

<Info>
  本ガイドの標準パレット寸法、距離、パラメータ範囲は、標準認識ワークフローにのみ適用されます。非標準、脚なし、高反射率のパレットは、事前に現地で評価してください。
</Info>

## 導入準備

### 標準パレットと設置要件

このワークフローでは、標準的な2脚または3脚パレットを使用します。元のワークフローでは `1.2 m × 0.8 m` または `1.2 m × 1.0 m` のパレットを使用します。非標準の寸法は導入前にMRDVSへ確認してください。

| 項目 | 要件 |
| --- | --- |
| カメラ位置 | カメラを2本のフォークの中央にできるだけ近づけます。左右方向のオフセットは `50 mm` 以下にしてください。 |
| カメラ姿勢 | カメラ前面を地面に対して垂直に保ち、ピッチとロールを最小化します。 |
| 視野 | 最短認識距離で、フォークがパレット全体を遮らないようにします。 |
| 追従設置 | カメラをフォーク根元のパネルに取り付け、フォークとともに移動させます。 |
| 下垂設置 | カメラをフォーク下部に取り付け、フォークの全下降時に追従させます。 |

フォーク長が `1.2 m` 以下の場合、経験的な取付高さは `0.35–0.4 m` です。より長いフォークでは、まず `0.4–0.8 m` を目安にします。最終的な高さは、視野、パレット脚の撮像、ドッキング距離から確認してください。

### 機器とソフトウェア

- カメラには `24 VDC` を供給し、Cat7 Ethernetケーブルでコンピューターに接続します。
- 推奨ホスト：Windows 10以降、Intel® Core™ i5（第7世代）以降、`8 GB` RAM、Intel® UHD Graphicsまたはより高性能なGPU。
- PalletProのインストール時にC\+\+ランタイムの確認が表示された場合は承諾してください。ランタイムがないとアプリケーションが起動しないことがあります。

<Warning>
  プロジェクトで提供されたカメラファームウェアとパレットアルゴリズムパッケージのみを使用してください。アップグレード中にカメラは再起動し、一時的にデバイス一覧から消えます。アップグレード前に、検証済みの校正データをバックアップしてください。
</Warning>

## クイック導入

<Steps>
  <Step title="ネットワークを設定してカメラを開く">
    コンピューターを `192.168.100.xxx / 255.255.255.0` サブネットに設定します。PalletProを起動し、対象カメラを検索して開きます。
  </Step>
  <Step title="バージョンと撮像を確認する">
    LxCameraViewerで、アプリケーション、カメラファームウェア、パレットアルゴリズムのバージョンがプロジェクト提供版と一致することを確認します。点群内にパレット脚全体が表示されることを確認します。
  </Step>
  <Step title="初期高さを設定する">
    **Parameter settings** の **Height adaptation** を使用して初期値を取得します。地面の線を基準に微調整し、**Save parameters** を選択します。
  </Step>
  <Step title="近端ティーチングを実行する">
    標準パレットを使用し、近くに障害物がない状態で中央に配置します。パレットがカメラから約 `1.3 m` の位置で **Pallet teaching (near end)** を選択します。
  </Step>
  <Step title="遠端ティーチングを実行する">
    パレットの横方向位置を維持します。車両を約 `600–1000 mm` 直線で後退させ、パレットがカメラから約 `2.0–2.4 m` の位置になったら **Pallet teaching (far end)** を選択します。
  </Step>
  <Step title="保存して検証する">
    パラメータを保存し、近端・遠端の位置で繰り返しテストします。X、Y、角度の出力と認識の安定性を確認します。
  </Step>
</Steps>

<Tip>
  遠端ティーチングはカメラのピッチを校正します。近端ティーチングと遠端ティーチングの間に、横移動や旋回を行わないでください。
</Tip>

## PalletProの使用

### メイン画面

| 領域 | 用途 |
| --- | --- |
| Basic operations | 外部パラメータ校正、パラメータ保存、カメラ操作。 |
| Advanced applications | 詳細パラメータ、3D表示、オフラインテスト。 |
| Camera settings | カメラの検索、開閉、ライブデータ表示、検出、投影。 |
| Parameter settings | カメラ名、設置高さ、姿勢、設置方法。 |
| File import | オフラインテスト用の校正ファイル、単一画像、画像フォルダーの取り込み。 |
| Logs and images | 実行ログ、バージョン、ライブ認識結果の表示。 |

### 外部パラメータ校正

**Basic operations → Extrinsic calibration** で、ティーチング前に **Calibration notes** を確認します。顧客名にはプロジェクト名と車両IDを使用します。カメラ光学中心からフォークリフト旋回中心までの距離が必要です。

| 校正手順 | 結果 |
| --- | --- |
| Near-end teaching | 取付高さ、横方向オフセット、方位、ロールを校正します。 |
| Far-end teaching | 近端の結果からピッチを校正します。 |
| Save parameters | 現在の校正値をカメラへ送信します。 |

<Frame>
  ![PalletProの近端パレットティーチング画面](/images/developers/deployment-palletpro-tray-teaching-near-end-explanation.avif)
</Frame>

### 詳細パラメータ

プロジェクトで必要な項目のみを変更し、変更ごとに **Save parameters** を選択してください。

| パラメータ | 用途 |
| --- | --- |
| `R` | カメラ姿勢：ピッチ、方位、ロール。 |
| `t` | カメラのオフセット。最初の値は横方向オフセットです。 |
| `ground_y` | カメラ高（`mm`）。 |
| `orientation` | 設置方法：`0` は正立、`2` は反転、`1` / `3` は側面設置。 |
| `multi_level` | 複数パレット認識：`0` は無効、`1` は有効。 |
| `quad` | 4脚パレット認識：`0` は無効、`1` は有効。 |
| `min_z` / `max_z` | カメラ距離軸方向の有効範囲。 |
| `min_x` / `max_x` | 有効な水平方向範囲。 |
| `two_leg` | 2脚パレット認識：`0` は無効、`1` は有効。 |

<Note>
  ここに記載されていない詳細パラメータは、MRDVSの指示がない限り変更しないでください。脚幅、ビーム検出、認識領域を調整する必要がある場合は、元の設定を保存し、変更ごとに検証してください。
</Note>

### オフラインテストとログ

**Advanced applications → Offline test** で、次のファイルをドラッグします。

- `pallet_settings.json` 校正ファイル
- 1枚のPNG画像、または結果画像を含むフォルダー

単一ファイルまたはフォルダーテストを選択し、**Start detection** を選択します。ログ領域にはカメラAPI、ファームウェア、アルゴリズム、認識結果が表示されます。トラブルシューティング用に、**Camera operations** からソフトウェアログをエクスポートします。

## 通信連携

### TCPとUDP

LxCameraViewerで **Pallet localization** を選択し、**Always on** に設定します。TCPサーバーの既定ポートは `5501`、UDPは `8000` です。メッセージはビッグエンディアンで、標準フレーム長は `16` バイトです。

| 方向 | 16進コマンド | 用途 |
| --- | --- | --- |
| Client → PalletPro | `60 04 00 00` | 認識を開始します。 |
| Client → PalletPro | `60 04 00 01` | 認識を停止します。 |

応答フレームには、戻りコード、長さ、X / Y / theta / Zの符号、パレット前面中心のX / Y、角度theta、パレット高さが含まれます。現行プロトコルの拡張バイトは `0` に設定します。

### RS485（M4 Proのみ）

Modbus RTUを `9600` baud、`8N1` で使用します。既定のModbusアドレスは `0x17` です。SDKで `1–247` のアドレスに設定してください。

| 操作 | ファンクションコード | レジスタ | 値 |
| --- | --- | --- | --- |
| 認識の有効化／停止 | `0x06` | `120` (`0x0078`) | `1` で有効、`0` で停止 |
| 結果の読み取り | `0x04` | `122` (`0x007A`) | `8` レジスタを読み取り |

結果フィールドは、X、Y、yaw、戻り値、高さで、それぞれ4バイトで表現されます。

### CANopen（M4 / M4 Mega）

CANは `250 Kbit/s` の標準11ビットフレームを使用します。コントローラーは `COB ID 0x212` を送信します。`MODE CTRL` の `0` は認識を無効、`1` は有効にします。デバイスは `0x192`、`0x292`、`0x392`、`0x492` を通じて認識状態、姿勢、位置、高さ、パレット寸法を返します。

### Modbus TCP

このインターフェースにはアルゴリズムバージョン `0.8.1` 以降が必要です。既定ポートは `6601` で、すべてのネットワークインターフェースをリッスンし、レジスタ開始アドレスは `0x100` です。

| オフセット | レジスタ | 内容 |
| --: | --- | --- |
| 0 | `0x100` | 絶対戻り値。`0` は認識成功を示します。 |
| 1–4 | `0x101–0x104` | X、Y、yaw、高さの符号。`0` は正、`1` は負。 |
| 5–8 | `0x105–0x108` | パレット前面中心のX / Y、yaw、高さ。 |
| 9 | `0x109` | パレット幅。 |
| 10 | `0x10A` | パレット脚の数。 |
| 11–19 | — | 予約済み。 |

## 検証とトラブルシューティング

### 校正の合否判定

近端・遠端ティーチング位置の間を繰り返し走行します。XおよびYの誤差が `10 mm` 以内で、認識が欠落なく安定している場合、校正は許容できます。たとえば `x = -2000`、`y = 100`、`yaw = 2.3` は、パレットがカメラ光学中心から `2000 mm` の距離、右に `100 mm`、平面視で反時計回りに `2.3°` 回転していることを示します。

### 主なエラーコード

| エラーコード | 意味 | 優先確認項目 |
| --: | --- | --- |
| `0` | 認識正常 | — |
| `-1` | 画像データなし、またはデータ不足 | カメラが画像を出力していることを確認します。 |
| `-2` / `-6` | 点数不足、またはパレット脚未検出 | 取付高さ、フォーク姿勢、遮蔽物、パレット脚の撮像を確認します。 |
| `-3` | パレット脚の寸法が条件外 | 脚幅またはパレット幅の制限を調整します。 |
| `-4` | カメラ高が未設定 | 設置高さを設定して保存します。 |
| `-5` | ビーム検出エラー、またはパレットの傾き過大 | ビームの撮像、フライングピクセル、ドッキング距離を確認します。 |
| `-7` | パレット脚幅の差が過大 | 反射板、壁、その他の物体が端部脚の撮像に影響していないか確認します。 |
| `-8` | パレット角度が大きすぎる | パレット姿勢を調整します。 |

### 認識条件と現場の制約

- 標準条件：パレット幅・長さ `800–2000 mm`、高さ `80–200 mm`、脚幅 `40–200 mm`、開口幅 `300–600 mm`、ビーム厚さ `30 mm` 以上、認識距離 `1200–3000 mm`。
- パレット全体を視野内に入れてください。フォーク、荷物、周辺物体による遮蔽を避けます。
- 黒色、低反射率、高反射率のパレットは現地でテストしてください。元のテストでは、反射率 `5%` の黒色パレットを `2 m` で撮像できました。必要に応じて積分時間と低信号しきい値を調整してください。
- 高位置でフォークを差し込む場合は、可能な限り反射板とパレット脚の間を `200 mm` 以上確保してください。
- 実運用のドッキングでは、アプリケーション層で結果のタイムスタンプを使用し、データが最新かを判断して遅延補正を防止してください。

非標準または脚なしパレットの評価についてはMRDVSへお問い合わせください。
