## 概要

本ガイドは、カメラデバイスを統合する開発者向けです。M4、M4 Mega、M4 Pro、V1 Pro、S2、S2 Max、H3 シリーズ製品の Camera SDK API を説明します。SDK は x86 Windows、x86 Linux、Arm Linux システムで動作します。

Camera SDK は、統一されたデバイスアクセスおよびパラメーター設定 API を提供します。深度、強度、点群、RGB データの同期・非同期取得に対応します。一部のカメラモデルでは、障害物回避、ドッキング、自己位置推定のデータも提供します。

<Info>
  サンプルと API 説明は製品に同梱される SDK バージョンに基づいています。使用可能なパラメーターは、製品、ファームウェア、SDK のバージョンによって異なる場合があります。
</Info>

サンプルは開発のためのガイドであり、すべてのデバイスやユースケースを網羅するものではありません。

2. ホストコンピューターで、カメラに接続するネットワークポートの IP アドレスを `192.168.100.x` セグメント内に設定し、デバイスと重複しないことを確認します。サブネットマスクは `255.255.255.0` です。

3. カメラ接続時は、SDK を実行するホストによるカメラデータパケットの遮断を防ぐため、ファイアウォールを無効にすることを推奨します。

```bash

sudo su root

```

インストールスクリプトは SDK を `/opt/Lanxin-MRDVS` にインストールし、現在のユーザーの環境変数を設定します。別のユーザーでプログラムを実行する場合は、そのユーザーでスクリプトを再実行するか、そのユーザーの `~/.bashrc` に次の行を追加します。

```bash
export LD_LIBRARY_PATH=/opt/Lanxin-MRDVS/lib/:$LD_LIBRARY_PATH
```

インストール前から開いている端末では、プログラムの起動前に次のコマンドを実行します。

```bash
source ~/.bashrc
```

## 呼び出し要件

### パラメーター型と対応 API

1. `LX_INT` で始まる列挙型は、`DcSetIntValue` または `DcGetIntValue` で INT 型パラメーターを設定・取得します。
2. `LX_FLOAT` で始まる列挙型は、`DcSetFloatValue` または `DcGetFloatValue` で FLOAT 型パラメーターを設定・取得します。
3. `LX_BOOL` で始まる列挙型は、`DcSetBoolValue` または `DcGetBoolValue` で BOOL 型パラメーターを設定・取得します。
4. `LX_STRING` で始まる列挙型は、`DcSetStringValue` または `DcGetStringValue` で文字列型パラメーターを設定・取得します。
5. `LX_CMD` で始まる列挙型のコマンドは、`DcSetCmd` で実行します。
6. `LX_PTR` で始まる列挙型は、`DcGetPtrValue` でポインター型の結果を取得します。

  ストリーミング中、または `LX_INT_WORK_MODE` が常時オンモードの場合は、以下の機能を設定しないでください。
</Warning>

- DcSetRoi

- LX\_INT\_2D\_BINNING\_MODE;
- LX\_BOOL\_ENABLE\_2D\_TO\_DEPTH;
- LX\_BOOL\_ENABLE\_MULTI\_EXPOSURE\_HDR;
- LX\_BOOL\_ENABLE\_MULTI\_MACHINE;
- LX\_INT\_TRIGGER\_MODE;
- LX\_INT\_CALCULATE\_UP;
- LX\_BOOL\_ENABLE\_HDR;
- LX\_BOOL\_ENABLE\_TOF\_DEPTH\_CALIBE;
- LX\_BOOL\_ENABLE\_SYNC\_FRAME
- LX\_INT\_SAVE\_PARAMS\_GROUP

**2. 動作モード（LX\_INT\_WORK\_MODE）が通常開放の場合でも、次の設定はできません。**

- LX\_INT\_TOF\_FREQMODE<br />

**3. 3D 自動露出（LX\_BOOL\_ENABLE\_3D\_AUTO\_EXPOSURE）が有効な場合、次の機能列挙値は操作できません。**

- LX\_BOOL\_ENABLE\_MULTI\_EXPOSURE\_HDR ;
- LX\_INT\_FIRST\_EXPOSURE;
- LX\_INT\_SECOND\_EXPOSURE;
- LX\_INT\_THIRD\_EXPOSURE;
- LX\_INT\_GAIN;<br />

**4. 3D 自動露出（LX\_BOOL\_ENABLE\_3D\_AUTO\_EXPOSURE）が無効な場合、次の機能列挙値は操作できません。**

- LX\_INT\_3D\_AUTO\_EXPOSURE\_LEVEL

3D 自動露出の最大値（LX\_INT\_3D\_AUTO\_EXPOSURE\_MAX）および最小値も設定できません。

- (LX\_INT\_3D\_AUTO\_EXPOSURE\_MIN)

**5. 2D 自動露出（LX\_BOOL\_ENABLE\_2D\_AUTO\_EXPOSURE）が有効な場合、次の機能列挙値は操作できません。**

- LX\_INT\_2D\_MANUAL\_EXPOSURE

<br />**6. 2D 自動露出（LX\_BOOL\_ENABLE\_2D\_AUTO\_EXPOSURE）が無効な場合、次の機能列挙値は操作できません。**

- LX\_INT\_2D\_AUTO\_EXPOSURE\_LEVEL;

<br />9.**S2 以外のデバイスで内蔵アルゴリズムを有効にする場合は、先に ToF アルゴリズムを設定します。アルゴリズムパラメーターは、内蔵アルゴリズム（LX\_INT\_ALGORITHM\_MODE）が有効な場合にのみ設定できます。**

- (LX\_STRING\_ALGORITHM\_PARAMS)

<br />10.**点群データ（LX\_PTR\_XYZ\_DATA）を取得するには、先に深度マップを有効にする必要があります。**

- (LX\_BOOL\_ENABLE\_3D\_DEPTH\_STREAM)
