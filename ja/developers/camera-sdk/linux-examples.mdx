## 概要

MRDVS Camera SDK for Linux には、C/C\+\+、Java（HTTP サービス）、ROS、ROS 2 のサンプルが含まれます。サンプルでは SDK の基本的なワークフローを示します。プロジェクトでは、用途に応じたロジックとエラー処理を追加してください。

まず、環境設定、インストールスクリプト、サンプルディレクトリの確認を完了します。次に、対象言語のコンパイルと実行の手順に従ってください。付録には、一般的な依存関係とテストパッケージのインストール方法を示します。

<Frame>

### 3.2 サンプルコードの概要

`Sample` ディレクトリに移動します。ディレクトリの内容は次のとおりです。

<Frame>
  ![Illustrations related to sample code introduction](/images/developers/camera-sdk-linux-examples-sample-code-introduction.avif)
</Frame>

- `C` フォルダーには C および C\+\+ 関連のコードが含まれます。
- `Java` フォルダーには、SDK を間接的に呼び出す HTTP サーバーが含まれます。
- `Ros` フォルダーには ROS のサンプルが含まれます。
- `Ros2` フォルダーには ROS 2 のサンプルが含まれます。

#### 3.2.1 C および C\+\+ サンプルコード

`C` ディレクトリに移動します。内容は次のとおりです。

<Frame>
  ![Illustrations related to C and C\+\+ sample code](/images/developers/camera-sdk-linux-examples-c-and-c-sample-code.avif)
</Frame>

9 つのフォルダーと 1 つの `CMakeLists` ファイルがあり、各フォルダーには CPP ファイルが含まれます。

各 CPP の主な機能は次のとおりです。

- `application_obstacle`: カメラストリームを取得し、障害物回避アルゴリズムを有効にして結果を出力します。
- `application_pallet`: カメラストリームを取得し、パレットアルゴリズムを有効にして結果を出力します。
- `arm_local_camera`: カメラ上の SDK \[ARM\] を呼び出し、ストリームデータを取得します。
- `frame_callback`: コールバック方式でカメラストリームデータを取得します。
- `multi_cameras`: 複数のカメラを開き、ストリームデータを取得します。
- `single_camera`: 1 台のカメラを開き、ストリームデータを取得します。
- `single_camera2`: 構造体を介してフレームデータを取得します。

用途に応じて、テストおよび変更するサンプルコードを選択してください。

## サンプルをコンパイルして実行する

### 4.1 C および C\+\+ サンプルコードのコンパイルと実行

サンプル内の `C` フォルダーに移動します。

<Frame>
  ![Illustrations related to compiling and running C and C\+\+ sample code](/images/developers/camera-sdk-linux-examples-compiling-and-running-c-and-c-sample-code.avif)
</Frame>

`C` フォルダーでターミナルを開き、次を実行します。

```bash
mkdir build
cd build
cmake ..
make
```

実行に成功したら、`build` フォルダーを開きます。内容は次のとおりです。

<Frame>
  ![サンプルコードとROS設定の画面](/images/developers/camera-sdk-linux-examples-compiling-and-running-c-and-c-sample-code-2.avif)
</Frame>

実行ファイルは `bin` ディレクトリにあります。内容は次のとおりです。

<Frame>
  ![サンプルコードとROS設定の画面](/images/developers/camera-sdk-linux-examples-compiling-and-running-c-and-c-sample-code-3.avif)
</Frame>

`arm` サンプルを除くすべてのサンプルがビルドされます。実行ファイル名はサンプルフォルダー名と同じで、直接実行できます。

### 4.2 Javaサンプルの実行手順

Javaサンプルはソースコードを直接提供せず、HTTPサーバーとPostmanサンプルを提供します。HTTP経由でカメラを制御する場合は、`java` フォルダーを使用します。内容は次のとおりです。

<Frame>
  ![サンプルコードとROS設定の画面](/images/developers/camera-sdk-linux-examples-the-java-sample-running-process.avif)
</Frame>

実行手順は次のとおりです。

- `config` フォルダーで `Configs.json` の `http_sever_host` と `http_sever_port` を変更します。

<Frame>
  ![サンプルコードとROS設定の画面](/images/developers/camera-sdk-linux-examples-java-sample-running-process-2.avif)
</Frame>

- `middleware` フォルダーで `start.sh` を実行し、転送サーバーを起動します。

<Frame>
  ![サンプルコードとROS設定の画面](/images/developers/camera-sdk-linux-examples-the-java-sample-running-process-3.avif)
</Frame>

- Postmanで `LxCamera.postman_collection.json` を開き、サンプルのポートへデータを送信します。

### 4.4 ROS2サンプルコードのビルドと実行

`ros2` フォルダーを開きます。内容は次のとおりです。

<Frame>
  ![サンプルコードとROS設定の画面](/images/developers/camera-sdk-linux-examples-compiling-and-running-ros2-sample-code.avif)
</Frame>

ROSサンプルノードは `colcon` でビルドします。

まず、ビルドツールをインストールします。

```bash
sudo apt install python3-colcon-common-extensions
```

<Frame>
  ![サンプルコードとROS設定の画面](/images/developers/camera-sdk-linux-examples-compiling-and-running-ros2-sample-code-2.avif)
</Frame>

次に `ros-pcl` 依存パッケージをインストールします。`foxy` は使用中のROS 2ディストリビューションに置き換えてください。

```bash
sudo apt-get install ros-foxy-pcl*
```

インストール後、`lx_camera_node_ws` ディレクトリでプロジェクトをビルドします。

```bash
colcon build
```

コンピューター性能により、ビルドには通常30〜120秒かかります。成功すると次のように表示されます。

<Frame>
  ![サンプルコードとROS設定の画面](/images/developers/camera-sdk-linux-examples-compiling-and-running-ros2-sample-code-3.avif)
</Frame>

一部の警告はバージョン互換性によるもので、対応不要です。ビルド後のフォルダー内容は次のとおりです。

<Frame>
  ![サンプルコードとROS設定の画面](/images/developers/camera-sdk-linux-examples-compiling-and-running-ros2-sample-code-4.avif)
</Frame>

次のコマンドで環境を読み込み、`ros2 launch` でノードを起動します。

source install/setup.bash
ros2 launch lx_camera_ros lx_camera_ros_launch.py
ros2 launch lx_camera_ros obstacleV2.launch.py
ros2 launch lx_camera_ros obstacle.launch.py

### 5.2 java

JavaサンプルはHTTPサーバーのみを提供するため、ここではインターフェースとメッセージ形式を説明します。Postmanでサンプルファイルを開きます。

<Frame>
  ![サンプルコードとROS設定の画面](/images/developers/camera-sdk-linux-examples-java.avif)
</Frame>

メッセージはすべてPOST方式です。送信前にIPアドレスをサーバーIPへ変更してください。URLはサーバーにハードコードされているため変更しません。応答メッセージの形式と内容は `body` に含まれます。

<Frame>
  ![サンプルコードとROS設定の画面](/images/developers/camera-sdk-linux-examples-java-2.avif)
</Frame>

1. `DcGetApiVersion`：SDKのバージョン番号を取得します。入力パラメータはありません。

<Frame>
  ![サンプルコードとROS設定の画面](/images/developers/camera-sdk-linux-examples-java-3.avif)
</Frame>

2. `DcSetInfoOutput`：SDKログの出力先を設定します。パラメータは次のとおりです。

- `log_path`：ログの出力先パスです。
- `print_level`：ログ出力レベルです。
- `enable_screen_print`：コンソールへログを出力するかを指定します。

3. `DcLog`：SDKログへ出力します。入力内容はSDKログに記録されます。
4. `DcGetDeviceList`：デバイス一覧を取得します。入力パラメータはなく、結果はJSONで返されます。
5. `DcOpenDevice`：デバイスを開きます。次の値を入力します。

<Frame>

### 5.3 ROS1 & ROS2

ROSではドライバーソースコードではなく、launchファイルの設定、設定の調整、メッセージの送受信を扱います。提供されるROSノードには主要機能が含まれるため、ソースコードを直接変更することは推奨しません。特別な要件がある場合は、先にC\+\+サンプルのコードフローを確認してください。

**ROSドライバーを実行する前に、システム既定パス上のOpenCVおよびPCLのバージョンが一意であることを確認してください。複数バージョンがあるとROSライブラリのリンクでエラーが発生し、ビルド失敗や実行時クラッシュの原因になります。**

## 付録

この付録では、いくつかのツールのインストール方法を説明します。手順を実行するには、Linux の基礎知識が必要です。PC ごとに環境が異なるため、ここで示す手順ですべての環境に正常にインストールできることを保証するものではありません。ここに記載されていない問題が発生した場合は、原因と解決方法を個別に調査してください。

### 1. 指定バージョンの CMake をインストールする

[CMake のダウンロードページ](https://cmake.org/download/)から必要なバージョンを取得します。ダウンロードしたパッケージを `tar -zxvf cmake-XXX.tar.gz` で展開し、展開先のディレクトリでコンパイルと設定を実行します。

./bootstrap

make

sudo make install

次のコマンドで CMake のバージョンを確認し、インストールが完了したことを確認します。

cmake --version

### 2. 指定バージョンの OpenCV をインストールする

1. [OpenCV Releases](https://opencv.org/releases/ "Releases-OpenCV")から必要なバージョンをダウンロードします。

<Frame>
  ![指定バージョンの OpenCV をインストールする画面](/images/developers/camera-sdk-linux-examples-the-installation-method-of-the-specified-version-of-opencv.avif)
</Frame>

2. 環境を準備します。次のコマンドを順に実行します。

sudo apt-get install build-essential

sudo apt-getinstallcmake gitlibgtk2.0-devpkg-config libavcodec-dev

libavformat-dev libswscale-dev

sudo apt-get install python-dev python-numpy libtbb2 libtbb-dev libjpeg-dev

libpng-dev libtiff-dev libjasper-dev libdc1394-22-dev

3. `opencv` ディレクトリを作成し、ダウンロードしたソースコードをそのディレクトリに展開します。
4. 次のコマンドを順に実行します。
5.   cd opencv
6.   mkdir build && cd build
7.   sudocmake-DCMAKE\_BUILD\_TYPE=Release-D
8.   CMAKE\_INSTALL\_PREFIX=/usr/local ..
9.   sudo make -j4
10. `sudo make install` を実行し、インストールが完了するまで待ちます。

### 3. 指定バージョンの PCL をインストールする

1. インストール可能な PCL のバージョンを確認します。

apt-cache madison libpcl-dev

2. 指定した PCL バージョンをインストールします。`1.10.0` は必要なバージョン番号に置き換えてください。

sudo apt-get install libpcl-dev=1.10.0

### 7. ROS2 でテストパッケージを作成する

colcon build

source install/setup.bash
