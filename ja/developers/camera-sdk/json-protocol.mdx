## 概要

カメラはTCP Socketサーバーとして動作し、既定ではポート`5501`で待ち受けます。メッセージはテキスト形式です。ASCIIを使用でき、JSONエンコードを推奨します。

<Info>
  ロボットまたはPLCから3Dビジョンタスクをトリガーし、カメラから返される結果を読み取る場合にこのプロトコルを使用します。
</Info>

## リクエストメッセージ

次のメッセージを送信して3Dビジョンタスクをトリガーします。

```json
{"action":"3D"}
```

## レスポンスメッセージ

カメラの処理完了後、JSONオブジェクトが返されます。

<ResponseField name="result" type="integer" required>
  検出ステータス。`0`はローカライゼーション失敗または結果なしを示します。その他の整数は成功を示し、返される結果数を表します。
</ResponseField>

<ResponseField name="pos" type="number[]" required>
  オブジェクト姿勢の配列。各結果にはロボット座標系の`X`、`Y`、`Z`、`RX`、`RY`、`RZ`が含まれます。位置の単位はmm、角度の単位は°で、`−180° ≤ RZ ≤ 180°`です。検出に失敗した場合、すべての値は`0`になります。
</ResponseField>

### レスポンス例

<Tabs>
  <Tab title="成功">

  <Tab title="失敗">

  </Tab>
