LxCameraViewerはカメラの検索と接続、画像と点群の表示、カメラパラメータの設定、アプリケーションアルゴリズムの保守ツールを提供します。

<Info>
  完全版PDFマニュアル：[LxCameraViewerユーザーマニュアル](https://pub-f1dc758884b94eaba9d8c5d3d7575b62.r2.dev/docs/pdf/lxcameraviewer_user_manual.pdf)。
</Info>

## 概要

LxCameraViewerはMRDVS Camera SDKをベースとし、WindowsとLinuxに対応します。深度、強度、点群、RGB画像の表示・保存、カメラおよびアプリケーションアルゴリズムのパラメータ読出し・設定、IP設定、パケットキャプチャ、通信、ネットワークカード設定ツールへのアクセスに使用します。

## インストールとネットワーク設定

### 推奨システム構成

| 構成項目 | Windows | Linux |
| --- | --- | --- |
| オペレーティングシステム | Windows 10（64ビット）またはWindows 11（64ビット） | Ubuntu（64ビット） |
| メモリ | 4 GB以上 | 4 GB以上 |
| ネットワークアダプターとケーブル | ギガビットEthernet以上 | ギガビットEthernet以上 |

### IPアドレスとゲートウェイの設定

カメラは固定IPアドレスを使用します。既定IPアドレスは `192.168.100.82` で、既定ゲートウェイは空欄にできます。サブネットマスクはWindowsで `255.255.0.0`、Linuxで `255.255.255.0` を使用します。

カメラに接続するホストコンピューターのEthernetアダプターを `192.168.100.x` に設定します。`x` は `3`～`254` の任意の数値で、カメラIPと重複してはいけません。たとえばカメラIPが `192.168.100.12` の場合、ホストIPは `192.168.100.89` に設定します。

### ソフトウェア画面の概要

#### カメラを開く前

初期画面には次の領域があります。

- **List panel**：デバイス一覧、現在の情報、デバイス情報。

- メニューバーをダブルクリックするとウィンドウを最大化または復元できます。メニューバーをドラッグしてウィンドウを移動します。

#### 画像ストリーム制御

- \[Start/stop flow\]：デバイスのストリームを開始または停止します。
- \[Single Save\]：有効なストリームデータの画像を保存します。

  - たとえば図2では深度画像と点群画像のみが保存されます。RGB画像と強度画像は有効でないため保存されません。
  - 深度・強度画像の拡張子は `.pgm`、RGB画像は `.png`、点群画像は `.pcd` です。
  - 保存される深度、強度、点群画像は疑似カラーを付加しない元画像です。
  - 連続保存のため複数回クリックできますが、連続保存は最大3回です。
- \[Depth Map\]：深度マップを表示（有効化）するかを指定します。
- \[Intensity graph\]：強度マップを表示（有効化）するかを指定します。
- \[Point Cloud\]：点群画像を表示（有効化）するかを指定します。
- \[RGB\]：RGB画像を有効化するかを指定します。
- RGB／強度マップの選択を解除すると、デバイスはRGB／強度画像の取得を停止します。深度データの取得は、深度マップと点群マップを同時に無効にした場合にのみ停止します。
- 図2では、デバイスがストリーミングを開始し、深度、点群、RGB、強度の各画像を表示しています。
- 図3では、デバイスがストリーミングを停止し、画像は表示されません。

#### 画像データ

- カメラ温度を表示します（図4の赤枠）。
- 深度マップ選択時に深度マップのフレームレートを表示します（図4の緑枠）。
- 強度マップ選択時に強度マップのフレームレートを表示します（図4の青枠）。
- RGB画像選択時にRGB画像のフレームレートを表示します（図4の赤紫枠）。
- RGB画像選択時に、選択したRGB画素の値を表示します（図4の黒枠）。
- 深度マップ選択時に、選択した深度画素の値を表示します（図4の黄枠）。
- 強度マップ選択時に、選択した強度画素の値を表示します（図4の橙枠）。
- 点群マップ選択時に、深度画像で選択した画素に対応する点群値を表示します（図4の紫枠）。
- 画素を選択していない場合は、既定で `(0,0)` の画素が選択されます。
- フレームレートが12を超える場合は背景が緑、6を超えて12未満の場合は橙、6未満の場合は赤になります。

##### 画像表示設定

- \[カメラモデルを表示\]：点群画像にカメラモデルを表示（図4）または非表示（図5）にします。
- \[疑似カラーを表示\]：点群に深度の疑似カラーを表示します。RGBアライメントを有効にするとRGBカラーを表示します。
- \[点群表示を安定化\]：一部のコンピューターで適応処理により点群が消える場合、点群表示を安定させます。
- \[強制画像同期\]：画面上の深度マップと点群マップの最小深度を変更します。カメラ出力は変わりません。
- \[干渉フレームを保持\]：画面上の深度マップと点群マップの最大深度を変更します。カメラ出力は変わりません。

## トラブルシューティング

|  |  |
| --- | --- |
| 問題 | 対処方法 |
| カメラが見つからない | 電源が接続され、電源投入後に前面の青色LEDが点灯していることを確認します。IPアドレスとサブネットマスク、ホストPCのネットワークアクセス制限も確認してください。 |
| カメラは開けるがストリーミングに失敗する | ホストPCでソフトウェアを管理者権限で起動していることを確認してください。 |
| 画像が遅延する | ネットワークカード、ケーブル、スイッチがギガビット対応であることを確認してください。RGBアライメント有効時は100 Mbpsネットワークで遅延が発生する場合があります。 |
| カメラが頻繁に再接続する | 工場出荷時設定への復元、ファームウェア更新、または100 Mbpsネットワークでの初回起動後は、約30秒間カメラが調整または再起動します。安定するまでホストPCは接続を試行します。 |
| 深度データまたは点群データがない | カメラが遮られていないこと、対象物が撮影範囲内にあること、深度の最小値・最大値とフィルターパラメータが正しいことを確認してください。 |
| 点群が消え、画面に白い枠だけが表示される | 点群画像をクリックし、`m` キーを押して点群安定化を有効にしてください。 |
| 点群表示が異常 | 点群のショートカットキーが操作されていないか確認し、点群安定化を有効にしてください。 |
| Linuxでカメラを開いても点群が表示されない | 点群画像をマウスでクリックしてドラッグしてください。 |
| 「VTKの読込みに失敗し、点群は表示されません」と表示される | GPU性能が不足していないか、グラフィックスドライバーが正常に動作しているか確認してください。点群表示には専用ビデオメモリを持つGPUとそのドライバーが必要です。 |
