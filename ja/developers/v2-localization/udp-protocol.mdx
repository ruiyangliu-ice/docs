V2 ProはUDP経由でクライアントと制御データおよびローカライゼーションデータを交換します。Webホストアプリケーションで、`portName`に対象デバイスのIPアドレス、`portCode`に待受ポートを設定します。V2 Proはポート`8001`で受信メッセージを待ち受けます。

## メッセージ規約

| 項目 | 規約 |
| --- | --- |
| バイト順序 | ビッグエンディアン：上位バイトが下位バイトに先行します。 |
| フレーム構成 | ヘッダー、長さ、コマンド、データ、チェックサム。 |
| チェックサム | 1バイト。ヘッダーとチェックサム自身を除く全バイトのXOR。 |
| 長さフィールド | ヘッダーとチェックサムを含みません。一部のメッセージには長さフィールドがありません。 |
| マップ名 | ASCII英字、数字、アンダースコアのみ使用可能で、先頭文字は英字にする必要があります。 |

<Note>
  バイト番号はByte 0から始まります。複数バイトの整数はすべてビッグエンディアンです。
</Note>

## V2 Proが受信するメッセージ

### オドメトリ

| バイト範囲 | 内容 |
| --- | --- |
| Byte 0–1 | ヘッダー：AC ED |
| Byte 2 | 長さ：Length |
| Byte 3 | コマンド：0x0A |
| Byte 4–7 | V3 V2 V1 V0、4バイト整数の速度 |
| Byte 8–11 | Theta3 Theta2 Theta1 Theta0、4バイト整数の角度 |
| Byte 12 | チェックサム |

速度`v`の単位はmm/sです。角度`theta`の単位は0.01°で、たとえば90°は9000として送信します。

### 再ローカライゼーション

| バイト範囲 | 内容 |
| --- | --- |
| Byte 0–1 | ヘッダー：AC ED |
| Byte 2 | 長さ：Length |
| Byte 3 | コマンド：0x02 |
| Byte 4–7 | X3 X2 X1 X0、4バイト整数のX座標 |
| Byte 8–11 | Y3 Y2 Y1 Y0、4バイト整数のY座標 |
| Byte 12–15 | Theta3 Theta2 Theta1 Theta0、4バイト整数の角度 |
| Byte 16 | チェックサム |

`x`と`y`の単位はmmです。`theta`の単位は0.01°で、たとえば90°は9000として送信します。

### マッピングの開始または停止

| バイト範囲 | 内容 |
| --- | --- |
| Byte 0–1 | ヘッダー：AC ED |
| Byte 2 | 長さ：Length |
| Byte 3 | コマンド：0x02 |
| Byte 4 | ステータス：0x01で開始、0x00で停止 |
| Byte 5–34 | マップ名、固定30バイトASCII。未使用バイトは0x00でパディング |
| Byte 35 | チェックサム |

開始コマンドはマッピングタスクごとに1回だけ送信します。繰り返し送信しないでください。

### マップを切り替える

| バイト範囲 | 内容 |
| --- | --- |
| Byte 0–1 | ヘッダー：AC ED |
| Byte 2 | 長さ：Length |
| Byte 3 | コマンド：0x0C |
| Byte 4–33 | マップ名、固定30バイトASCII。未使用バイトは0x00でパディング |
| Byte 34 | チェックサム |

コマンドを送信する前に、対象マップが作成済みであることを確認してください。

## V2 Proが送信するメッセージ

### ローカライゼーション結果

| バイト範囲 | 内容 |
| --- | --- |
| Byte 0–1 | ヘッダー：AC ED |
| Byte 2 | 長さ：Length |
| Byte 3 | コマンド：0x01 |
| Byte 4–7 | X3 X2 X1 X0、X座標 |
| Byte 8–11 | Y3 Y2 Y1 Y0、Y座標 |
| Byte 12–15 | Theta3 Theta2 Theta1 Theta0、方位 |
| Byte 16–23 | Timestamp7からTimestamp0、タイムスタンプ |
| Byte 24 | チェックサム |

`X`と`Y`の単位はmmです。`THETA`の単位は0.001 radです。再ローカライゼーションに成功すると、V2 Proはこのメッセージを継続的に送信します。

### タスク結果

マッピング開始、マッピング停止、マップ切り替えの各コマンドは、次のメッセージでステータスを返します。

| バイト | 内容 |
| --- | --- |
| Byte 0–1 | ヘッダー：AC ED |
| Byte 2 | 長さ：Length |
| Byte 3 | コマンド：0xFF |
| Byte 4 | タスクID |
| Byte 5 | ステータス：0x01は成功、0x00は失敗 |
| Byte 6 | チェックサム |

| タスクID | 操作 |
| --- | --- |
| 0x01 | マッピング開始 |
| 0x02 | マッピング停止 |
| 0x03 | マップ切り替え |

<Info>
  マッピングの停止には時間がかかることがあります。完了までの時間は通常、データ収集時間のおよそ3分の1です。次の操作を始める前に、タスク結果メッセージを待ってください。
</Info>
