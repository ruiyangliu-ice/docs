手動フォークリフトの運用は、しばしばドライバーの経験に依存します。一方、保管ロケーションの記録は現場の状態に追従できないことがあります。走行効率、ロケーション状態、狭い通路での安全は、倉庫管理における一般的な課題です。

## ソリューションアーキテクチャ

このソリューションは、手動フォークリフトの自己位置推定システムと保管ロケーション状態システムを組み合わせます。前者はフォークリフトの位置と姿勢を、後者は占有状態と荷物状態を提供します。両方のデータストリームを上位システムへ送信し、タスク配車と荷物追跡に使用できます。

## 手動フォークリフトの自己位置推定

フォークリフト上部に 3D ビジョンカメラを搭載します。システムは IMU の補助により、天井や壁面の自然特徴を使って自己位置を推定します。プロジェクト記録では位置決め精度は **1～5 cm** とされています。実際の精度は、現場特徴、設置条件、キャリブレーションに依存します。

  ![手動フォークリフトのビジョン自己位置推定システム](/images/solutions/warehouse-forklift-localization-and-bin-detection-solution.avif)

システムは、付近の人、車両、潜在的なリスクをドライバーに通知でき、立入制限区域を設定することもできます。自己位置推定結果をロケーション状態と組み合わせれば、荷物の配置を記録し、タスクルートの調整にも利用できます。

## 保管ロケーション状態認識

RGB-D カメラが 3D 情報と色情報を取得し、ロケーション内の荷物の有無、配置状態、占有異常を判定します。必要に応じてアルゴリズムは荷物カテゴリを識別でき、カメラ側の結果を配車システムへ送信できます。

| 機能 | 説明 |
| --- | --- |
| 3D 監視 | 深度データと色情報を組み合わせてロケーション状態を判定します。 |
| カメラ内処理 | 外部産業用コンピューターの必要性を低減します。 |
| 通信統合 | TCP/IP、UDP、HTTP に対応し、JSON を出力します。 |
| 配車連携 | タスク割り当てにリアルタイムのロケーション情報を提供します。 |

## 連携ワークフロー

1. 自己位置推定システムが、フォークリフトの位置と姿勢を継続的に出力します。
2. ロケーションカメラが、対象ロケーションの占有状態と荷物状態を報告します。
3. 上位システムが車両、荷物、ロケーションのデータを関連付け、ピックアップおよび配置タスクを確認して荷物位置を記録します。
4. ロケーションまたは車両の状態が変化した場合、上位システムはタスクルートとリソース配分を更新できます。
