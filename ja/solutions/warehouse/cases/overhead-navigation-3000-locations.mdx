## プロジェクトの背景

大手受託製造企業が運営する床置き倉庫には、**3,000\+** の保管ロケーションがあります。商品とパレットが頻繁に移動するため、固定的な基準がほとんどありません。顧客は床面への QR コード設置も望んでいませんでした。無人フォークリフトは、通路内の人や段ボールなど、低い障害物および頭上の障害物を検出する必要があります。

## 技術選定

荷物位置が頻繁に変化する場所や、広いオープンスペースで安定した特徴が少ない場所では、変化する輪郭や基準不足によりレーザー SLAM が影響を受ける場合があります。このため、プロジェクトでは Bluebotics の Visual SLAM 無人フォークリフトに、MRDVS のビジョン自己位置推定、パレットドッキング、3D ビジョン障害物回避を統合しました。

## ソリューションの構成要素

| モジュール | 機能 |
| --- | --- |
| Visual SLAM 自己位置推定 | 深度カメラがマーカーのない 3D 環境データを取得し、ロボットの自己位置推定とナビゲーションに使用します。プロジェクト記録では、代表的な地点到達精度は **±1 cm** とされています。 |
| パレットドッキング | 点群データからパレットのずれを算出し、フォークリフトの姿勢とフォーク方向の調整を誘導します。 |
| 3D ビジョン障害物回避 | 視野内の低い障害物および頭上の障害物を検出し、走行用の環境情報を提供します。 |

<Info>
  実際の自己位置推定精度と稼働性能は、現場構造、環境変化、設置条件、キャリブレーションに依存します。導入前に必ず現地でシステムを検証してください。
</Info>
