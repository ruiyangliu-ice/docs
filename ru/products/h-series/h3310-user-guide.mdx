## Термины и принцип работы

### Основные термины

| Термин | Описание |
| --- | --- |
| База | Горизонтальное расстояние между оптическими центрами двух стереоскопических блоков формирования изображения. |
| Глубина | Данные, представляющие расстояние от каждого пикселя до камеры. |
| FOV | Поле зрения, включая горизонтальный, вертикальный и диагональный углы. |
| IR-камера | Камера для формирования изображений в ближнем инфракрасном диапазоне. |
| RGB-камера | Камера для формирования цветных изображений. |
| Камера глубины | Система формирования изображений, которая выдаёт данные глубины и обычно включает блоки проецирования, формирования изображения и обработки глубины. |
| SoC | Система на кристалле для обработки изображений, вычисления глубины и выполнения прикладных алгоритмов. |

## Обзор продукта

H3310 — промышленная RGB-D камера со структурированным светом массой 400 г. Её можно установить на составного робота или небольшой роботизированный манипулятор. В рабочем диапазоне 300–600 мм камера выдаёт высокоточные данные глубины и RGB, а также предоставляет встроенную вычислительную платформу для прикладных алгоритмов.

<Frame>
  ![Камера H3310](/images/products/h-series-h3310-user-guide-h3310-camera.avif)
</Frame>

### Возможности

- Встроенная вычислительная платформа производительностью 6,0 TOPS для прикладных алгоритмов.
- Вывод изображений глубины, RGB и амплитуды.
- Открытые интерфейсы для интеграции с роботизированными манипуляторами и мобильными роботами.

## Часто задаваемые вопросы

<AccordionGroup>
  <Accordion title="Хост-приложение не может открыть камеру">
    Убедитесь, что брандмауэр хоста не блокирует подключение, затем проверьте питание камеры и сетевое соединение.
  </Accordion>

  <Accordion title="В списке устройств отображается несколько IP-адресов">
    В локальной сети может находиться несколько доступных для обнаружения устройств. Выберите IP-адрес целевой камеры.
  </Accordion>

  <Accordion title="Поток данных нестабилен">
    Используйте кабель Gigabit Ethernet. Сеть со скоростью 100 Мбит/с может привести к начальной нестабильности потока.
  </Accordion>

  <Accordion title="Программа не запускается после установки">
    Если программа установлена в каталог с ограниченным доступом, проверьте разрешения на доступ к файлам и запуск программ.
  </Accordion>
</AccordionGroup>
