## Обзор продукта

### Назначение и область применения

В этом документе описаны спецификации камеры S10 и отдельные конструктивные особенности для разработчиков, которые интегрируют и используют продукт.

### Терминология

| RGB-D камера | Камера, которая выдаёт синхронизированные и пространственно выровненные изображения RGB и глубины |
| --- | --- |
| Глубина | Видеопоток, аналогичный цветному или монохромному потоку, где каждый пиксель представляет расстояние до камеры |
| FOV | Поле зрения: угловой диапазон сцены, захватываемой камерой, включая горизонтальное (HFOV), вертикальное (VFOV) и диагональное (DFOV) поля зрения |
| ИК-камера | Инфракрасная камера; в этом продукте она в основном захватывает ближний инфракрасный диапазон |
| RGB-камера | Цветная камера |
| Камера глубины | Камера, модуль глубины которой обычно включает точечный проектор, ИК-камеру и процессор глубины; её цветовой модуль обычно является RGB-камерой |
| SoC | Система на кристалле, используемая для обработки изображений, вычисления глубины и прикладных алгоритмов |
| dToF | Технология измерения глубины по прямому времени пролёта |

### Принцип работы

Этот продукт представляет собой dToF 3D-камеру глубины с большой дальностью, высокой точностью, устойчивостью к помехам и стабильными данными. Встроенный модуль RGB захватывает цветные изображения. Камера выполняет внутреннее выравнивание изображений RGB и глубины.

### Сведения о продукте

Эта компактная промышленная RGB-D камера предоставляет данные глубины на расстояниях от 0.3m до 8m. Она выполняет пространственное и временное выравнивание изображений RGB и глубины. Встроенный SoC выводит данные глубины, интенсивности, RGB, облака точек и результаты обнаружения препятствий. Помимо Ethernet, два входа IO и два выхода IO переключаются между четырьмя зонами обнаружения препятствий и выдают сигналы аварийной остановки, замедления и безопасного состояния.

## Первое использование

### Проверка подключения

1. Подключите камеру к источнику постоянного тока 24V/2A. Медленно мигающий синий индикатор питания подтверждает нормальное включение.
2. Подключите камеру к компьютеру кабелем Ethernet категории 6.
3. IP-адрес камеры по умолчанию — 192.168.100.82.
4. Настройте IP-адрес компьютера в подсети камеры и отключите брандмауэр компьютера.
5. Запустите хост-программное обеспечение для просмотра изображений камеры.
6. Обратитесь в отдел продаж или техническую поддержку MRDVS, чтобы получить хост-программное обеспечение.

### Подключение I/O

| Интерфейс | Тип | Примечания |
| --- | --- | --- |
| IN1 | Вход | Дискретный вход с активным высоким уровнем; поддерживает 24V/разомкнутый вход |
| IN2 | Вход | Дискретный вход с активным высоким уровнем; поддерживает 24V/разомкнутый вход |
| OUT1 | Выход | Дискретный выход на землю/разомкнутый; поддерживает подтяжку к 24V |
| OUT2 | Выход | Дискретный выход на землю/разомкнутый; поддерживает подтяжку к 24V |
| COM | GND | Общий провод дискретных выходов; используйте IN1 с IN\_COM1 |

### Устранение неисправностей

| № | Проблема | Решение |
| --- | --- | --- |
| 1 | Камера не отвечает при открытии | Убедитесь, что брандмауэр отключён |
| 2 | Хост-программное обеспечение обнаруживает несколько IP-адресов | Другое устройство в локальной сети использует тот же IP-адрес; выберите нужный IP-адрес |
| 3 | Данные камеры нестабильны после открытия | Используйте кабель Gigabit Ethernet; первоначально данные могут быть нестабильными через Fast Ethernet |
| 4 | Место установки программного обеспечения | На настройки разрешений может повлиять установка по умолчанию на диске C |
