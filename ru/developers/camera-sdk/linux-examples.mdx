## Обзор

Camera SDK MRDVS для Linux включает примеры на C/C\+\+, Java (HTTP-сервис), ROS и ROS 2. Примеры показывают базовый рабочий процесс SDK; добавьте логику приложения и обработку ошибок, необходимые для вашего проекта.

Сначала завершите настройку среды, выполните установочный скрипт и проверьте каталоги примеров. Затем следуйте разделу компиляции и запуска для нужного языка. В приложении приведены способы установки распространённых зависимостей и тестовых пакетов.

#### 3.2.1 Примеры кода C и C\+\+

Перейдите в каталог C. Его содержимое выглядит следующим образом:

<Frame>
  ![Illustrations related to C and C\+\+ sample code](/images/developers/camera-sdk-linux-examples-c-and-c-sample-code.avif)

Каталог содержит 9 папок и один файл CMakeLists; в каждой папке находится файл cpp.

Основные функции каждого файла cpp следующие:

- application\_obstacle: получение данных потока камеры, включение алгоритма объезда препятствий и вывод результатов алгоритма;
- application\_pallet: получение данных потока камеры, включение алгоритма паллет и вывод результатов алгоритма;
- arm\_local\_camera: вызов SDK на камере \[ARM\] и получение данных потока;
- frame\_callback: получение данных потока камеры с помощью callback-функции;
- multi\_cameras: открытие нескольких камер и получение потоковых данных;
- single\_camera: открытие одной камеры и получение потоковых данных;
- single\_camera2: получение данных кадра через структуру.

Выбирайте разные примеры кода для тестирования и изменения в зависимости от задачи.

## Компиляция и запуск примеров

### 4.1 Компиляция и запуск примеров C и C\+\+

Перейдите в папку C в каталоге примера:

<Frame>
  ![Illustrations related to compiling and running C and C\+\+ sample code](/images/developers/camera-sdk-linux-examples-compiling-and-running-c-and-c-sample-code.avif)
</Frame>

Откройте терминал в папке C и выполните:

```bash
mkdir build
cd build

```

После успешного выполнения перейдите в папку build. Её содержимое должно выглядеть следующим образом:

<Frame>
  ![Illustrations related to compiling and running C and C\+\+ sample code 2](/images/developers/camera-sdk-linux-examples-compiling-and-running-c-and-c-sample-code-2.avif)
</Frame>

Исполняемый файл находится в каталоге bin. После перехода в каталог bin должно отображаться следующее:

<Frame>
  ![Illustrations related to compiling and running C and C\+\+ sample code 3](/images/developers/camera-sdk-linux-examples-compiling-and-running-c-and-c-sample-code-3.avif)

Будут скомпилированы все примеры, кроме примера arm. Имя исполняемого файла совпадает с именем папки примера, поэтому его можно запустить напрямую.

Пример Java отличается от других примеров. Он не содержит исходный код напрямую, а предоставляет HTTP-сервер и пример Postman. Если нужно косвенно управлять камерой через HTTP, выберите пример Java и перейдите в папку java. Её содержимое выглядит следующим образом:

<Frame>
  ![Illustrations related to the java sample running process](/images/developers/camera-sdk-linux-examples-the-java-sample-running-process.avif)
</Frame>

Процесс запуска выглядит следующим образом:

- Перейдите в папку config и измените поля http\_sever\_host и http\_sever\_port в файле Configs.json:

<Frame>
  ![Illustrations related to java sample running process 2](/images/developers/camera-sdk-linux-examples-java-sample-running-process-2.avif)
</Frame>

- Перейдите в папку middleware и выполните скрипт start.sh, чтобы включить сервер передачи данных.

<Frame>
  ![Illustrations related to the java sample running process 3](/images/developers/camera-sdk-linux-examples-the-java-sample-running-process-3.avif)
</Frame>

- Откройте файл LxCamera.postman\_collection.json в Postman и отправьте данные на порт примера.

  ![Illustrations related to compiling and running ROS sample code 3](/images/developers/camera-sdk-linux-examples-compiling-and-running-ros-sample-code-3.avif)

### 4.4 Компиляция и запуск примера ROS 2

Перейдите в папку ros2. Её содержимое выглядит следующим образом:

<Frame>
  ![Illustrations related to compiling and running ROS2 sample code](/images/developers/camera-sdk-linux-examples-compiling-and-running-ros2-sample-code.avif)
</Frame>

Пример узла ROS компилируется с помощью colcon.

Сначала установите инструменты компиляции:

```bash
sudo apt install python3-colcon-common-extensions
```

<Frame>
  ![Illustrations related to compiling and running ROS2 sample code 2](/images/developers/camera-sdk-linux-examples-compiling-and-running-ros2-sample-code-2.avif)
</Frame>

Затем установите пакет зависимости `ros-pcl`. Замените `foxy` на дистрибутив ROS 2, установленный в вашей системе:

```bash
sudo apt-get install ros-foxy-pcl*
```

После установки перейдите в каталог `lx_camera_node_ws` и соберите проект:

```bash
colcon build
```

В зависимости от производительности компьютера компиляция обычно занимает от 30 до 120 секунд. После успешной компиляции отобразится следующее:

<Frame>
  ![Illustrations related to compiling and running ROS2 sample code 3](/images/developers/camera-sdk-linux-examples-compiling-and-running-ros2-sample-code-3.avif)
</Frame>

Некоторые предупреждения вызваны проблемами совместимости версий и не требуют обработки. После завершения компиляции содержимое папки выглядит следующим образом:

<Frame>
  ![Illustrations related to compiling and running ROS2 sample code 4](/images/developers/camera-sdk-linux-examples-compiling-and-running-ros2-sample-code-4.avif)
</Frame>

Выполните следующие команды, чтобы загрузить среду и запустить узел с помощью `ros2 launch`:

```bash
source install/setup.bash
ros2 launch lx_camera_ros lx_camera_ros_launch.py
ros2 launch lx_camera_ros obstacleV2.launch.py
ros2 launch lx_camera_ros obstacle.launch.py
ros2 launch lx_camera_ros pallet.launch.py
```

Сверху вниз показаны: запуск обычных узлов, запуск двух узлов алгоритма объезда препятствий, запуск узлов алгоритма объезда препятствий и запуск узлов алгоритма паллет. Одновременно можно включить только один узел.

### 5.3 ROS 1 и ROS 2

В описании ROS рассматриваются не исходный код драйвера, а параметры конфигурации в launch-файле, их настройка, а также отправка и подписка на сообщения. Предоставленный узел ROS уже содержит большинство функций, поэтому напрямую изменять исходный код драйвера не рекомендуется. При особых требованиях сначала изучите поток выполнения в примере C\+\+, а затем изменяйте исходный код драйвера.

**При запуске драйвера ROS убедитесь, что в системном пути по умолчанию присутствует только одна версия OpenCV и PCL. В противном случае при связывании библиотеки ROS возникнет ошибка, которая может привести к сбою компиляции или аварийному завершению во время выполнения.**

## Appendix

This appendix provides installation methods for some tools. When using these methods, you need to have at least some basic knowledge of Linux. There is no guarantee that every computer can be successfully installed through the methods shown in the appendix of this document. The environment of each computer is different, and the problems encountered may not be consistent. If you encounter problems not shown in this appendix, please search for solutions yourself.

### 1. Cmake specified version installation method

Go to [https://cmake.org/download/](https://cmake.org/download/) and download the required CMake version. Extract the downloaded package with `tar -zxvf cmake-XXX.tar.gz`. Enter the extracted directory, then compile and configure it:

./bootstrap

make

sudo make install

Check the Cmake version to see if the installation is successful:

cmake --version
