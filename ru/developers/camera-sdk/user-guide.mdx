## Обзор

Это руководство предназначено для разработчиков, интегрирующих камеры. В нем описаны API Camera SDK для продуктов M4, M4 Mega, M4 Pro, V1 Pro, S2, S2 Max и H3 Series. SDK работает в системах Windows x86 и Linux x86 или Arm.

Camera SDK предоставляет унифицированные API для доступа к устройству и настройки параметров. SDK поддерживает синхронный и асинхронный сбор данных глубины, интенсивности, облака точек и RGB. Некоторые модели камер также предоставляют данные для объезда препятствий, стыковки или локализации.

<Info>
  Примеры и описания API основаны на версии SDK, поставляемой с продуктом. Доступные параметры могут различаться в зависимости от продукта, версии прошивки и версии SDK.
</Info>

Примеры предназначены для помощи при разработке и могут не охватывать все устройства и сценарии использования.

#### Настройка сети

1. Сетевой сегмент IP-адресов камеры по умолчанию: 192.168.100.\*
2. На хост-компьютере задайте для сетевого порта, подключенного к камере, адрес из сегмента 192.168.100.x и убедитесь, что он не конфликтует с устройством. Маска подсети — 255.255.255.0, как показано на рисунке ниже:

<Frame>
  ![Иллюстрации, относящиеся к настройке сетевой среды](/images/developers/camera-sdk-user-guide-network-environment-construction.avif)
</Frame>

3. При подключении к камере рекомендуется отключить брандмауэр, чтобы хост с SDK не перехватывал пакеты данных камеры, как показано на следующем рисунке:

<Frame>
  ![Иллюстрации, относящиеся к настройке сетевой среды 2](/images/developers/camera-sdk-user-guide-network-environment-construction-2.avif)

4. Настройка сети в Linux аналогична настройке в Windows. Команды управления брандмауэром зависят от дистрибутива. В Ubuntu выполните:

```bash
sudo systemctl stop ufw.service
sudo systemctl disable ufw.service
sudo ufw status
```

##### Linux

1. Распакуйте пакет и запустите скрипт установки:

```bash
tar xvf Lanxin-MRDVS-xxx.tar.gz
cd Lanxin-MRDVS
sudo su root
chmod +x install.sh
./install.sh
```

Скрипт установки размещает SDK в `/opt/Lanxin-MRDVS` и задает переменные среды для текущего пользователя. Если программа запускается от имени другого пользователя, повторно выполните скрипт для этого пользователя или добавьте следующую строку в его `~/.bashrc`:

```bash
export LD_LIBRARY_PATH=/opt/Lanxin-MRDVS/lib/:$LD_LIBRARY_PATH
```

Для сеансов терминала, открытых до установки, перед запуском программы выполните следующую команду:

```bash
source ~/.bashrc
```

## Требования к вызовам

### Типы параметров и соответствующие API

1. Для перечислений с префиксом LX\_INT используйте DcSetIntValue или DcGetIntValue для задания или получения параметров типа INT.
2. Для перечислений с префиксом LX\_FLOAT используйте DcSetFloatValue или DcGetFloatValue для задания или получения параметров типа FLOAT.
3. Для перечислений с префиксом LX\_BOOL используйте DcSetBoolValue или DcGetBoolValue для задания или получения параметров типа BOOL.
4. Для перечислений с префиксом LX\_STRING используйте DcSetStringValue или DcGetStringValue для задания или получения строковых параметров.
5. Для выполнения команд перечислений с префиксом LX\_CMD используйте DcSetCmd.
6. Для перечислений с префиксом LX\_PTR используйте DcGetPtrValue для получения результатов типа указателя.

### Предварительные условия API

<Warning>
  Во время потоковой передачи или когда для `LX_INT_WORK_MODE` установлен постоянно включенный режим не задавайте перечисленные ниже функции.
</Warning>

**1. Когда поток запущен или для рабочего режима (LX\_INT\_WORK\_MODE) установлен постоянно включенный режим, нельзя задавать следующие функции:**

- LX\_INT\_2D\_BINNING\_MODE;
- LX\_BOOL\_ENABLE\_2D\_TO\_DEPTH;
- LX\_BOOL\_ENABLE\_MULTI\_EXPOSURE\_HDR;
- LX\_BOOL\_ENABLE\_MULTI\_MACHINE;

- LX\_INT\_CALCULATE\_UP;
- LX\_BOOL\_ENABLE\_HDR;
- LX\_BOOL\_ENABLE\_TOF\_DEPTH\_CALIBE;
- LX\_BOOL\_ENABLE\_SYNC\_FRAME
- LX\_INT\_SAVE\_PARAMS\_GROUP

**2. Эти параметры нельзя задавать даже при постоянно включенном рабочем режиме (LX\_INT\_WORK\_MODE):**

- LX\_INT\_TOF\_FREQMODE<br />

**3. Когда включена автоматическая экспозиция 3D (LX\_BOOL\_ENABLE\_3D\_AUTO\_EXPOSURE), нельзя выполнять следующие операции с перечислениями функций:**

- LX\_BOOL\_ENABLE\_MULTI\_EXPOSURE\_HDR ;
- LX\_INT\_FIRST\_EXPOSURE;
- LX\_INT\_SECOND\_EXPOSURE;
- LX\_INT\_THIRD\_EXPOSURE;
- LX\_INT\_GAIN;<br />

**4. Когда автоматическая экспозиция 3D (LX\_BOOL\_ENABLE\_3D\_AUTO\_EXPOSURE) выключена, нельзя выполнять следующие операции с перечислением функции:**

- LX\_INT\_3D\_AUTO\_EXPOSURE\_LEVEL

Нельзя задавать максимальное (LX\_INT\_3D\_AUTO\_EXPOSURE\_MAX) и минимальное значение автоматической экспозиции 3D

- (LX\_INT\_3D\_AUTO\_EXPOSURE\_MIN)

**5. Когда включена автоматическая экспозиция 2D (LX\_BOOL\_ENABLE\_2D\_AUTO\_EXPOSURE), нельзя выполнять следующие операции с перечислениями функций:**

- LX\_INT\_2D\_MANUAL\_EXPOSURE

<br />**6. Когда автоматическая экспозиция 2D (LX\_BOOL\_ENABLE\_2D\_AUTO\_EXPOSURE) выключена, нельзя выполнять следующие операции с перечислением функции:**

- LX\_INT\_2D\_AUTO\_EXPOSURE\_LEVEL;

<br />7.**В специальном режиме фильтрации нельзя задавать следующие параметры:**

- LX\_INT\_FILTER\_SMOOTH\_LEVEL LX\_INT\_FILTER\_NOISE\_LEVEL
- LX\_INT\_FILTER\_TIME\_LEVEL

<br />8.**Перед включением устранения искажений 2D сначала включите выравнивание RGB-D:**

- LX\_BOOL\_ENABLE\_2D\_TO\_DEPTH

<br />9.**Для устройств, не относящихся к S2, перед включением встроенного алгоритма сначала задайте алгоритм ToF. Параметры алгоритма можно задавать только при включенном встроенном алгоритме (LX\_INT\_ALGORITHM\_MODE).**

- (LX\_STRING\_ALGORITHM\_PARAMS)

<br />10.**Для получения данных облака точек (LX\_PTR\_XYZ\_DATA) сначала включите карту глубины.**

- (LX\_BOOL\_ENABLE\_3D\_DEPTH\_STREAM)
