## Обзор

Камера работает как сервер TCP Socket и по умолчанию прослушивает порт `5501`. Сообщения передаются в текстовом виде; поддерживается ASCII, рекомендуется кодировка JSON.

<Info>
  Используйте этот протокол, когда робот или ПЛК запускает задачу 3D-зрения и считывает результат, возвращаемый камерой.
</Info>

## Запрос

Для запуска задачи 3D-зрения отправьте следующее сообщение:

```json
{"action":"3D"}
```

## Ответ

После завершения работы камера возвращает объект JSON.

<ResponseField name="result" type="integer" required>
  Статус обнаружения. `0` означает ошибку локализации или отсутствие результата. Любое другое целое число означает успешное выполнение и задает количество возвращенных результатов.
</ResponseField>

<ResponseField name="pos" type="number[]" required>
  Массив поз объектов. Каждый результат содержит `X`, `Y`, `Z`, `RX`, `RY` и `RZ` в системе координат робота. Положение указано в мм, углы — в °; `−180° ≤ RZ ≤ 180°`. При ошибке обнаружения все значения равны `0`.
</ResponseField>

### Примеры ответов

<Tabs>
  <Tab title="Успешный ответ">
    ```json
    {"result":2,"pos":[100,107.3,1530,179,89,89,112,432.1,1500,179,89,75]}
    ```
  </Tab>
  <Tab title="Ошибка">
    ```json
    {"result":0,"pos":[0,0,0,0,0,0]}
    ```
  </Tab>
</Tabs>
