Визуальный 3D-объезд препятствий выполняет на камере обнаружение объектов, адаптацию к поверхности и вывод состояния препятствий. После настройки внешних параметров камеры и зон можно переключать группы параметров объезда препятствий и считывать результаты через хост-приложение, API или поддерживаемую промышленную шину.

<Info>
  Значения в этом руководстве показывают только взаимосвязи параметров конфигурации. Фактические значения зависят от транспортного средства, места установки и рабочей зоны. Перед отправкой конфигурации проверьте ее на месте.
</Info>

## Подготовка к развертыванию

### Установка камеры

| Тип транспортного средства | Рекомендации по установке |
| --- | --- |
| Underride AMR | Установите камеру на передней поверхности по направлению движения. Крепежная конструкция не должна перекрывать поле зрения. Рекомендуется S10. |
| Погрузчик | Установите камеру на мачте, направив объектив вниз примерно на `30°–55°`. Край поля зрения должен достигать передней части транспортного средства. По возможности устанавливайте камеру на высоте не более `2 m`. Рекомендуется S10. |

### Подключение камеры

<Steps>
  <Step title="Настройте сеть хоста">
    Заводской адрес камеры — `192.168.100.82`. Настройте Ethernet-адаптер компьютера в той же подсети.
  </Step>
  <Step title="Подключитесь и проверьте изображение">
    Откройте **LxCameraViewer**, найдите и откройте камеру, затем убедитесь, что карта глубины и облако точек отображаются правильно.
  </Step>
  <Step title="При необходимости измените адрес камеры">
    В разделе **Other tools → Network → IP configuration tool** измените IP-адрес. После изменения камера перезапустится. Если камера перемещается в другую подсеть, также обновите Ethernet-адрес компьютера.
  </Step>
</Steps>

<Warning>
  Не отключайте брандмауэр навсегда в производственной сети. В контролируемой сети отладки разрешите только необходимые приложения и порты в соответствии с политикой безопасности.
</Warning>

### Настройка изображения

В разделах **3D settings** и **Filter settings** проверьте качество изображения. Для устаревших конфигураций объезда препятствий в качестве начальных можно использовать высокую экспозицию `650`, низкую экспозицию `200` и порог слабого сигнала `10–20`. Для S10 обычно достаточно уровня бликов `1`. Для нестандартных установок перед развертыванием подтвердите параметры со службой технической поддержки.

## Настройка алгоритма объезда препятствий

<Steps>
  <Step title="Включите алгоритм">
    В разделе **Application algorithm** выберите постоянно включенный режим. Для S10 выберите **Obstacle avoidance algorithm**. Для других поддерживаемых моделей выберите **Obstacle avoidance algorithm 2.0**.
  </Step>
  <Step title="Выберите тип зоны">
    Выберите для транспортного средства прямоугольную или секторную зону. S10 не поддерживает секторные зоны; их использование может привести к неверным результатам.
  </Step>
  <Step title="Задайте внешние параметры и зоны">
    Сначала задайте внешние параметры камеры, затем настройте зоны объезда препятствий. После изменения внешних параметров остальные зоны используют новые значения.
  </Step>
  <Step title="Отправьте и проверьте параметры">
    Отправьте параметры, затем проверьте зоны предупреждения, тревоги и экранирования в представлении облака точек и в состоянии выхода.
  </Step>
</Steps>

### Внешние параметры камеры

| Параметр | Пример | Описание |
| --- | --: | --- |
| Roll (ось X) | `180°` | Ориентация камеры; пример для стандартной вертикальной установки. |
| Pitch (ось Y) | `90°` | Ориентация камеры; пример для стандартной вертикальной установки. |
| Yaw (ось Z) | `90°` | Ориентация камеры. |
| Положение X | `430 mm` | Положение камеры вдоль оси транспортного средства от передней части к задней. |
| Положение Y | `0 mm` | Положение камеры вдоль оси транспортного средства слева направо; `0` означает центр. |
| Положение Z | `120 mm` | Высота камеры над землей. |

Сначала задайте высоту установки, затем точно настройте roll и pitch, пока поверхность не станет горизонтальной в представлении облака точек. После завершения выберите **Send parameters**.

### Зоны объезда препятствий

| Параметр | Пример | Назначение |
| --- | --: | --- |
| Расстояние предупреждения (дальний X) | `2000 mm` | Расстояние, за пределами которого зона считается свободной; интервал до расстояния тревоги — зона предупреждения/замедления. |
| Расстояние тревоги (средний X) | `1500 mm` | Интервал до расстояния экранирования — зона тревоги/остановки. |
| Расстояние экранирования (ближний X) | `600 mm` | Ближняя мертвая зона; препятствия в этой зоне исключаются из объезда препятствий. |
| Диапазон слева / справа (Y) | `−810 / 1270 mm` | Пределы обнаружения по обе стороны от центральной линии транспортного средства. |
| Нижняя / верхняя высота (Z) | `10 / 1500 mm` | Диапазон высот, включенный в обнаружение. |

<Tip>
  Значения X отсчитываются относительно центра транспортного средства. При расчете фактического расстояния защиты также учитывайте смещение камеры по X, например вычитайте продольное смещение камеры из расстояния предупреждения.
</Tip>

Количество поддерживаемых групп зон зависит от способа переключения:

| Способ переключения | Поддерживаемые группы |
| --- | --: |
| S2 / S2 Max 2.0 I/O | `0–3` |
| SDK, UDP, RS485 или CAN | `0–19` (зависит от модели) |

Сохраните проверенные значения в `Tools\\params\\<camera ID>\\avoidance.json`. Этот файл можно применить к другому транспортному средству того же типа с помощью **Load configuration from file**.

## Связь и вывод состояния

Перед использованием промышленной шины или сетевого протокола настройте зоны объезда препятствий и внешние параметры в хост-приложении. За исключением API, большинство способов связи переключают группы параметров; для подробной настройки параметров используйте хост-приложение или API.

| Камера | Поддерживаемая связь |
| --- | --- |
| S2 | API, UDP, I/O |
| S2 Max | API, UDP, CAN |
| S2 Max 2.0 | API, UDP, I/O, CAN |
| M4 Pro | API, UDP, RS485 |
| M4 | API, UDP, CAN |
| M4 Mega | API, UDP, I/O, CAN |

<Note>
  I/O имеет наивысший приоритет. Пока активен I/O, другие способы не могут изменить текущую группу параметров, но могут обновлять параметры по умолчанию или временные параметры. Хост-приложение и API задают параметры по умолчанию; UDP, CAN и RS485 обычно задают временные параметры. Поведение после отключения питания зависит от способа сохранения последней конфигурации.
</Note>

### API

Приложения Windows, Linux и ARM могут вызывать API объезда препятствий через SDK. После установки хост-приложения Windows SDK и примеры доступны в его каталоге установки. Пример объезда препятствий находится в `Sample\\C\\application_obstacled`. Для S10 не переключайте группы параметров через API с высокой частотой; вместо этого используйте UDP или I/O.

### RS485 (только M4 Pro)

Используйте Modbus RTU с рекомендуемой скоростью `9600`. Считайте два входных регистра, начиная с адреса `108` (`0x6C`), с кодом функции `0x04`, чтобы получить текущий результат объезда препятствий. Запишите один регистр по адресу `106` (`0x6A`) с кодом функции `0x06`, чтобы переключить группы параметров.

| Контакт | Сигнал | Цвет провода |
| --: | --- | --- |
| 1 | GND | Blue |
| 2 | RS485\_A | Gray |
| 3 | RS485\_B | White |
| 4 | VIN\+ | Brown |
| 5 | VIN− | Black |

### UDP и TCP

Сообщения отправляются в виде шестнадцатеричных кадров. Для UDP сначала отправьте сообщение установления соединения. После установления соединения камера отправляет результаты с частотой кадров изображения.

| Направление | Кадр | Значение |
| --- | --- | --- |
| Камера → контроллер | `ACED0410XX000000` | Препятствий нет; `XX` — текущая группа параметров. |
| Камера → контроллер | `ACED0410XX000001` | Предупреждение/замедление. |
| Камера → контроллер | `ACED0410XX000002` | Тревога/остановка. |
| Контроллер → камера (UDP) | `ACED040000000000` | Установить UDP-соединение. |
| Контроллер → камера | `ACED041A00000000` to `ACED041A00000013` | Переключить группу параметров `0–19`. |
| Контроллер → камера | `ACED041B00000000` | Сохранить текущую группу как группу по умолчанию. |

Удаленный порт UDP по умолчанию — `6688`. Переключение параметров требует времени загрузки; не переключайте их слишком быстро, так как это может снизить частоту кадров изображения и частоту обновления результатов.

### CAN и I/O

CAN может переключать группы параметров на поддерживаемых моделях. Выходы I/O сообщают о состоянии свободной зоны, замедления и аварийной остановки. Тип выхода может быть push-pull или open-drain; перед подключением уточните тип входа контроллера.

| Push-pull OUT1 | Push-pull OUT2 | Состояние |
| --- | --- | --- |
| `24 V` | `24 V` | Препятствий нет |
| `24 V` | `0 V` | Замедление |
| `0 V` | `24 V` | Аварийная остановка |
| `0 V` | `0 V` | Отключено, выполняется инициализация или обнаружена ошибка |

<Warning>
  Для S10 подключите `24 V−` к силовой земле контроллера, а `IN_G` и `OUT_G` — к сигнальной земле контроллера. Если контроллер не различает эти две земли, используйте утвержденную на объекте схему общей земли. Уточните, использует ли контроллер сигналы PNP или NPN, и проверьте подключение мультиметром.
</Warning>

## Устранение неполадок

| Симптом | Проверки |
| --- | --- |
| Черные или плохо отражающие объекты не обнаруживаются | Проверьте покрытие облаком точек; отрегулируйте время интегрирования и порог слабого сигнала. При необходимости добавьте отражающую поверхность на черный наконечник вилы. |
| Низкие объекты не запускают обнаружение | Проверьте нижний предел Z; для проверки временно задайте `0`. Если обнаружение по-прежнему не выполняется, проверьте высоту установки и покрытие облаком точек. |
| Параметры не применяются | Убедитесь, что параметры были отправлены. Проверьте их допустимость, сетевое соединение и приоритет группы параметров. |
| Аномальные данные | Проверьте наличие препятствий в крепежной конструкции, защитной пленки на объективе или дополнительного защитного стекла. |
