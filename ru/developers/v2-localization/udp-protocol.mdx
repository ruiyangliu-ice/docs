V2 Pro обменивается с клиентом данными управления и локализации по протоколу UDP. В веб-хост-приложении задайте для `portName` IP-адрес целевого устройства, а для `portCode` — порт прослушивания. V2 Pro принимает входящие сообщения на порту `8001`.

## Формат сообщений

| Элемент | Правило |
| --- | --- |
| Порядок байтов | Big-endian: старший байт расположен перед младшим. |
| Структура кадра | Заголовок, длина, команда, данные и контрольная сумма. |
| Контрольная сумма | Один байт. Примените XOR ко всем байтам, кроме заголовка и самой контрольной суммы. |
| Поле длины | Не включает заголовок и контрольную сумму. Некоторые сообщения не содержат поля длины. |
| Имя карты | Только буквы ASCII, цифры и символы подчёркивания; первый символ должен быть буквой. |

<Note>
  Нумерация байтов начинается с Byte 0. Для всех многоразрядных целых чисел используется порядок big-endian.
</Note>

## Сообщения, получаемые V2 Pro

### Одометрия

| Диапазон байтов | Содержимое |
| --- | --- |
| Byte 0–1 | Заголовок: AC ED |
| Byte 2 | Длина: Length |
| Byte 3 | Команда: 0x0A |
| Byte 4–7 | V3 V2 V1 V0, 4-байтовое целое значение скорости |
| Byte 8–11 | Theta3 Theta2 Theta1 Theta0, 4-байтовое целое значение угла |
| Byte 12 | Контрольная сумма |

Скорость `v` указывается в мм/с. Угол `theta` указывается в сотых долях градуса; например, угол 90° передаётся как 9000.

### Релокация

| Диапазон байтов | Содержимое |
| --- | --- |
| Byte 0–1 | Заголовок: AC ED |
| Byte 2 | Длина: Length |
| Byte 3 | Команда: 0x02 |
| Byte 4–7 | X3 X2 X1 X0, 4-байтовое целое значение координаты X |
| Byte 8–11 | Y3 Y2 Y1 Y0, 4-байтовое целое значение координаты Y |
| Byte 12–15 | Theta3 Theta2 Theta1 Theta0, 4-байтовое целое значение угла |
| Byte 16 | Контрольная сумма |

`x` и `y` указываются в мм. `theta` указывается в сотых долях градуса; например, угол 90° передаётся как 9000.

### Запуск или остановка построения карты

| Диапазон байтов | Содержимое |
| --- | --- |
| Byte 0–1 | Заголовок: AC ED |
| Byte 2 | Длина: Length |
| Byte 3 | Команда: 0x02 |
| Byte 4 | Состояние: 0x01 запускает построение карты; 0x00 останавливает построение карты |
| Byte 5–34 | Имя карты, фиксированное поле ASCII длиной 30 байт; незадействованные байты заполняются значением 0x00 |
| Byte 35 | Контрольная сумма |

Отправляйте команду запуска один раз для каждой задачи построения карты. Не отправляйте её повторно.

### Переключение карт

| Диапазон байтов | Содержимое |
| --- | --- |
| Byte 0–1 | Заголовок: AC ED |
| Byte 2 | Длина: Length |
| Byte 3 | Команда: 0x0C |
| Byte 4–33 | Имя карты, фиксированное поле ASCII длиной 30 байт; незадействованные байты заполняются значением 0x00 |
| Byte 34 | Контрольная сумма |

Перед отправкой команды убедитесь, что целевая карта построена.

## Сообщения, отправляемые V2 Pro

### Результат локализации

| Диапазон байтов | Содержимое |
| --- | --- |
| Byte 0–1 | Заголовок: AC ED |
| Byte 2 | Длина: Length |
| Byte 3 | Команда: 0x01 |
| Byte 4–7 | X3 X2 X1 X0, координата X |
| Byte 8–11 | Y3 Y2 Y1 Y0, координата Y |
| Byte 12–15 | Theta3 Theta2 Theta1 Theta0, ориентация |
| Byte 16–23 | Timestamp7–Timestamp0, временная метка |
| Byte 24 | Контрольная сумма |

`X` и `Y` указываются в мм. `THETA` указывается в тысячных долях радиана. После успешной релокации V2 Pro непрерывно отправляет это сообщение.

### Результат задачи

Команды запуска и остановки построения карты, а также переключения карты возвращают состояние в следующем сообщении.

| Byte | Содержимое |
| --- | --- |
| Byte 0–1 | Заголовок: AC ED |
| Byte 2 | Длина: Length |
| Byte 3 | Команда: 0xFF |
| Byte 4 | Идентификатор задачи |
| Byte 5 | Состояние: 0x01 — успех; 0x00 — ошибка |
| Byte 6 | Контрольная сумма |

| Идентификатор задачи | Операция |
| --- | --- |
| 0x01 | Запуск построения карты |
| 0x02 | Остановка построения карты |
| 0x03 | Переключение карты |

<Info>
  Остановка построения карты может занять некоторое время. Обычно она занимает около трети времени сбора данных. Дождитесь сообщения с результатом задачи, прежде чем запускать другую операцию.
</Info>
