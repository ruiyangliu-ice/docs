На этой странице описан веб-интерфейс V2 в режиме только локализации. Перед построением или переключением карт, а также перед повторной локализацией убедитесь, что транспортное средство, камера и LiDAR работают нормально.

<Warning>
  Переключение карт, обновление прошивки и перезапуск встроенного приложения влияют на службы локализации. Выполняйте эти операции только при остановленном транспортном средстве, в безопасной рабочей зоне и при наличии процедуры восстановления.
</Warning>

## Обзор интерфейса

| Область | Содержимое |
| --- | --- |
| Строка меню | Функции построения карт, повторной локализации, управления картами и обслуживания. |
| Область карты | Загруженная 2D-карта контуров и значок локализации транспортного средства. |
| Область RGB | Изображение RGB в реальном времени с камеры верхнего обзора. |
| Область состояния | Уровень сигнала повторной локализации, координаты транспортного средства, скорость и координаты курсора. Качество сигнала отображается от лучшего к худшему зелёным, синим и красным цветами. |

## Построение карты

### Создание карты

<Steps>
  <Step title="Начало построения карты">
    В веб-интерфейсе нажмите **Start Mapping**.

    <Frame>
      ![Кнопка Start Mapping в интерфейсе V2 в режиме только локализации](/images/developers/v2-localization-pure-localization-guide-1-starting-to-build-a-map.avif)
    </Frame>
  </Step>
  <Step title="Ввод имени карты">
    Имя карты может содержать только буквы, цифры и символы подчёркивания и должно начинаться с буквы.

    <Columns cols={2}>
      <Frame>
        ![Диалог ввода имени карты](/images/developers/v2-localization-pure-localization-guide-1-starting-mapping-2.avif)
      </Frame>

      <Frame>
        ![Страница построения карты](/images/developers/v2-localization-pure-localization-guide-1-starting-mapping-3.avif)
      </Frame>
    </Columns>
  </Step>
  <Step title="Съёмка области и остановка построения карты">
    Проведите AGV по целевой области. После завершения съёмки нажмите **Stop Mapping** и дождитесь окончания обработки. Время обработки зависит от размера отснятой области.
  </Step>
  <Step title="Подтверждение карты">
    После успешного построения откройте **Map Management** и убедитесь, что новая карта появилась в списке.
  </Step>
</Steps>

### Инкрементальное построение карты

Используйте инкрементальное построение, чтобы добавить область к существующей карте. Перед началом выполните повторную локализацию и переключитесь на карту, которую нужно расширить.

<Info>
  Инкрементальное построение запускается и останавливается вручную HTTP-запросом по адресу [http://192.168.100.201:9998/tool/rob/sendCMD](http://192.168.100.201:9998/tool/rob/sendCMD).
</Info>

<Tabs>
  <Tab title="Запуск инкрементального построения карты">
    ```json
    {
      "cmd": 904,
      "attach": {
        "sub_command": 0,
        "param": ""
      }
    }
    ```
  </Tab>
  <Tab title="Остановка инкрементального построения карты">
    ```json
    {
      "cmd": 905,
      "attach": {
        "sub_command": 0,
        "param": ""
      }
    }
    ```
  </Tab>
</Tabs>

После завершения операции новая отснятая область записывается в текущую карту. Перезапустите службу локализации, чтобы изменения вступили в силу.

</Frame>

## Повторная локализация

### Ручная повторная локализация

Нажмите **Relocalization**, затем перетащите указатель в области карты, чтобы задать приблизительную позу транспортного средства и совместить облако точек LiDAR с картой контуров. После успешной повторной локализации ошибка **Localization timeout** исчезнет.

<Frame>
  ![Ручная повторная локализация в интерфейсе V2 в режиме только локализации](/images/developers/v2-localization-pure-localization-guide-3-relocation.avif)
</Frame>

### Повторная локализация по AprilTag

При построении карты можно размещать AprilTag в выбранных местах. Когда метка полностью попадает в поле зрения устройства, система определяет её карту и позу, при необходимости переключает карту и автоматически выполняет повторную локализацию.

- Создавайте метки с помощью [генератора AprilTag](https://chaitanyantr.github.io/apriltag).
- Идентификаторы меток должны быть уникальными в пределах видимой области устройства.
- Используйте фиксированное семейство меток, показанное в примере интерфейса.

<Frame>
  ![Настройка повторной локализации по AprilTag](/images/developers/v2-localization-pure-localization-guide-3-relocation-2.avif)
</Frame>

## Обслуживание

### Обновление прошивки

Импортируйте локальный пакет прошивки на странице обновления, чтобы обновить прошивку шасси, исполнительного механизма или камеры. Пакет восстановления содержит версию до предыдущего обновления и может использоваться для отката.

<Warning>
  Откат прошивки камеры, обновлённой стандартным способом через хост-компьютер, невозможен. Перед обновлением проверьте пакет и текущую версию.
</Warning>
