이 가이드는 MRDVS 사람 감지, 보관 위치 감지 및 체적 감지 알고리즘의 배포, 캘리브레이션, 구성 및 결과 통합을 다룹니다. 알고리즘은 카메라에서 실행되며, 알고리즘 호스트 애플리케이션은 구성, 업그레이드 및 결과 확인에 사용됩니다.

<Info>
  알고리즘 펌웨어와 알고리즘 호스트 애플리케이션은 프로젝트별로 제공됩니다. 알고리즘 펌웨어를 플래시하기 전에 카메라가 MDS 펌웨어 버전을 실행 중인지 확인하세요. 프로젝트와 카메라 모델에 맞는 설치 패키지를 사용하세요.
</Info>

## 지원 범위

### 시스템 구성 요소

| 구성 요소 | 기능 |
| --- | --- |
| 3D camera | RGB 이미지와 포인트 클라우드를 캡처하고 카메라에서 감지 알고리즘을 실행합니다. |
| 알고리즘 host application | 알고리즘을 구성하고 외부 파라미터를 캘리브레이션하며 결과를 표시하고 알고리즘 펌웨어를 업그레이드합니다. |
| Industrial PC or upper-layer system | 호스트 애플리케이션을 실행하거나 네트워크 인터페이스를 통해 결과를 읽습니다. |
| LiDAR | `mid360`이며 기존 레이더 기반 솔루션 구성에 사용됩니다. |

## 하드웨어 및 네트워크 배포

### 카메라 설치

용도 a rigid bracket to prevent movement or vibration after installation. 사람 감지 normally uses a horizontal installation or an installation with an angle of no more than 30°.

<Frame>
  ![카메라 브래킷 설치 예시](/images/developers/deployment-algorithm-detection-camera-installation-methods.avif)
</Frame>

### 장치 연결

<Steps>
  <Step title="전원 및 네트워크 연결">
    안정화된 24 V DC 전원으로 카메라에 전원을 공급하세요. Cat6A 또는 Cat7 케이블로 카메라를 기가비트 스위치나 컨트롤러에 연결하세요.
  </Step>
  <Step title="여러 카메라 배포">
    각 카메라를 CAD 계획에 지정된 높이와 위치에 설치하세요. 모든 카메라를 기가비트 스위치를 통해 연결하고 각각의 전원 및 링크 상태를 확인하세요.
  </Step>
  <Step title="테스트 대상 준비">
    외부 파라미터를 캘리브레이션하고 영역을 구성하기 전에 감지할 사람, 팔레트 또는 화물을 카메라 화면에 배치하세요.
  </Step>
</Steps>

### 호스트 네트워크 구성

호스트 컴퓨터와 카메라를 같은 서브넷에 연결하세요. 원래 예제에서는 다음 구성을 사용합니다.

| 항목 | 예시 |
| --- | --- |
| 호스트 IP 주소 | `192.168.100.xxx` |
| 서브넷 마스크 | `255.255.255.0` |
| 기본 게이트웨이 | `192.168.100.1` |

<Steps>
  <Step title="어댑터 설정 열기">
    Windows에서 **Control Panel → Network and Sharing Center → Change adapter settings** 를 열고 카메라에 연결된 Ethernet 어댑터를 선택하세요.
  </Step>
  <Step title="IPv4 구성">
    **Internet 프로토콜 Version 4 (TCP/IPv4)** 를 열고 **용도 the following IP address** 를 선택한 다음 카메라 서브넷의 사용하지 않는 고정 주소를 입력하세요.
  </Step>
  <Step title="연결 확인">
    설정을 저장하고 기가비트 링크를 확인한 뒤 호스트 애플리케이션으로 카메라를 검색하거나 여세요.
  </Step>
</Steps>

</Warning>

## 소프트웨어 설치 및 업그레이드

### 호스트 애플리케이션 설치

1. Obtain the camera host application from the [software downloads](https://zcnt5g3o2989.feishu.cn/wiki/Q8IYwGiGaiIvIyktiavczymanOe?from=from_copylink "Software downloads") page.
2. 카메라 설치 host application outside the system drive.
3. 프로젝트에서 제공한 알고리즘 호스트 애플리케이션 파일을 카메라 호스트 애플리케이션 디렉터리 아래의 `Tools` 폴더에 복사하세요. 같은 이름의 파일을 교체한 다음 실행 파일을 두 번 클릭하여 시작하세요.

<Frame>
  ![카메라 호스트 애플리케이션 설치](/images/developers/deployment-algorithm-detection-picture-2.avif)
</Frame>

알고리즘 호스트 애플리케이션만 업그레이드하려면 해당 `.exe` 파일을 제공된 버전으로 교체하세요.

### 알고리즘 펌웨어 업그레이드

<Warning>
  플래시하는 동안 카메라가 재시작됩니다. 전원이나 네트워크를 분리하거나 호스트 애플리케이션을 닫지 마세요. 패키지는 카메라 모델, MDS 펌웨어 버전 및 프로젝트 알고리즘과 일치해야 합니다.
</Warning>

<Tabs>
  <Tab title="카메라 호스트 애플리케이션">
    1. Start `LxCameraViewer.exe` and open the camera.
    2. Select **기본 도구 → 기능 settings → Firmware upgrade**.
    3. Choose the delivered detection algorithm file and select **Run**.
  </Tab>
  <Tab title="알고리즘 host application">
    1. Select the target camera in the device list.
    2. Select **Upgrade firmware**, choose the detection algorithm file, and open it.
    3. Wait for the camera to appear in the device list again.
  </Tab>
</Tabs>

재부팅 후 카메라가 다시 표시되면 플래시가 완료된 것입니다. 알고리즘 호스트 애플리케이션에서 카메라 배경이 녹색이면 카메라가 연결되고 알고리즘을 사용할 수 있다는 뜻입니다.

## 알고리즘 host application

### 시작 및 상태

`LxApplicationViewer.exe`를 시작하세요. 장치 목록의 녹색 아이콘은 연결된 카메라를 나타냅니다. 장치를 선택하여 현재 보기를 RGB 모드와 포인트 클라우드 모드 사이에서 전환하세요. 일반 사용자는 결과를 볼 수 있고 관리자는 카메라 및 알고리즘 파라미터를 수정할 수 있습니다.

<Frame>
  ![알고리즘 host application main window](/images/developers/deployment-algorithm-detection-administrator.avif)
</Frame>

### 기본 도구

| 기능 | Description |
| --- | --- |
| 용도r switching | 권한 수준을 전환합니다. 관리자는 카메라 및 알고리즘 파라미터를 구성할 수 있습니다. |
| Ideal ground | 기준 수평면을 표시하거나 숨깁니다. |
| Extrinsic ground | 외부 파라미터 캘리브레이션으로 계산한 지면을 표시하거나 숨깁니다. |
| Display cache | 변경하지 않습니다. |
| Display algorithm | 현재 활성화된 알고리즘을 표시합니다. |
| Export saved images | 저장된 이미지를 내보냅니다. |
| Historical playback | RGB 이미지와 ToF 데이터 로그를 확인합니다. |
| Switch application algorithm | 실행할 알고리즘을 선택한 다음 **Save and send** 를 선택합니다. |
| Display detection results | 현재 알고리즘의 출력을 표시합니다. |

### 상태 표시줄 및 재생

| 기능 | Description |
| --- | --- |
| RGB | RGB 이미지를 표시합니다. |
| Point cloud | 포인트 클라우드를 표시합니다. |
| Stop algorithm | 현재 알고리즘을 중지합니다. 카메라 전원을 다시 켤 때까지 자동으로 재시작되지 않습니다. |
| Upgrade firmware | 알고리즘 펌웨어 업그레이드 절차를 엽니다. |
| Restart camera | 선택한 카메라를 재시작합니다. |

상태가 변경되면 소프트웨어가 RGB 프레임 하나와 포인트 클라우드 데이터를 저장합니다. 재생 데이터는 알고리즘 간에 공유되지 않습니다. 재생 시간에는 호스트 컴퓨터의 시스템 시간이 아니라 카메라 내부 시계가 사용됩니다.

장치 배경이 노란색이거나 녹색인데도 이미지가 업데이트되지 않으면 자동 새로 고침을 활성화하여 이미지 수집을 재개하세요.

## 외부 파라미터 캘리브레이션

### 카메라 구성

| 구성 | Description |
| --- | --- |
| Camera name | 여러 카메라를 배포한 환경에서 카메라를 식별합니다. |
| Simulation mode | 내부 기능이므로 비활성화 상태로 두세요. |
| Image-save mode | 알고리즘 이미지 데이터를 카메라에 저장합니다. |
| Image-acquisition mode | `MDS`는 카메라 액세스를 점유하지 않습니다. `SDK`는 점유하므로 알고리즘 실행 중에는 호스트 애플리케이션에서 카메라를 열 수 없습니다. |
| `x`, `y`, `z` | 카메라 외부 파라미터 위치입니다. `z`는 지면에서 카메라까지의 높이입니다. |
| `roll`, `pitch`, `yaw` | 카메라 외부 파라미터 방향 각도입니다. |
| Ideal ground | 기본값을 유지합니다. |
| Read configuration from camera | 현재 카메라 구성을 읽습니다. |
| Save and send | 변경 사항을 카메라에 기록합니다. 저장하지 않은 파라미터는 적용되지 않습니다. |
| 외부 파라미터 캘리브레이션 | 카메라 높이와 방향을 캘리브레이션합니다. |

<Tabs>
  <Tab title="수직 설치">
    1. Open **카메라 구성**. Before calibration, set `x`, `y`, `z`, `roll`, `pitch`, and `yaw` to `0`, then select **Save and send**.
    2. Select **외부 파라미터 캘리브레이션**. After calibration succeeds, verify the result in the parameter panel.

    <Frame>
      ![외부 파라미터 캘리브레이션 for a vertical installation](/images/developers/deployment-algorithm-detection-vertical-installation-of-external-parameter-calibration.avif)
    </Frame>
  </Tab>
  <Tab title="수평 설치">
    1. Open **카메라 구성** and enter the parameter-calibration page.
    2. 포인트 클라우드의 지면을 좌표계에 맞추세요. 빨간색 `X`축과 녹색 `Y`축은 지면에 놓고 파란색 `Z`축은 지면에 수직으로 위를 향하게 합니다.
    3. 일반적으로 먼저 `roll`과 `z`만 조정하고 나머지 값은 `0`으로 설정하세요. 확인 후 **Save and send** 를 선택합니다.

    <Frame>
      ![외부 파라미터 캘리브레이션 result for a horizontal installation](/images/developers/deployment-algorithm-detection-1.avif)
    </Frame>
  </Tab>
</Tabs>

## 알고리즘 배포

포인트 클라우드 모드로 전환하고 이미지 영역 위에서 스크롤하여 포인트 클라우드 데이터를 표시하세요.

### 사람 감지

<Steps>
  <Step title="수평 설치 캘리브레이션">
    `X`축과 `Y`축을 지면 포인트 클라우드에 맞추세요. `Z`축은 지면에 수직으로 위를 향해야 합니다.
  </Step>
  <Step title="전역 파라미터 설정">
    Open **사람 감지**. Usually only **Rotation detection** needs to be set. Clockwise camera rotation supports `0°`, `90°`, `180°`, and `270°`.
  </Step>
  <Step title="감지 영역 생성">
    **Add detection region** 을 선택하고 최소 및 최대 `X`, `Y`, `Z`를 설정한 뒤 영역을 대상 위로 이동하세요. 원래 예제에서는 `1000 × 1000 × 2000 mm` 영역을 사용합니다.
  </Step>
  <Step title="저장 및 확인">
    **Save and send** 를 선택하고 사람이 영역을 통과하는 테스트를 수행한 다음 상태 표시줄 또는 기록 재생에서 결과를 확인하세요.
  </Step>
</Steps>

| 매칭 규칙 | 사람 없음 | 사람 | 장애물 | 사람 and obstacle |
| --- | --- | --- | --- | --- |
| 깊이만 사용 | `0` | `2` | `2` | `2` |
| 시맨틱 및 깊이 | `0` | `1` | `0` | `1` |

깊이 전용 모드는 영역의 모든 객체를 보고합니다. 시맨틱 및 깊이 모드는 사람으로 분류된 클러스터만 보고합니다.

### 보관 위치 감지

<Steps>
  <Step title="카메라 캘리브레이션">
    외부 파라미터 캘리브레이션 절차를 따르세요. `X`와 `Y`를 지면에 맞추고 `Z`는 수직으로 위를 향하게 유지합니다.
  </Step>
  <Step title="전역 파라미터 구성">
    현장에 맞게 **Alignment check**, **Alignment angle** 및 **Minimum point count** 를 설정하세요. 화물을 정해진 각도로 배치해야 할 때 정렬 확인을 활성화합니다.
  </Step>
  <Step title="보관 위치 생성">
    포인트 클라우드 모드에서 **Add storage location** 을 선택하고 탑뷰로 전환한 다음 `X`를 눌러 그리기를 시작하거나 중지하세요. 팔레트 위로 사각형을 드래그하고 `X`, `Y`, `Z` 경계를 조정합니다. 다시 `X`를 눌러 그리기 모드를 종료하세요.
  </Step>
  <Step title="저장 및 확인">
    Select **Save and send**. 2D RGB 또는 3D 포인트 클라우드 모드에서 위치를 구성하고 상태 표시줄의 `Result`를 확인하세요.
  </Step>
</Steps>

### 체적 감지

<Steps>
  <Step title="수직 설치 캘리브레이션">

  <Step title="최소 크기 및 영역 설정">
    작은 대상을 필터링하도록 최소 `X`, `Y`, `Z` 값을 설정하세요. 그런 다음 감지 평면과 화물 크기에 따라 영역 경계를 설정합니다.
  </Step>
  <Step title="저장 및 확인">
    **Save and send** 를 선택하고 영역에 하나 이상의 객체를 배치한 뒤 반환된 길이, 너비, 높이 및 개수를 확인하세요.
  </Step>
</Steps>

### Modbus TCP(보관 위치 감지)

결과는 보관 위치 ID 순서로 정렬되며 최대 처음 16개 위치가 반환됩니다.

| 구성 | 값 |
| --- | --- |
| 포트 | `16502` |
| 수신 주소 | `0.0.0.0` (all network interfaces) |
| 레지스터 수 | `16` |
| 시작 주소 | `0x0100` |
| Byte order | 빅 엔디안 |

| 레지스터 | Content | 데이터 형식 |
| --- | --- | --- |
| `0x0100 + ID` | 보관 위치 및 마커 감지 결과 | 2-byte `uint16_t` |
| High 8 bits | 보관 위치 상태 코드 | `0–2` |
| Low 8 bits | 마커 상태 코드 | `0–2`; 이 기능은 현재 사용할 수 없으므로 보관 위치 상태 코드와 같은 의미를 가집니다. |

| 위치 상태 | 의미 | 조건 |
| --- | --- | --- |
| `0` | 비어 있음 | 화물 또는 팔레트 없음 |
| `1` | 정상적으로 점유됨 | 화물이 요구된 방식으로 배치됨 |
| `2` | 비정상적으로 점유됨 | 화물 크기 또는 위치가 요구 조건을 벗어남 |

| 마커 상태 | 의미 |
| --- | --- |
| `0` | 마커가 감지되지 않음 |
| `1` | 마커가 감지됨 |
| `2` | 마커 감지 오류 |

#### 네 번째 보관 위치 읽기

다음 예제에서는 트랜잭션 ID `0x0001`을 사용하여 주소 `0x0104`의 홀딩 레지스터 하나를 읽습니다. 응답에는 상태 `0x0002`가 포함됩니다.

```text
Request: 00 01 00 00 00 06 FF 03 01 04 00 01
Response: 00 01 00 00 00 05 FF 03 02 00 02
```

| 필드 | 요청 value | Description |
| --- | --- | --- |
| Transaction identifier | `00 01` | 클라이언트 시퀀스 번호이며 응답이 이 값과 일치해야 합니다. |
| 프로토콜 identifier | `00 00` | 고정 Modbus/TCP 값입니다. |
| Length | `00 06` | 다음 요청 필드의 바이트 수입니다. |
| Unit identifier | `FF` | 브로드캐스트 모드 또는 장치 주소입니다. |
| 기능 code | `03` | 홀딩 레지스터를 읽습니다. |
| 시작 주소 | `01 04` | `0x0100 + 4`입니다. |
| 레지스터 수 | `00 01` | 레지스터 하나를 읽습니다. |

## 문제 해결

| 증상 | 우선 확인 사항 |
| --- | --- |
| 카메라를 찾을 수 없음 | 호스트와 카메라가 같은 서브넷에 있고 네트워크 어댑터가 기가비트이며 전원과 스위치 링크가 정상인지 확인하세요. |
| 파라미터가 적용되지 않음 | 변경 후 **Save and send** 를 선택했는지 확인하세요. |
