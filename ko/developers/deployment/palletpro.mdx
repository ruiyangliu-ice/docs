PalletPro는 M Series 카메라의 팔레트 인식 및 도킹 파라미터를 구성합니다. 알고리즘은 장치에서 실행되며 PalletPro는 카메라에 연결하고 이미징을 확인하며 외부 파라미터를 캘리브레이션하고 인식 영역을 조정한 뒤 결과를 읽습니다.

<Info>
  이 가이드의 표준 팔레트 크기, 거리 및 파라미터 범위는 표준 인식 절차에만 적용됩니다. 표준이 아니거나 다리가 없거나 반사율이 높은 팔레트는 먼저 현장에서 평가하세요.
</Info>

## 배포 준비

### 표준 팔레트 및 설치 요구 사항

이 절차에서는 표준 2다리 또는 3다리 팔레트를 사용합니다. 원래 절차에서는 `1.2 m × 0.8 m` 또는 `1.2 m × 1.0 m` 팔레트를 사용합니다. 표준이 아닌 크기는 배포 전에 MRDVS와 확인하세요.

| 항목 | 요구 사항 |
| --- | --- |
| 카메라 위치 | 카메라를 두 포크 사이의 중앙에 최대한 가깝게 유지하세요. 좌우 오프셋은 `50 mm`를 초과하지 않아야 합니다. |
| 카메라 자세 | 카메라 전면이 지면에 수직이 되도록 하고 pitch와 roll을 최소화하세요. |
| 시야 | 가장 가까운 인식 거리에서 포크가 팔레트 전체를 가리지 않아야 합니다. |
| 추종 설치 | 포크와 함께 움직이도록 카메라를 포크 루트 패널에 장착하세요. |
| 하강 설치 | 포크가 완전히 내려갔을 때 포크와 함께 움직이도록 카메라를 포크 아래에 장착하세요. |

포크 길이가 `1.2 m` 이하이면 경험적 장착 높이는 `0.35–0.4 m`입니다. 더 긴 포크는 `0.4–0.8 m`를 시작 범위로 사용하세요. 최종 높이는 시야, 팔레트 다리 이미징 및 도킹 거리를 기준으로 확인하세요.

### 장비 및 소프트웨어

- 카메라에 `24 VDC` 전원을 공급하고 Cat7 Ethernet 케이블로 컴퓨터에 연결하세요.
- 권장 호스트: Windows 10 이상, Intel® Core™ i5(7세대) 이상, `8 GB` RAM, Intel® UHD Graphics 또는 그 이상의 GPU입니다.
- PalletPro를 설치할 때 C\+\+ 런타임 설치 메시지를 수락하세요. 런타임이 없으면 애플리케이션이 시작되지 않을 수 있습니다.

<Warning>
  프로젝트용으로 제공된 카메라 펌웨어와 팔레트 알고리즘 패키지만 사용하세요. 업그레이드 중 카메라가 재시작되며 장치 목록에서 일시적으로 사라집니다. 업그레이드 전에 검증된 캘리브레이션을 백업하세요.
</Warning>

## 빠른 배포

<Steps>
  <Step title="네트워크 구성 및 카메라 열기">
    컴퓨터를 `192.168.100.xxx / 255.255.255.0` 서브넷에 연결하세요. PalletPro를 시작하고 대상 카메라를 검색하여 여세요.
  </Step>
  <Step title="버전 및 이미징 확인">
    LxCameraViewer에서 애플리케이션, 카메라 펌웨어 및 팔레트 알고리즘 버전이 프로젝트 제공 버전과 일치하는지 확인하세요. 포인트 클라우드에서 팔레트 다리가 모두 보이는지 확인합니다.
  </Step>
  <Step title="초기 높이 설정">
    **파라미터 설정**에서 **Height adaptation**을 사용하여 초기값을 얻으세요. 지면 선을 기준으로 미세 조정한 다음 **파라미터 저장**를 선택합니다.
  </Step>
  <Step title="근거리 티칭 실행">
    표준 팔레트를 사용하고 주변에 장애물이 없도록 중앙에 배치하세요. 팔레트가 카메라에서 약 `1.3 m` 거리에 있을 때 **Pallet teaching (near end)**를 선택합니다.
  </Step>
  <Step title="원거리 티칭 실행">
    팔레트의 좌우 위치를 그대로 유지하세요. 팔레트가 카메라에서 약 `2.0–2.4 m` 떨어질 때까지 차량을 약 `600–1000 mm` 직선으로 후진한 다음 **Pallet teaching (far end)**를 선택합니다.
  </Step>
  <Step title="저장 및 확인">
    파라미터를 저장하고 근거리 및 원거리 위치를 반복해서 테스트하세요. X, Y, 각도 출력 및 인식 안정성을 확인합니다.
  </Step>
</Steps>

<Tip>
  원거리 티칭은 카메라 pitch를 캘리브레이션합니다. 근거리 티칭과 원거리 티칭 사이에 좌우로 이동하거나 회전하지 마세요.
</Tip>

## PalletPro 사용

### 기본 인터페이스

| 영역 | 용도 |
| --- | --- |
| 기본 작업 | 외부 파라미터 캘리브레이션, 파라미터 저장 및 카메라 작업입니다. |
| 고급 애플리케이션 | 고급 파라미터, 3D 표시 및 오프라인 테스트입니다. |
| 카메라 설정 | 카메라 검색, 열기 또는 닫기, 실시간 데이터 표시, 감지 및 투영입니다. |
| 파라미터 설정 | 카메라 이름, 설치 높이, 자세 및 설치 방법입니다. |
| 파일 가져오기 | 오프라인 테스트를 위해 캘리브레이션 파일, 단일 이미지 또는 이미지 폴더를 가져옵니다. |
| 로그 및 이미지 | 실행 로그, 버전 및 실시간 인식 결과를 확인합니다. |

### 외부 파라미터 캘리브레이션

In **기본 작업 → 외부 파라미터 캘리브레이션**, read **Calibration notes** before teaching. Use the project name and vehicle ID for the customer name. The distance from the camera optical center to the forklift rotation center is required.

| 캘리브레이션 단계 | 결과 |
| --- | --- |
| 근거리 티칭 | 장착 높이, 좌우 오프셋, heading 및 roll을 캘리브레이션합니다. |
| 원거리 티칭 | 근거리 결과를 기준으로 pitch를 캘리브레이션합니다. |
| 파라미터 저장 | 현재 캘리브레이션을 카메라로 전송합니다. |

<Frame>
  ![PalletPro 근거리 팔레트 티칭 인터페이스](/images/developers/deployment-palletpro-tray-teaching-near-end-explanation.avif)
</Frame>

### 고급 파라미터

Change only fields required by the project and select **파라미터 저장** after every change.

| Parameter | 용도 |
| --- | --- |
| `R` | 카메라 자세: pitch, heading, and roll. |
| `t` | 카메라 오프셋이며 첫 번째 값은 좌우 오프셋입니다. |
| `ground_y` | 카메라 높이이며 단위는 `mm`입니다. |
| `orientation` | 설치 방법: `0`은 정방향, `2`는 반전, `1`/`3`은 측면 장착입니다. |
| `multi_level` | 다중 팔레트 인식: `0`은 끔, `1`은 켬입니다. |
| `quad` | 4다리 팔레트 인식: `0`은 끔, `1`은 켬입니다. |
| `min_z` / `max_z` | 카메라 거리 축을 따른 유효 범위입니다. |
| `min_x` / `max_x` | 유효 수평 범위입니다. |
| `two_leg` | 2다리 팔레트 인식: `0`은 끔, `1`은 켬입니다. |

<Note>
  MRDVS의 요청이 없다면 여기에 나열되지 않은 고급 파라미터를 변경하지 마세요. 다리 너비, 빔 감지 또는 인식 영역을 조정해야 한다면 원래 구성을 보존하고 각 변경 사항을 검증하세요.
</Note>

### 오프라인 테스트 및 로그

In **고급 애플리케이션 → Offline test**, drag in:

- `pallet_settings.json` 캘리브레이션 파일
- PNG 이미지 하나 또는 결과 이미지가 들어 있는 폴더

단일 파일 테스트 또는 폴더 테스트를 선택하고 **Start detection**을 선택하세요. 로그 영역에 카메라 API, 펌웨어, 알고리즘 및 인식 결과가 표시됩니다. 문제 해결을 위해 **Camera operations**에서 소프트웨어 로그를 내보내세요.

## 통신 통합

### TCP 및 UDP

LxCameraViewer에서 **Pallet localization**을 선택하고 **Always on**으로 설정하세요. TCP 서버의 기본 포트는 `5501`, UDP의 포트는 `8000`입니다. 메시지는 빅 엔디안 바이트 순서를 사용하며 표준 프레임 길이는 `16`바이트입니다.

| 방향 | 16진수 명령 | 용도 |
| --- | --- | --- |
| Client → PalletPro | `60 04 00 00` | 인식 시작입니다. |
| Client → PalletPro | `60 04 00 01` | 인식 중지입니다. |

응답 프레임에는 반환 코드, 길이, X/Y/theta/Z 부호, 팔레트 전면 중심 X/Y, 각도 theta 및 팔레트 높이가 포함됩니다. 현재 프로토콜의 확장 바이트는 `0`으로 설정하세요.

### RS485(M4 Pro 전용)

`9600` 보드레이트와 `8N1`로 Modbus RTU를 사용하세요. 기본 Modbus 주소는 `0x17`이며 SDK를 사용하여 `1–247` 범위의 주소를 설정할 수 있습니다.

| 작업 | 함수 코드 | 레지스터 | 값 |
| --- | --- | --- | --- |
| 인식 활성화/중지 | `0x06` | `120` (`0x0078`) | `1`은 활성화, `0`은 중지 |
| 결과 읽기 | `0x04` | `122` (`0x007A`) | 레지스터 `8`개 읽기 |

결과 fields are X, Y, yaw, return value, and height, each represented by a 4-byte field.

### CANopen(M4/M4 Mega)

CAN은 `250 Kbit/s`의 표준 11비트 프레임을 사용합니다. 컨트롤러는 `COB ID 0x212`를 전송하며 `MODE CTRL`이 `0`이면 인식을 비활성화하고 `1`이면 활성화합니다. 장치는 `0x192`, `0x292`, `0x392`, `0x492`를 통해 인식 상태, 포즈, 위치, 높이 및 팔레트 크기를 반환합니다.

### Modbus TCP

이 인터페이스에는 알고리즘 버전 `0.8.1` 이상이 필요합니다. 기본 포트는 `6601`이며 모든 네트워크 인터페이스에서 수신 대기하고 레지스터 시작 주소 `0x100`을 사용합니다.

| 오프셋 | 레지스터 | 내용 |
| --: | --- | --- |
| 0 | `0x100` | 절대 반환 값이며 `0`은 인식 성공을 의미합니다. |
| 1–4 | `0x101–0x104` | X, Y, yaw 및 높이의 부호이며 `0`은 양수, `1`은 음수입니다. |
| 5–8 | `0x105–0x108` | 팔레트 전면 중심 X/Y, yaw 및 높이입니다. |
| 9 | `0x109` | 팔레트 너비입니다. |
| 10 | `0x10A` | 팔레트 다리 수입니다. |
| 11–19 | — | 예약됨 |

## 확인 및 문제 해결

### 캘리브레이션 판정

근거리와 원거리 티칭 위치 사이를 반복 주행하세요. X와 Y 오차가 `10 mm` 이내이고 누락 없이 인식이 안정적이면 캘리브레이션을 허용할 수 있습니다. 예를 들어 `x = -2000`, `y = 100`, `yaw = 2.3`은 탑뷰에서 팔레트가 카메라 광학 중심에서 `2000 mm` 떨어져 있고 오른쪽으로 `100 mm` 이동했으며 시계 반대 방향으로 `2.3°` 회전했음을 의미합니다.

### 일반 오류 코드

| 오류 코드 | 의미 | 우선 확인 |
| --: | --- | --- |
| `0` | 인식 정상 | — |
| `-1` | 이미지 데이터 없음 또는 데이터 부족 | 카메라가 이미지를 출력하는지 확인하세요. |
| `-2` / `-6` | 포인트가 너무 적거나 팔레트 다리가 감지되지 않음 | 장착 높이, 포크 자세, 장애물 및 팔레트 다리 이미징을 확인하세요. |
| `-3` | 팔레트 다리 크기가 조건을 벗어남 | 다리 너비 또는 팔레트 너비 한계를 조정하세요. |
| `-4` | 카메라 높이가 설정되지 않음 | 설치 높이를 설정하고 저장하세요. |
| `-5` | 빔 감지 오류 또는 팔레트 기울기 과다 | 빔 이미징, 플라잉 픽셀 및 도킹 거리를 확인하세요. |
| `-7` | 팔레트 다리 너비 차이가 너무 큼 | 반사체, 벽 또는 다른 객체가 가장자리 다리 이미징에 영향을 주는지 확인하세요. |
| `-8` | 팔레트 각도가 너무 큼 | 팔레트 자세를 조정하세요. |

### 인식 조건 및 현장 한계

- 표준 조건: 팔레트 너비와 길이 `800–2000 mm`, 높이 `80–200 mm`, 다리 너비 `40–200 mm`, 개구부 너비 `300–600 mm`, 빔 두께 최소 `30 mm`, 인식 거리 `1200–3000 mm`입니다.
- 팔레트 전체가 시야 안에 들어오도록 하세요. 포크, 화물 또는 주변 객체에 가려지지 않도록 합니다.
- 검은색, 저반사 및 고반사 팔레트를 현장에서 테스트하세요. 원래 테스트에서는 반사율 `5%`인 검은색 팔레트를 `2 m`에서 이미징할 수 있었습니다. 필요하면 적분 시간과 낮은 신호 임계값을 조정하세요.
- 포크를 높은 위치에서 집는 경우 가능한 한 반사체와 팔레트 다리 사이를 `200 mm` 이상 유지하세요.
- 실시간 도킹에서는 애플리케이션 계층의 결과 타임스탬프를 사용하여 데이터가 최신인지 판단하고 지연된 보정을 방지하세요.

표준이 아니거나 다리가 없는 팔레트는 MRDVS에 문의하여 평가하세요.
