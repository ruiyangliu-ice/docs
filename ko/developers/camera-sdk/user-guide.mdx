## 개요

이 가이드는 카메라 장치를 통합하는 개발자를 위한 문서입니다. M4, M4 Mega, M4 Pro, V1 Pro, S2, S2 Max 및 H3 시리즈 제품의 Camera SDK API를 설명합니다. SDK는 x86 Windows와 x86 또는 Arm Linux 시스템에서 실행됩니다.

Camera SDK는 통합된 장치 액세스 및 매개변수 구성 API를 제공합니다. 깊이, 강도, 포인트 클라우드 및 RGB 데이터를 동기 또는 비동기 방식으로 수집할 수 있습니다. 일부 카메라 모델은 장애물 회피, 도킹 또는 위치 추정 데이터도 제공합니다.

<Info>
  예제와 API 설명은 제품과 함께 제공된 SDK 버전을 기준으로 합니다. 사용할 수 있는 매개변수는 제품, 펌웨어 및 SDK 버전에 따라 다를 수 있습니다.
</Info>

예제는 개발 참고용이며 모든 장치 또는 사용 사례를 다루지는 않을 수 있습니다.

##### Linux

1. 패키지의 압축을 풀고 설치 스크립트를 실행합니다.

```bash
tar xvf Lanxin-MRDVS-xxx.tar.gz
cd Lanxin-MRDVS
sudo su root
chmod +x install.sh
./install.sh
```

설치 스크립트는 SDK를 `/opt/Lanxin-MRDVS`에 설치하고 현재 사용자의 환경 변수를 설정합니다. 다른 사용자로 프로그램을 실행하는 경우 해당 사용자로 스크립트를 다시 실행하거나 해당 사용자의 `~/.bashrc`에 다음 줄을 추가합니다.

```bash
export LD_LIBRARY_PATH=/opt/Lanxin-MRDVS/lib/:$LD_LIBRARY_PATH
```

설치 전에 열려 있던 터미널 세션에서는 프로그램을 시작하기 전에 다음 명령을 실행합니다.

```bash
source ~/.bashrc
```

## 호출 요구 사항

### 매개변수 유형 및 해당 API

1. LX\_INT 접두사가 붙은 열거형은 DcSetIntValue 또는 DcGetIntValue를 사용하여 INT 유형 매개변수를 설정하거나 가져옵니다.
2. LX\_FLOAT 접두사가 붙은 열거형은 DcSetFloatValue 또는 DcGetFloatValue를 사용하여 FLOAT 유형 매개변수를 설정하거나 가져옵니다.
3. LX\_BOOL 접두사가 붙은 열거형은 DcSetBoolValue 또는 DcGetBoolValue를 사용하여 BOOL 유형 매개변수를 설정하거나 가져옵니다.
4. LX\_STRING 접두사가 붙은 열거형은 DcSetStringValue 또는 DcGetStringValue를 사용하여 문자열 유형 매개변수를 설정하거나 가져옵니다.
5. LX\_CMD 접두사가 붙은 열거형의 명령을 실행하려면 DcSetCmd를 사용합니다.
6. LX\_PTR 접두사가 붙은 열거형의 포인터 유형 결과를 가져오려면 DcGetPtrValue를 사용합니다.

### API 사전 조건

<Warning>
  스트리밍이 활성화되어 있거나 `LX_INT_WORK_MODE`가 상시 동작 모드로 설정된 경우 아래에 나열된 기능을 설정하지 마세요.
</Warning>

**1. 스트림이 시작되었거나 작업 모드(LX\_INT\_WORK\_MODE)가 상시 동작 모드인 경우 다음 기능을 설정할 수 없습니다.**

- DcSetRoi
- LX\_INT\_3D\_BINNING\_MODE;
- LX\_INT\_2D\_BINNING\_MODE;
- LX\_BOOL\_ENABLE\_2D\_TO\_DEPTH;
- LX\_BOOL\_ENABLE\_MULTI\_EXPOSURE\_HDR;
- LX\_BOOL\_ENABLE\_MULTI\_MACHINE;
- LX\_INT\_TRIGGER\_MODE;
- LX\_INT\_CALCULATE\_UP;
- LX\_BOOL\_ENABLE\_HDR;
- LX\_BOOL\_ENABLE\_TOF\_DEPTH\_CALIBE;
- LX\_BOOL\_ENABLE\_SYNC\_FRAME
- LX\_INT\_SAVE\_PARAMS\_GROUP

**2. 작업 모드(LX\_INT\_WORK\_MODE)가 상시 동작 모드인 경우에도 다음 설정을 지정할 수 없습니다.**

- LX\_INT\_TOF\_FREQMODE<br />

**3. 3D 자동 노출(LX\_BOOL\_ENABLE\_3D\_AUTO\_EXPOSURE)을 켜면 다음 기능 열거형을 조작할 수 없습니다.**

- LX\_BOOL\_ENABLE\_MULTI\_EXPOSURE\_HDR ;
- LX\_INT\_FIRST\_EXPOSURE;
- LX\_INT\_SECOND\_EXPOSURE;
- LX\_INT\_THIRD\_EXPOSURE;
- LX\_INT\_GAIN;<br />

**4. 3D 자동 노출(LX\_BOOL\_ENABLE\_3D\_AUTO\_EXPOSURE)을 끄면 다음 기능 열거형을 조작할 수 없습니다.**

- LX\_INT\_3D\_AUTO\_EXPOSURE\_LEVEL

3D 자동 노출의 최대값(LX\_INT\_3D\_AUTO\_EXPOSURE\_MAX)과 최소값을 설정할 수 없습니다.

- (LX\_INT\_3D\_AUTO\_EXPOSURE\_MIN)

**5. 2D 자동 노출(LX\_BOOL\_ENABLE\_2D\_AUTO\_EXPOSURE)을 켜면 다음 기능 열거형을 조작할 수 없습니다.**

- LX\_INT\_2D\_MANUAL\_EXPOSURE

<br />**6. 2D 자동 노출(LX\_BOOL\_ENABLE\_2D\_AUTO\_EXPOSURE)을 끄면 다음 기능 열거형을 조작할 수 없습니다.**

- LX\_INT\_2D\_AUTO\_EXPOSURE\_LEVEL;

<br />7.**특수 필터링 모드에서는 다음 설정을 지정할 수 없습니다.**

- LX\_INT\_FILTER\_SMOOTH\_LEVEL LX\_INT\_FILTER\_NOISE\_LEVEL
- LX\_INT\_FILTER\_TIME\_LEVEL

<br />8.**2D 왜곡 보정을 켜려면 먼저 RGB-D 정렬을 켜야 합니다.**

- LX\_BOOL\_ENABLE\_2D\_TO\_DEPTH

<br />9.**S2 이외의 장치에서 내장 알고리즘을 켤 때는 먼저 ToF 알고리즘을 설정해야 합니다. 알고리즘 매개변수는 내장 알고리즘(LX\_INT\_ALGORITHM\_MODE)이 켜진 경우에만 설정할 수 있습니다.**

- (LX\_STRING\_ALGORITHM\_PARAMS)

<br />10.**포인트 클라우드 데이터(LX\_PTR\_XYZ\_DATA)를 가져오려면 먼저 깊이 맵을 열어야 합니다.**

- (LX\_BOOL\_ENABLE\_3D\_DEPTH\_STREAM)
