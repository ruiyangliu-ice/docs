## 개요

Linux용 MRDVS Camera SDK에는 C/C\+\+, Java(HTTP 서비스), ROS 및 ROS 2 예제가 포함되어 있습니다. 예제는 기본 SDK 작업 흐름을 보여주므로 프로젝트에 맞는 로직과 오류 처리를 추가하세요.

먼저 환경 설정, 설치 스크립트 및 샘플 디렉터리 확인을 완료하세요. 그런 다음 대상 언어의 컴파일 및 실행 섹션을 따르세요. 부록에는 일반 종속성과 테스트 패키지의 설치 방법이 정리되어 있습니다.

#### 3.2.1 C 및 C\+\+ 샘플 코드

C 디렉터리로 이동하세요. 디렉터리 내용은 다음과 같습니다.

<Frame>
  ![C 및 C\+\+ 샘플 코드 관련 그림](/images/developers/camera-sdk-linux-examples-c-and-c-sample-code.avif)
</Frame>

폴더 9개와 CMakeLists 파일 1개가 있으며 각 폴더에 cpp 파일이 들어 있습니다.

각 cpp의 주요 기능은 다음과 같습니다.

- application\_obstacle: 카메라 스트림 데이터를 가져와 장애물 회피 알고리즘을 활성화하고 알고리즘 결과를 출력합니다.
- application\_pallet: 카메라 스트림 데이터를 가져와 팔레트 알고리즘을 활성화하고 알고리즘 결과를 출력합니다.
- arm\_local\_camera: 카메라 \[ARM\]에서 SDK를 호출하고 스트림 데이터를 가져옵니다.
- frame\_callback: 콜백 방식으로 카메라 스트림 데이터를 가져옵니다.
- multi\_cameras: 여러 카메라를 열고 스트리밍 데이터를 가져옵니다.
- single\_camera: 단일 카메라를 열고 스트리밍 데이터를 가져옵니다.
- single\_camera2: 구조체를 통해 프레임 데이터를 가져옵니다.

필요에 따라 다양한 샘플 코드를 선택하여 테스트하고 수정할 수 있습니다.

### 4.4 ROS 2 샘플 코드 컴파일 및 실행

ROS 노드 예제는 colcon으로 컴파일합니다.

먼저 컴파일 도구를 설치하세요.

```bash
sudo apt install python3-colcon-common-extensions
```

<Frame>
  ![ROS 2 샘플 코드 컴파일 및 실행 관련 그림 2](/images/developers/camera-sdk-linux-examples-compiling-and-running-ros2-sample-code-2.avif)

그런 다음 `ros-pcl` 종속 패키지를 설치하세요. `foxy`를 시스템에 설치된 ROS 2 배포판 이름으로 바꾸세요.

```bash
sudo apt-get install ros-foxy-pcl*
```

설치 후 `lx_camera_node_ws` 디렉터리로 이동하여 프로젝트를 빌드하세요.

```bash
colcon build
```

### 5.3 ROS1 및 ROS2

ROS 설명에서는 드라이버 소스 코드 자체보다 launch 파일의 구성에 해당하는 내용, 구성 조정 방법, 메시지 송수신 및 구독 방법을 다룹니다. 제공되는 ROS 노드에는 대부분의 기능이 이미 포함되어 있으므로 드라이버 소스 코드를 직접 수정하지 않는 것이 좋습니다. 특별한 요구 사항이 있다면 먼저 C\+\+ 예제의 코드 흐름을 이해한 후 드라이버 소스 코드를 수정하세요.

**ROS 드라이버를 실행할 때는 시스템 기본 경로에 있는 OpenCV와 PCL 버전이 각각 하나만 존재하는지 확인해야 합니다. 그렇지 않으면 ROS 라이브러리를 링크할 때 오류가 발생하여 컴파일이 실패하거나 실행 중 충돌이 발생할 수 있습니다.**

**String 형식 값을 설정할 때는 ROS2의 처음 큰따옴표와 ROS1의 처음 작은따옴표를 제외하고 작은따옴표와 큰따옴표에 이스케이프 문자를 추가해야 합니다. 예를 들어 문자열 \[PUT”123”\]을 입력하려면 이스케이프 문자를 추가하여 \[PUT\\”123\\”\]로 입력해야 합니다.**

### 6.2 CPU 세부 정보

CPU 세부 정보에는 다양한 작동 조건에서 노드가 사용하는 CPU 리소스가 표시됩니다. 테스트는 **AMD64 \[8코어\], 8G 메모리** 하드웨어 환경을 기준으로 하며, 테스트 카메라는 **M4 Pro**, 테스트 알고리즘은 **팔레트 알고리즘**입니다. **2D 너비와 높이는 1280\*960, 3D 너비와 높이는 640\*480**이고, **2D 왜곡 보정은 켜짐, 3D 왜곡 보정은 꺼짐, 적분 시간 110~3000, 깊이 0~8000, ToF 프레임 속도 14, 스트리밍 모드, 평활화 수준 1, 노이즈 수준 1, 시간 영역 수준 0**으로 설정했습니다. 통계 명령은 **TOP**입니다. 테스트 소프트웨어 환경이 **VM 가상 머신**이므로 실제 장치에서 표시되는 데이터가 문서의 값과 비교해 변동하는 것은 정상입니다. S2와 같은 일부 카메라는 호스트 컴퓨터에서 알고리즘을 계산하므로 리소스 사용량이 많을 수 있으며 이는 정상입니다. <br />

## 부록

이 부록에서는 일부 도구의 설치 방법을 제공합니다. 이 방법을 사용하려면 Linux에 대한 기본 지식이 필요합니다. 이 문서의 부록에 소개된 방법으로 모든 컴퓨터에 성공적으로 설치할 수 있다고 보장할 수는 없습니다. 컴퓨터 환경마다 다르고 발생하는 문제도 다를 수 있습니다. 부록에 없는 문제가 발생하면 직접 해결 방법을 검색하세요.

### 1. Cmake 지정 버전 설치 방법

[https://cmake.org/download/](https://cmake.org/download/)로 이동하여 필요한 CMake 버전을 다운로드하세요. `tar -zxvf cmake-XXX.tar.gz`로 다운로드한 패키지의 압축을 풀고 압축 해제된 디렉터리로 이동한 다음 컴파일하고 구성합니다.

./bootstrap

make

sudo make install

CMake 버전을 확인하여 설치가 성공했는지 확인하세요.

cmake --version

### 2. OpenCV 지정 버전 설치 방법

1. 필요한 OpenCV 버전을 다운로드하세요: [Releases-OpenCV](https://opencv.org/releases/ "Releases-OpenCV")
