## 개요

카메라는 TCP Socket 서버로 실행되며 기본적으로 포트 `5501`에서 수신 대기합니다. 메시지는 텍스트 형식이며 ASCII를 지원하고 JSON 인코딩을 권장합니다.

<Info>
  로봇 또는 PLC가 3D 비전 작업을 트리거하고 카메라가 반환한 결과를 읽을 때 이 프로토콜을 사용하세요.
</Info>

## 요청 메시지

다음 메시지를 보내 3D 비전 작업을 트리거하세요.

```json
{"action":"3D"}
```

## 응답 메시지

카메라가 작업을 완료하면 JSON 객체를 반환합니다.

<ResponseField name="result" type="integer" required>
  감지 상태입니다. `0`은 로컬라이제이션 실패 또는 결과 없음을 나타냅니다. 그 밖의 정수는 성공을 나타내며 반환된 결과 수를 표시합니다.
</ResponseField>

<ResponseField name="pos" type="number[]" required>
  객체 포즈 배열입니다. 각 결과에는 로봇 좌표계의 `X`, `Y`, `Z`, `RX`, `RY`, `RZ`가 포함됩니다. 위치 단위는 mm이고 각도 단위는 °이며 `−180° ≤ RZ ≤ 180°`입니다. 감지에 실패하면 모든 값이 `0`입니다.
</ResponseField>
