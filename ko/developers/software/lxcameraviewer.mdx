LxCameraViewer는 카메라를 검색하고 연결하며, 이미지와 포인트 클라우드를 표시하고, 카메라 매개변수를 구성하며, 애플리케이션 알고리즘 유지 관리 도구를 제공합니다.

<Info>
  전체 PDF 매뉴얼: [LxCameraViewer 사용자 매뉴얼](https://pub-f1dc758884b94eaba9d8c5d3d7575b62.r2.dev/docs/pdf/lxcameraviewer_user_manual.pdf).
</Info>

## 개요

LxCameraViewer는 MRDVS Camera SDK를 기반으로 하며 Windows와 Linux를 지원합니다. 깊이, 강도, 포인트 클라우드 및 RGB 이미지를 확인하고 저장할 수 있으며, 카메라와 애플리케이션 알고리즘 매개변수를 읽고 설정하고, IP 구성, 패킷 캡처, 통신 및 네트워크 카드 구성 도구에 액세스할 수 있습니다.

## 설치 및 네트워크 구성

### 권장 시스템 구성

| 구성 항목 | Windows | Linux |
| --- | --- | --- |
| 운영 체제 | Windows 10 (64-bit) 또는 Windows 11 (64-bit) | Ubuntu (64-bit) |
| 메모리 | 4 GB 이상 | 4 GB 이상 |
| 네트워크 어댑터 및 케이블 | 기가비트 이더넷 이상 | 기가비트 이더넷 이상 |

### IP 주소 및 게이트웨이 구성

카메라는 고정 IP 주소를 사용합니다. 기본 IP 주소는 `192.168.100.82`이며 기본 게이트웨이는 비워 둘 수 있습니다. Windows에서는 서브넷 마스크 `255.255.0.0`을 사용하고 Linux에서는 `255.255.255.0`을 사용합니다.

카메라에 연결된 호스트 컴퓨터의 이더넷 어댑터를 `192.168.100.x`로 설정합니다. 여기서 `x`는 `3`부터 `254`까지의 숫자 중 카메라 IP와 다른 값이어야 합니다. 예를 들어 카메라 IP가 `192.168.100.12`라면 호스트 컴퓨터 IP를 `192.168.100.89`로 설정합니다.

## LxCameraViewer 사용

### 소프트웨어 인터페이스 개요

#### 카메라가 열리지 않은 경우

초기 인터페이스에는 다음 영역이 있습니다.

- **목록 패널**: 디바이스 목록, 현재 정보 및 디바이스 정보입니다.
- **상단 메뉴 표시줄**: 도구 및 인터페이스 언어를 선택합니다.
- **이미지 표시 영역**: 포인트 클라우드, 깊이, 강도 및 RGB 화면입니다.
- 메뉴 표시줄을 두 번 클릭하면 창을 최대화하거나 원래 크기로 복원할 수 있습니다. 메뉴 표시줄을 드래그하여 창을 이동합니다.

<Frame>
  ![카메라가 열리지 않은 소프트웨어 인터페이스 개요 관련 아이콘](/images/developers/software-lxcameraviewer-software-interface-overview-camera-not-opened.avif)
</Frame>

#### 카메라가 열린 경우

카메라를 열면 오른쪽에 기능 표시줄이 나타납니다.

- **기본 도구**: 이미지 표시 설정, 2D 설정, 3D 설정, 필터링, 하드웨어 인터페이스, 수집 설정 및 기능 설정입니다.
- **애플리케이션 알고리즘**: 작동 모드 설정, 알고리즘 모드 설정, 알고리즘 버전 및 세부 알고리즘 설정입니다.
- **기타 도구**: 로컬 포인트 클라우드 로드, IP 구성, 패킷 캡처, 네트워크 카드 구성, 통신, GPU 활성화 및 로그 수준입니다.

<Frame>

### 디바이스 열기 및 닫기

#### 디바이스 목록

- 디바이스 목록은 왼쪽 위에 있습니다. **새로 고침**을 사용하여 카메라를 검색하고, 옆의 버튼으로 목록을 접거나 펼칩니다.
- 각 디바이스에는 열림 상태, 카메라 ID 및 IP 주소가 표시됩니다. 카메라 ID 위에 마우스를 올리면 IP 주소를 확인할 수 있습니다.
- **열기** 또는 **닫기**를 클릭하여 연결을 제어합니다. 버튼에는 현재 상태도 표시됩니다.
- 선택한 디바이스는 파란색으로 표시됩니다. 네트워크 대역폭이 충분하면 여러 디바이스를 열 수 있으며, 카메라 ID를 클릭하여 디바이스 사이를 전환합니다.

### 현재 정보

### 디바이스 정보

- 디바이스 정보 영역은 왼쪽 아래에 있으며 선택한 디바이스의 다음 정보를 표시합니다.

  - 일련 번호
  - SDK가 디바이스를 여는 데 사용하는 카메라 ID
  - IP 주소
  - MAC 주소
  - 소프트웨어 버전
  - 알고리즘 버전(카메라를 연 후 표시됨)
  - 네트워크 속도(닫힌 상태에서는 연결 끊김으로 표시되며, 열린 상태에서는 어댑터와 케이블에 따라 100 Mbps 또는 기가비트로 표시됨)
  - 카메라 모델
  - 이미지 버전(카메라를 연 후 표시됨)
- 접기 버튼을 클릭하여 이 영역을 숨깁니다. 항목을 마우스 오른쪽 버튼으로 클릭하여 값을 복사합니다.

### 이미지 미리 보기 및 저장

#### 미리 보기

- 이미지 및 이미지 데이터, 이미지 관련 작업 소프트웨어는 가운데 영역(그림 1의 빨간색 상자 안)에 표시됩니다.
- \[흐름 시작/중지\] \[단일 저장\] \[깊이 맵\] \[강도 맵\] \[RGB\] \[포인트 클라우드\]는 이미지 작업을 제어하는 기능입니다.
- 가운데에는 디바이스에서 가져온 깊이 이미지, 강도 이미지, 포인트 클라우드 이미지 및 RGB 이미지가 표시됩니다.
- 아래쪽의 흰색 글자는 카메라 및 이미지 데이터입니다(그림 2 참조).

#### 이미지 스트림 제어

- \[흐름 시작/중지\] 버튼: 클릭하여 디바이스의 스트림을 시작하거나 중지합니다.
- \[단일 저장\] 버튼: 시작된 스트림의 이미지 데이터를 저장합니다.

  - 예를 들어 그림 2에서는 깊이 이미지와 포인트 클라우드 이미지만 저장됩니다. RGB 이미지와 강도 이미지는 시작되지 않았으므로 저장되지 않습니다.
  - 깊이 맵과 강도 맵 파일의 접미사는 .pgm이고, RGB 이미지 파일의 접미사는 .png이며, 포인트 클라우드 파일의 접미사는 .pcd입니다.
  - 저장된 깊이 이미지, 강도 이미지 및 포인트 클라우드 이미지는 의사 색상을 추가하지 않은 원본 이미지입니다.
  - 여러 번 클릭하여 연속으로 저장할 수 있지만 한 번에 최대 3회까지 연속 저장할 수 있습니다.
- \[깊이 맵\] 확인란: 깊이 맵을 표시(활성화)할지 여부를 설정합니다.
- \[강도 그래프\] 확인란: 강도 그래프를 표시(활성화)할지 여부를 설정합니다.
- \[포인트 클라우드\] 확인란: 포인트 클라우드 이미지를 표시(활성화)할지 여부를 설정합니다.
- \[RGB\] 확인란: RGB 이미지를 활성화할지 여부를 설정합니다.
- RGB 또는 강도 맵의 선택을 해제하면 디바이스는 RGB 또는 강도 맵 이미지 수집을 중지합니다. 단, 깊이 맵과 포인트 클라우드 맵을 동시에 끈 경우에만 깊이 데이터 수집도 중지됩니다.
- 그림 2에서는 디바이스가 스트리밍을 시작하여 깊이 이미지, 포인트 클라우드 이미지, RGB 이미지 및 강도 이미지를 표시합니다.

##### 3D 설정

- \[3D 너비\] 포인트 클라우드 이미지의 너비입니다. 디바이스 모델에 따라 결정되며 설정할 수 없습니다.
- \[3D 높이\] 포인트 클라우드 이미지의 높이입니다. 디바이스 모델에 따라 결정되며 설정할 수 없습니다.
- \[픽셀 비닝\] 1\*1, 2\*2 또는 N\*N을 선택하여 행렬의 픽셀 값을 더한 다음 2\*2 또는 N\*N으로 나누어 비닝 이미지를 생성합니다. 스트림을 중지한 후 수정할 수 있습니다(이미지 크기는 가로와 세로 모두 원래 크기를 비닝 픽셀 크기로 나눈 값이 됩니다).
- \[RGB 정렬\] 깊이 맵, 강도 맵, 포인트 클라우드 및 RGB 이미지를 정렬합니다. 정렬 후 깊이 맵과 강도 맵의 너비와 높이는 RGB 이미지와 같아집니다. 포인트 클라우드 데이터가 증가하며 스트림을 중지한 후 수정할 수 있습니다.
- \[다중 카메라 모드\] 여러 카메라를 동시에 사용할 때 켜면 다른 카메라의 간섭을 제거할 수 있습니다. 스트림을 중지한 후 수정할 수 있습니다.
- \[다중 장치 알고리즘 감도\] 디바이스의 내장 매개변수는 디바이스 모델에 따라 결정되며 설정할 수 없습니다.
- \[왜곡 보정\] 내부 매개변수의 왜곡 매개변수를 호출하여 인터페이스에 표시되는 이미지의 왜곡을 제거합니다.
- \[왜곡 보정 계수\] 왜곡 계수를 조정하여 보정된 이미지의 왜곡을 강화하거나 약화합니다.
- \[주파수 모드\] 디바이스의 내장 매개변수는 디바이스 모델에 따라 결정됩니다(일부 카메라의 주파수는 고정되어 설정할 수 없음).
- \[HDR 활성화\] HDR을 활성화하면 명암 변화가 큰 장면에서 이미지 선명도를 높일 수 있습니다.
- \[자동 노출\] 켜면 디바이스가 주변 광도에 따라 노출 매개변수를 자동으로 조정합니다.
- \[목표 강도\] 깊이 이미지를 수집할 때의 강도 임계값입니다(설정할 수 없음).
- \[자동 노출 상한\] 자동 노출의 상한을 설정합니다.
- \[자동 노출 하한\] 자동 노출의 하한을 설정합니다(설정할 수 없음).
- \[게인\] 강도 값을 배수로 높일 수 있습니다(설정할 수 없음).
- [x] ROI 영역 왼쪽 위 모서리의 x 좌표를 설정합니다. 스트림을 중지한 후 수정할 수 있습니다.
- \[y\] ROI 영역 왼쪽 위 모서리의 y 좌표를 설정합니다. 스트림을 중지한 후 수정할 수 있습니다.
- \[높은 적분\] 높은 적분 시간입니다. 값을 높이면 카메라가 더 먼 거리를 측정할 수 있습니다.

##### 필터 설정

- \[최소 깊이\] 깊이 맵의 의사 색상 또는 거리에 대한 하한입니다. 이 값보다 작으면 의사 색상이 검은색으로 표시되고 강제로 0으로 설정됩니다.
- \[최대 깊이\] 깊이 맵의 의사 색상 또는 거리에 대한 상한입니다. 이 값보다 크면 의사 색상이 검은색으로 표시되고 강제로 0으로 설정됩니다.
- \[낮은 신호 임계값\] 강도 값의 하한입니다. 이 값보다 작으면 깊이 맵의 해당 픽셀이 강제로 0으로 설정됩니다(강도 맵에는 적용되지 않음).
- \[높은 신호 임계값\] 강도 값의 상한입니다. 이 값보다 크면 깊이 맵의 해당 픽셀이 강제로 0으로 설정됩니다(강도 맵에는 적용되지 않음).
- \[약한 신호 측정\] 약한 신호 감지 수준을 설정합니다. 수준이 높을수록 감지가 쉬워집니다.

- \[노이즈 수준\] 노이즈 필터링 임계값을 설정합니다(값이 클수록 노이즈가 많아짐).
- \[시간 영역 수준\] 시간 필터링의 강도를 제어하고 과거 여러 프레임의 데이터를 사용하여 깊이 데이터의 연속성을 높입니다.

##### 수집 설정

- \[프레임 동기화\] 이미지를 저장할 때 각 이미지 유형의 수집 환경 조건이 일치하도록 제어합니다.
- \[트리거 모드\] 스트림 모드를 연속, 수동 또는 능동으로 제어합니다.
- \[포인트 클라우드 저장 방식\]

  - 일반(비정렬 포인트 클라우드): 포인트 클라우드 수는 변하지 않으며, width = width\*height, height = 1입니다(그림 3 참조).
  - 정렬된 포인트 클라우드: 포인트 클라우드 수는 변하지 않으며, width = ToF width, height = ToF height입니다(그림 4 참조).
- \[포인트 클라우드 저장 형식\] 포인트 클라우드를 저장할 데이터 형식을 설정합니다.

  - BINARY: 바이너리 형식으로 저장합니다.
  - ASCII: ascii 코드 형식, 즉 텍스트 모드로 저장합니다.
- \[포인트 클라우드 값 단위\] 포인트 클라우드 이미지 데이터의 측정 단위를 설정합니다.
- \[이미지 저장 시작\] 현재 선택한 이미지 유형을 계속 저장합니다.
- \[저장 경로 열기\] \[단일 저장\] 기능으로 이미지를 저장하는 경로를 엽니다.

참고: 640\*480 이미지의 경우 ASCII 저장 시간은 약 6.6초이고 바이너리 저장 시간은 약 32ms입니다. 바이너리 저장 속도는 ASCII의 206배입니다. 바이너리 형식으로 저장하는 것이 좋습니다.

##### 장애물 회피 알고리즘

- 애플리케이션 알고리즘을 장애물 회피 알고리즘으로 설정하면 장애물 회피 관련 구성이 표시됩니다.
- \[차체 표시\] 포인트 클라우드 이미지에 차체 위치를 표시하는 차량 모델을 끄거나 켤 수 있습니다.
- \[장애물 회피 인덱스\] 장애물 회피에는 여러 구성을 사용할 수 있으며 이 옵션으로 설정합니다.
- \[카메라 각도 Roll (x-axis)\] 카메라 외부 매개변수의 롤 각도이며 기본 카메라 값은 180입니다.
- \[카메라 각도 Pitch (y-axis)\] 카메라 외부 매개변수의 피치 각도이며 기본 수직 설치 값은 90입니다.
- \[카메라 각도 Yaw (z-axis)\] 카메라 외부 매개변수의 헤딩 요 각도이며 기본값은 90입니다.
- \[카메라 위치 (distance x)\] 카메라 외부 매개변수로, x 방향과 원점 사이의 거리입니다. 단위는 미터입니다.
- \[카메라 위치 (width y)\] 카메라 외부 매개변수로, y 방향과 원점 사이의 거리입니다. 가운데에 설치하면 0입니다. 단위는 미터입니다.
- \[카메라 위치 (height z)\] 카메라의 외부 매개변수로, z 방향과 원점 사이의 거리이며 카메라의 지면으로부터의 높이로 이해할 수 있습니다. 단위는 미터입니다.
- \[조기 경고 거리 (x far)\] 장애물 회피 범위로, x 방향에서 차량 중심까지의 거리입니다. 이 거리보다 먼 장애물은 안전한 것으로 간주하며, 조기 경고 거리와 경보 거리 사이의 장애물은 조기 경고 감속 대상으로 간주되어 인터페이스에 노란색 영역으로 표시됩니다. 단위는 미터입니다.
- \[경보 거리 (x center)\] 장애물 회피 범위로, x 방향에서 차량 중심까지의 거리입니다. 이 거리보다 가까운 장애물은 경보 정지 대상으로 간주되어 인터페이스에 빨간색 영역으로 표시됩니다. 조기 경고 거리와 경보 거리 사이의 거리는 조기 경고 감속 범위로 간주되어 인터페이스에 노란색 영역으로 표시됩니다. 단위는 미터입니다.
- \[차폐 거리 (near x)\] 장애물 회피 범위로, 차량 중심에서 x 방향으로 떨어진 거리입니다. 이 거리 안의 장애물은 무시됩니다. 단위는 미터입니다.
- \[장애물 회피 범위 왼쪽 (y left)\] 장애물 회피 범위로, y 방향의 왼쪽에서 차량 중심까지의 거리입니다. 단위는 미터입니다.
- \[장애물 회피 범위 오른쪽 (y right)\] 장애물 회피 범위로, y 방향의 오른쪽에서 차량 중심까지의 거리입니다. 단위는 미터입니다.
- \[장애물 회피 높이 하한 (z lower)\] 장애물 회피 범위의 지면으로부터의 높이입니다. 이 높이보다 낮은 영역은 처리하지 않습니다. 설정이 너무 작으면 거리 측정 오류로 오경보가 발생할 수 있고, 너무 크면 지면의 큰 장애물이 필터링되어 오경보가 발생할 수 있습니다. 단위는 미터입니다.
- \[장애물 회피 높이 상한 (z upper)\] 장애물 회피 범위의 지면으로부터의 높이입니다. 이 높이보다 높은 영역은 처리하지 않습니다. 단위는 미터입니다.
- \[장애물 회피 출력\] 장애물 회피 결과를 출력합니다.
- \[카메라 외부 매개변수 초기화\] 카메라에 기록되지 않은 모든 매개변수를 복원합니다.
- \[외부 매개변수 설정\] 모든 매개변수를 카메라에 기록합니다.
- 장애물 회피 세부 설정은 장애물 회피 문서를 참조하십시오.

- \[카메라 각도 Pitch (y-axis)\] Y축에 대한 카메라의 기울기입니다.
- \[카메라 각도 Yaw (z-axis)\] Z축에 대한 카메라의 기울기입니다.
- \[카메라 위치 (distance x)\] X 방향에서 카메라 광학 중심과 지게차 회전 중심 사이의 상대 거리입니다.
- \[카메라 위치 (width y)\] Y 방향에서 카메라 광학 중심과 지게차 회전 중심 사이의 상대 거리입니다.
- \[카메라 위치 (height z)\] Z 방향에서 카메라 광학 중심과 지게차 회전 중심 사이의 상대 거리입니다.
- \[지면 높이\] 카메라 광학 중심에서 지면까지의 거리입니다.
- \[팔레트 다리 최대 너비\] 팔레트 유형에 지정된 팔레트 다리의 최대 너비와 호환되어야 합니다.
- \[팔레트 다리 최소 너비\] 팔레트 유형에 지정된 팔레트 다리의 최소 너비와 호환되어야 합니다.
- \[팔레트까지의 거리\] 삽입이 완료된 후 카메라 광학 중심에서 팔레트까지의 거리입니다.
- \[설치 방법\] 카메라의 고정 방향에 따라 설정하며, 기본값은 정방향 설치(0)입니다.
- \[최소 Z 값\] 팔레트에서 가장 가까운 깊이 거리를 식별합니다.
- \[최대 Z 값\] 팔레트에서 가장 먼 깊이 거리를 식별합니다.
- \[최소 X 값\] 팔레트의 가로 경계(카메라를 중심으로 한 왼쪽 경계)를 식별합니다.
- \[최대 X 값\] 팔레트의 가로 경계(카메라를 중심으로 한 오른쪽 경계)를 식별합니다.
- \[팔레트 알고리즘 출력\] 팔레트 알고리즘의 결과를 표시합니다.
- \[보정 안내\] 지면이 평평하고 팔레트 앞에 장애물이 없을 때 자동으로 보정합니다. 팔레트는 표준 크기여야 합니다.
- \[기본 매개변수 복원\] 모든 매개변수를 공장 출하 기본값으로 복원합니다.
- \[카메라에서 외부 매개변수 읽기\] 카메라에서 모든 매개변수를 읽습니다. 전송되지 않은 모든 매개변수는 덮어써집니다.
- \[매개변수 전송\] 모든 매개변수를 카메라에 기록합니다.
- 팔레트 감지 세부 설정은 팔레트 감지 기능 문서를 참조하십시오.

- \[GPU 활성화\] GPU 계산을 사용하여 그래픽을 처리할 수 있습니다.
- \[로그 수준\] 로그 출력 정보의 상세 수준을 제어합니다.

## 문제 해결

|  |  |
| --- | --- |
| 문제 설명 | 해결 방법 |
| 카메라를 찾을 수 없음 | \* 카메라 전원이 연결되어 있는지 확인합니다. 전원을 켜면 카메라 전면의 파란색 표시등이 계속 켜져 있어야 합니다. \* IP 주소와 서브넷 마스크가 올바른지 확인합니다. \* 호스트 컴퓨터의 네트워크 액세스가 차단되어 있지 않은지 확인합니다. |
| 카메라는 열리지만 스트리밍에 실패함 | 호스트 컴퓨터에서 관리자 권한으로 실행했는지 확인합니다. |
| 이미지 지연 | 네트워크 카드, 네트워크 케이블 및 스위치가 기가비트인지 확인합니다. RGB 정렬을 켜면 100M 네트워크에서 어느 정도 지연이 발생합니다. |
| 카메라가 자주 다시 연결됨 | 공장 설정 복원, 펌웨어 업그레이드 후 또는 100M 네트워크에서 카메라를 처음 켤 때 카메라는 약 30초 동안 자체 조정 또는 다시 시작합니다. 이 30초 동안 호스트 컴퓨터는 카메라가 안정될 때까지 계속 연결을 시도합니다. |
| 깊이 데이터와 포인트 클라우드 데이터가 없음 | \* 카메라가 가려져 있지 않은지 확인합니다. \* 물체가 카메라 촬영 범위 안에 있는지 확인합니다. \* 최대/최소 깊이 값이 올바른지 확인합니다. \* 필터 매개변수가 올바른지 확인합니다. |
| 포인트 클라우드가 사라지고 인터페이스에 흰색 프레임만 표시됨 | 마우스로 포인트 클라우드 이미지를 클릭하고 'm' 키를 눌러 포인트 클라우드 안정화를 켭니다. |
| 포인트 클라우드 표시가 비정상임 | 포인트 클라우드 바로 가기 키를 조작했는지 확인하고 포인트 클라우드 안정화를 켭니다. |
| Linux에서 카메라를 연 후 포인트 클라우드가 표시되지 않음 | 마우스로 포인트 클라우드 이미지를 누른 채 드래그하여 표시합니다. |
| 애플리케이션 표시: VTK 로드 실패, 포인트 클라우드가 표시되지 않음. 그래픽 카드 구성과 그래픽 카드 드라이버를 확인하십시오. | \* 그래픽 카드 구성이 너무 낮지 않은지 확인합니다. \* 그래픽 카드 드라이버가 정상적으로 실행되는지 확인합니다. \* 포인트 클라우드를 표시하려면 전용 비디오 메모리와 해당 드라이버가 있는 그래픽 카드가 필요합니다. |
