---

이 페이지에서는 LxCameraViewer의 일반적인 장치 구성 및 유지 관리 작업을 요약합니다. 설치, 장치 연결 및 전체 인터페이스 레퍼런스는 [LxCameraViewer 사용자 가이드](/ko/developers/software/lxcameraviewer)를 참조하세요.

<Warning>
  카메라 펌웨어 또는 애플리케이션 알고리즘을 업그레이드하기 전에 패키지가 카메라 모델과 일치하는지 확인하세요. 업그레이드 중에는 전원이나 네트워크를 분리하지 마세요.
</Warning>

## 네트워크 및 인터페이스

### 카메라 IP 주소 변경

**Other tools**에서 **IP configuration tool**을 열고 대상 카메라를 선택한 다음 IP 주소, 서브넷 마스크 또는 게이트웨이를 업데이트하세요. 호스트와 카메라를 같은 서브넷에 유지합니다.

<Frame>
  ![IP configuration tool의 카메라 네트워크 설정](/images/developers/software-lxcameraviewer-common-operations-camera-ip-modification-method.avif)
</Frame>

### CAN 보드레이트 및 CAN ID 구성

**Basic tools → Hardware interface**를 열고 CAN 보드레이트 또는 CAN ID를 변경하세요. 같은 CAN 버스의 장치는 동일한 보드레이트를 사용해야 합니다.

<Frame>
  ![LxCameraViewer의 CAN 보드레이트 및 CAN ID 설정](/images/developers/software-lxcameraviewer-common-operations-modifying-can-baud-rate-and-can-id-methods.avif)
</Frame>

## 버전 및 업그레이드

### 소프트웨어, 펌웨어 및 알고리즘 버전 확인

카메라를 연 후 장치 정보 또는 소프트웨어 버전 패널에서 카메라 펌웨어, LxCameraViewer 및 애플리케이션 알고리즘 버전을 확인하세요.

<Frame>
  ![LxCameraViewer에서 펌웨어, 소프트웨어 및 알고리즘 버전 확인](/images/developers/software-lxcameraviewer-common-operations-viewing-methods-of-firmware-version-pc-software-version-and-algorithm-versio.avif)
</Frame>

### 카메라 펌웨어 또는 애플리케이션 알고리즘 업그레이드

**Basic tools → Function settings**를 열고 펌웨어 또는 애플리케이션 알고리즘 업그레이드를 선택한 다음 안내에 따라 제공된 업그레이드 파일을 고르세요.

<Frame>
  ![LxCameraViewer에서 카메라 펌웨어 또는 애플리케이션 알고리즘 업그레이드](/images/developers/software-lxcameraviewer-common-operations-camera-firmware-upgrade-and-application-algorithm-upgrade-methods.avif)
</Frame>

## 파라미터 및 이미징

### 이미징 파라미터 가져오기 또는 내보내기

**Basic tools → Function settings**를 열어 현재 카메라 구성을 내보내거나 파일에서 저장된 구성을 로드하세요.

<Frame>
  ![LxCameraViewer에서 카메라 이미징 파라미터 가져오기 및 내보내기](/images/developers/software-lxcameraviewer-common-operations-import-and-export-methods-of-camera-imaging-parameters.avif)
</Frame>

### 애플리케이션 알고리즘 항상 켜기

**Application algorithm**에서 작동 모드를 구성하여 호스트 애플리케이션이 연결 해제된 후에도 카메라가 활성화된 알고리즘 결과를 계속 출력하도록 하세요.

<Frame>
  ![LxCameraViewer에서 애플리케이션 알고리즘을 항상 켜짐으로 구성](/images/developers/software-lxcameraviewer-common-operations-applying-algorithm-to-set-normally-open-method.avif)
</Frame>

### 카메라 내부 파라미터 가져오기

**Basic tools → Function settings**를 열고 카메라 내부 파라미터를 읽으세요.

<Frame>
  ![LxCameraViewer에서 카메라 내부 파라미터 읽기](/images/developers/software-lxcameraviewer-common-operations-the-method-of-obtaining-internal-parameters-of-the-camera.avif)
</Frame>

### RGB-D 정렬 활성화

**Basic tools → 3D settings**를 열고 RGB-D 정렬을 활성화하세요.

<Frame>
  ![LxCameraViewer에서 RGB-D 정렬 활성화](/images/developers/software-lxcameraviewer-common-operations-rgbd-alignment-opening-method.avif)
