이 페이지에는 V2 비주얼 로컬라이제이션 모듈이 제공하는 HTTP 엔드포인트가 정리되어 있습니다. 각 주소의 IP 자리 표시자를 모듈 IP 주소로 바꾸세요. 별도 설명이 없는 한 `code: 200` 및 `message: success`는 요청이 성공적으로 처리되었음을 의미합니다.

<Warning>
  소프트웨어 업데이트, 맵 배포 또는 전환, 프로그램 재시작 및 카메라 재부팅은 로컬라이제이션을 중단합니다. 차량이 정지해 있고 복구 절차를 사용할 수 있을 때만 이 엔드포인트를 호출하세요.
</Warning>

## 프로그램 및 장치 정보

### 주 프로그램 업데이트

주소: `http://<ip>:9998/tool/rob/quiet_update`

<ParamField body="url" type="string" required>
  주 프로그램 업그레이드 패키지에 연결할 수 있는 URL입니다.
</ParamField>

### 카메라 높이 설정

주소: `http://<ip>:9998/tool/rob/setHeightRequest`

<ParamField body="height" type="number" required>
  카메라 높이입니다.
</ParamField>

### 프로그램 버전 가져오기

주소: `http://<ip>:9998/tool/rob/getRobotVersion`

이 엔드포인트에는 요청 파라미터가 필요하지 않습니다.

<ResponseField name="code" type="integer" required>
  응답 상태 코드입니다.
</ResponseField>

<ResponseField name="data" type="string">
  `version 12313`과 같은 프로그램 버전입니다.
</ResponseField>

### 차량 정보 가져오기

주소: `http://<ip>:9998/tool/rob/getVehicle`

이 엔드포인트에는 요청 파라미터가 필요하지 않습니다.

<ResponseField name="data" type="object" required>
  차량 정보 객체입니다.
</ResponseField>

<ResponseField name="vehicleId" type="string">
  차량 UUID입니다.
</ResponseField>

<ResponseField name="mapId" type="string">
  현재 맵입니다.
</ResponseField>

<ResponseField name="vehicleType" type="string">
  차량 유형입니다.
</ResponseField>

## 맵 관리

### 현재 실행 중인 맵 패키지 다운로드

주소: `http://<ip>:9998/tool/rob/getRunMapZip`

요청 헤더: `Content-Type: application/json`

<ParamField body="Name" type="string" required>
  맵 이름입니다.
</ParamField>

응답은 콘텐츠 유형이 `application/zip`인 ZIP 파일입니다.

### 맵 생성 시작

주소: `http://<ip>:9998/tool/rob/startMapping`

<ParamField body="name" type="string" required>

### 맵 생성 중지

주소: `http://<ip>:9998/tool/rob/stopMapping`

이 엔드포인트에는 요청 파라미터가 필요하지 않습니다.

### 증분 맵 생성 시작 또는 중지

주소: `http://<ip>:9998/tool/rob/sendCMD`

| 작업 | `cmd` | `attach.sub_command` | `attach.param` |
| --- | --: | --: | --- |
| 증분 맵 생성 시작 | `904` | `0` | `mapname` |
| 증분 맵 생성 중지 | `905` | `0` | `mapname` |

### 맵 목록 가져오기

로컬 맵 목록 엔드포인트를 사용하세요.

`http://<ip>:9998/tool/rob/getRunMapLists`

이 엔드포인트에는 요청 파라미터가 필요하지 않습니다. The response `run_maps` is an array of map names.

<Note>
  백엔드 맵 목록 엔드포인트 `http://<ip>:9998/tool/editor/getLocalMaps`는 더 이상 사용되지 않으며 권장하지 않습니다.
</Note>
