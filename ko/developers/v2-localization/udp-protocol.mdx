V2 Pro는 UDP를 통해 클라이언트와 제어 및 로컬라이제이션 데이터를 교환합니다. 웹 호스트 애플리케이션에서 `portName`을 대상 장치 IP 주소로, `portCode`를 수신 대기 포트로 설정하세요. V2 Pro는 수신 메시지를 포트 `8001`에서 대기합니다.

## 메시지 규칙

| 항목 | 규칙 |
| --- | --- |
| 바이트 순서 | 빅 엔디안: 상위 바이트가 하위 바이트보다 먼저 옵니다. |
| 프레임 구조 | 헤더, 길이, 명령, 데이터 및 체크섬입니다. |
| 체크섬 | 1바이트입니다. 헤더와 체크섬 자체를 제외한 모든 바이트를 XOR합니다. |
| 길이 필드 | 헤더와 체크섬을 제외합니다. 일부 메시지에는 길이 필드가 없습니다. |
| 맵 이름 | ASCII 문자, 숫자 및 밑줄만 사용할 수 있으며 첫 문자는 문자여야 합니다. |

<Note>
  바이트 번호는 Byte 0부터 시작합니다. 여러 바이트로 구성된 모든 정수는 빅 엔디안 순서를 사용합니다.
</Note>

## V2 Pro가 수신하는 메시지

### 오도메트리

| Byte range | 내용 |
| --- | --- |
| Byte 0–1 | 헤더: AC ED |
| Byte 2 | 길이: Length |
| Byte 3 | 명령: 0x0A |
| Byte 4–7 | V3 V2 V1 V0, 4바이트 정수 속도 |
| Byte 8–11 | Theta3 Theta2 Theta1 Theta0, 4바이트 정수 각도 |
| Byte 12 | 체크섬 |

속도 `v`의 단위는 mm/s입니다. 각도 `theta`의 단위는 0.01°이며, 예를 들어 90°는 9000으로 전송합니다.

### 재배치

| Byte range | 내용 |
| --- | --- |
| Byte 0–1 | 헤더: AC ED |
| Byte 2 | 길이: Length |
| Byte 3 | Command: 0x02 |
| Byte 4–7 | X3 X2 X1 X0, 4바이트 정수 X 좌표 |
| Byte 8–11 | Y3 Y2 Y1 Y0, 4바이트 정수 Y 좌표 |
| Byte 12–15 | Theta3 Theta2 Theta1 Theta0, 4바이트 정수 각도 |
| Byte 16 | 체크섬 |

`x`와 `y`의 단위는 mm입니다. `theta`의 단위는 0.01°이며, 예를 들어 90°는 9000으로 전송합니다.

### 맵 생성 시작 또는 중지

| Byte range | 내용 |
| --- | --- |
| Byte 0–1 | 헤더: AC ED |
| Byte 2 | 길이: Length |
| Byte 3 | Command: 0x02 |
| Byte 4 | 상태: 0x01은 맵 생성을 시작하고 0x00은 중지합니다. |
| Byte 5–34 | 맵 이름, fixed 30-byte ASCII; pad unused bytes with 0x00 |
| Byte 35 | 체크섬 |

맵 생성 작업마다 시작 명령을 한 번만 보내세요. 반복해서 보내지 마세요.

### 맵 전환

| Byte range | 내용 |
| --- | --- |
| Byte 0–1 | 헤더: AC ED |
| Byte 2 | 길이: Length |
| Byte 3 | Command: 0x0C |
| Byte 4–33 | 맵 이름, fixed 30-byte ASCII; pad unused bytes with 0x00 |
| Byte 34 | 체크섬 |

명령을 보내기 전에 대상 맵이 생성되었는지 확인하세요.

## V2 Pro가 전송하는 메시지

### 로컬라이제이션 결과

| Byte range | 내용 |
| --- | --- |
| Byte 0–1 | 헤더: AC ED |
| Byte 2 | 길이: Length |
| Byte 3 | Command: 0x01 |
| Byte 4–7 | X3 X2 X1 X0, X 좌표 |
| Byte 8–11 | Y3 Y2 Y1 Y0, Y 좌표 |
| Byte 12–15 | Theta3 Theta2 Theta1 Theta0, 방향 |
| Byte 16–23 | Timestamp7~Timestamp0, 타임스탬프 |
| Byte 24 | 체크섬 |

`X`와 `Y`의 단위는 mm입니다. `THETA`의 단위는 0.001 rad입니다. 재배치가 성공하면 V2 Pro가 이 메시지를 계속 전송합니다.

### 작업 결과

맵 생성 시작, 맵 생성 중지 및 맵 전환 명령은 다음 메시지로 상태를 반환합니다.

| Byte | 내용 |
| --- | --- |
| Byte 0–1 | 헤더: AC ED |
| Byte 2 | 길이: Length |
| Byte 3 | Command: 0xFF |
| Byte 4 | 작업 ID |
| Byte 5 | Status: 0x01 success; 0x00 failure |
| Byte 6 | 체크섬 |

| 작업 ID | 작업 |
| --- | --- |
| 0x01 | Start mapping |
| 0x02 | Stop mapping |
| 0x03 | Switch map |

<Info>
  맵 생성 중지에는 시간이 걸릴 수 있습니다. 완료까지는 일반적으로 데이터 수집 시간의 약 3분의 1이 걸립니다. 다른 작업을 시작하기 전에 작업 결과 메시지를 기다리세요.
</Info>
