## 거리 측정 원리 및 사양

### 거리 측정 원리

S2 Max는 비행시간(ToF)으로 거리를 측정합니다. 빛을 방출한 시점과 물체에서 반사된 빛을 수신한 시점 사이의 시간을 측정합니다.

S2 Max는 깊이를 직접 측정해 적은 연산 자원으로 고품질 깊이 데이터를 생성하고 높은 프레임 속도로 깊이 장면을 구성합니다. LiDAR와 마찬가지로 ToF 카메라는 펄스 ToF(P\_ToF)와 연속파 ToF(CW\_ToF)로 나뉩니다. P\_ToF는 일반적으로 보이지 않는 광 펄스를 방출하고 왕복 시간으로 거리를 계산합니다. CW\_ToF는 변조된 연속광을 방출하고 송신광과 수신광의 위상 차이로 비행 시간을 계산합니다.

### 감지 범위

그림 3.1은 S2 Max의 감지 영역을 보여 줍니다. 수평 감지 각도는 81°, 수직 각도는 61°입니다. 감지 거리는 광 출력에 따라 달라집니다. 광 출력과 표적 반사율이 높으면 근거리 사각 영역이 커지고 원거리 사각 영역이 줄어듭니다. 광 출력과 표적 반사율이 낮으면 근거리 사각 영역이 줄어들고 원거리 사각 영역이 커집니다. 반사율 10%~~90% 표적에서 S2 Max의 범위는 0.2~~5m입니다. 5m를 넘으면 반사 신호가 약하고 주변광 간섭이 커져 거리 측정 오차가 크게 증가합니다.

### 4.2 정밀도

정밀도는 일반적으로 단일 지점의 변동(1-σ)을 의미합니다. 광전자 측정 장치인 S2 Max는 AD 변환, 신호 대 잡음비, 시스템 노이즈 등의 영향을 받습니다. 그림 4.3은 정밀도와 신호 강도의 관계를 보여 줍니다.

<Frame>
  ![정밀도와 신호 강도](/images/products/s-series-s2-max-user-guide-precision-and-signal-strength.avif)
</Frame>

그림 4.3. 정밀도와 신호 강도

S2 Max는 광전자 아날로그 신호를 디지털 데이터로 변환합니다. ADC는 최소 해상도로 아날로그 신호를 양자화하고 노이즈를 추가합니다. 예를 들어 1.1V 신호는 1V로 읽혀 10%의 오차가 생길 수 있고, 10.1V는 10V로 읽혀 1%의 오차가 생길 수 있으며, 100.1V는 100V로 읽혀 0.1%의 오차가 생길 수 있습니다. 따라서 AD 변환은 신호 강도가 낮을수록 상대적으로 더 큰 노이즈와 오차를 만듭니다. ToF 카메라의 신호 대 잡음비는 일반적으로 적분 시간 t와 SNR∝1/√t의 관계를 가지므로, 적분 시간을 늘리면 신호 강도가 높아집니다.

두 카메라를 평행하게 설치하면 각 카메라가 자신과 다른 카메라에서 돌아온 빛을 모두 수신하여 깊이 데이터에 간섭이 생깁니다. 평행 간섭은 두 S2 Max 카메라가 같은 방향을 향할 때 증가하는 감지 오차입니다.

### 6.3 IP 주소

S2 Max의 출고 시 기본 IP 주소는 192.168.100.82입니다. MRDVS 데모 도구를 사용해 IP 주소를 변경하거나 DHCP를 활성화하십시오.

### 6.4 데모 소프트웨어

### 6.4.1 IP 설정

전원 케이블을 연결한 다음 Ethernet 케이블로 카메라를 컴퓨터에 연결합니다. 카메라의 출고 시 기본 IP가 192.168.100.82이므로 컴퓨터를 192.168.100.x(100.82 제외)로 설정하고 서브넷 마스크를 255.255.255.0으로 설정합니다. **설정** → **Ethernet** → **어댑터 옵션 변경** 을 열고 **Ethernet** 을 마우스 오른쪽 버튼으로 클릭한 다음 **Internet Protocol Version 4 (TCP/IPv4)** 를 선택합니다. 예를 들어 IP 주소를 192.168.100.20, 서브넷 마스크를 255.255.255.0으로 설정합니다.

### 6.4.2 소프트웨어 열기

소프트웨어를 다운로드하고 설치한 다음 LxCameraViwer 데모 아이콘을 두 번 클릭합니다. 카메라 하나가 연결되면 호스트 소프트웨어가 자동으로 카메라를 검색하고 열어 데이터 수집을 시작합니다.

**참고: 처음 실행할 때 일부 시스템에서는 방화벽 액세스 권한을 허용해야 합니다.**

소프트웨어는 기본 기능, 이미지 선택, 카메라 설정 및 카메라 정보를 제공합니다. 카메라 정보에는 카메라 IP, ID, MAC 주소, 일련번호, 소프트웨어 버전 및 알고리즘 버전이 포함됩니다. **Depth**, **Intensity**, **RGB** 또는 **Point cloud** 를 선택해 해당 이미지를 표시합니다.

### 문제 해결

표 9-1. 문제 해결

| 번호 | 문제 | 해결 방법 |
| --- | --- | --- |
| 1 | 카메라를 열어도 응답하지 않음 | 방화벽이 비활성화되어 있는지 확인합니다. |
| 2 | 호스트 소프트웨어가 여러 IP 주소를 감지함 | LAN의 다른 장치가 같은 IP를 사용하고 있습니다. 필요한 IP 주소를 선택합니다. |
| 3 | 카메라를 연 후 데이터가 불안정함 | Gigabit Ethernet 케이블을 사용합니다. Fast Ethernet에서는 초기 데이터가 불안정할 수 있습니다. |
| 4 | 소프트웨어 설치 위치 | C 드라이브의 기본 설치는 권한 설정의 영향을 받을 수 있습니다. |
