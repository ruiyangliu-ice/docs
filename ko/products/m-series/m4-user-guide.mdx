## 제품 개요

이 가이드는 Zhejiang MRDVS Technology Co., Ltd.에서 개발한 M4 카메라의 사양, 기능 및 사용 방법을 설명합니다.

## 작동 원리 및 사양

### ToF 거리 측정 원리

M4 카메라는 ToF(time-of-flight) 거리 측정 방식을 사용합니다. 빛을 방출한 뒤 물체에서 반사되어 돌아오는 데 걸리는 시간을 측정하여 물체와 카메라 사이의 거리를 계산합니다.

M4 카메라는 깊이를 직접 캡처하므로 적은 연산 리소스로 고품질 깊이 정보를 제공하고 높은 프레임 속도로 깊이 장면을 구성할 수 있습니다. LiDAR와 마찬가지로 ToF 카메라는 펄스 ToF(P\_ToF) 또는 연속파 변조 ToF(CW\_ToF)를 사용할 수 있습니다. P\_ToF는 일반적으로 보이지 않는 광 펄스를 방출하고 왕복 시간으로 거리를 계산합니다. CW\_ToF는 변조된 연속광을 방출하고 방출광과 반환광의 위상 차이로 거리를 계산합니다.

### 작동 범위 및 반사율

그림 3.4는 M4의 감지 영역을 보여 줍니다. 카메라의 수평 시야각은 81°이고 수직 시야각은 61°입니다. 감지 거리는 광 출력에 따라 달라집니다. 광 출력과 대상 반사율이 높으면 근거리 사각 영역이 커지고 원거리 사각 영역이 작아집니다. 광 출력과 대상 반사율이 낮으면 근거리 사각 영역이 작아지고 원거리 사각 영역이 커집니다. 반사율이 10%~~90%인 물체의 경우 M4의 측정 범위는 0.3~~5m입니다. 5m를 넘으면 약한 반사 신호가 주변광의 영향을 더 많이 받아 오차가 커집니다.

## 정확도 및 다중 카메라 배치

### 4.1 정확도

보정은 센서 측정값과 실제 값 사이의 고정 오프셋을 하나의 값에서 다른 값으로 매핑하여 제거합니다. M4 카메라를 보정하려면 레일에 카메라를 장착하고 흰색 벽을 향하게 합니다. 각 픽셀의 측정값을 카메라와 해당 벽 영역 사이의 거리에 매핑한 뒤 이 매핑으로 측정값을 보정합니다. 그림 4.1을 참조하십시오.

<Frame>
  ![M4 보정 설정](/images/products/m-series-m4-user-guide-m4-calibration-setup.avif)
</Frame>

그림 4.1. 보정

M4는 능동 거리 측정을 사용하므로 정확도에 영향을 주는 요소가 많습니다. 잘못된 설치는 다중 경로 효과를 일으켜 측정값을 왜곡할 수 있습니다.

이 현상은 반사율이 낮은 대상이 반사율이 높은 물체 옆에 있을 때 특히 두드러집니다. 이상적인 경우 빛은 파란색 경로를 따릅니다. 벽에서 반사된 빛이 대상에 도달한 다음 초록색 경로를 따라 카메라로 돌아올 수도 있습니다. 인접한 고반사율 물체에서 직접 반사된 조명이 빨간색 경로를 따라 카메라에 들어올 수도 있습니다. 광학적 결함은 이 빛을 글레어로 만들어 거리 측정을 방해하며, 그림 4.2와 같습니다.

</Frame>

그림 4.3. 측정 정밀도와 신호 강도

M4는 광전자 아날로그 신호를 디지털 데이터로 변환합니다. ADC 변환 중 아날로그 값은 가장 작은 해상도 단위로 반올림되어 노이즈가 발생합니다. 1.1V 신호가 1V로 표현되면 오차는 10%가 됩니다. 10.1V 신호가 10V가 되고 100.1V 신호가 100V가 되면 각각 약 1%의 오차가 발생합니다. 따라서 ADC 변환은 신호 수준이 낮을 때 더 큰 노이즈와 오차를 만듭니다. ToF 카메라의 신호 대 잡음비는 일반적으로 SNR∝1/√t를 따르며, 여기서 `t`는 적분 시간입니다. 적분 시간을 늘리면 신호 강도가 증가합니다.

## 다중 카메라 간섭

### 5.1 병렬 간섭

두 카메라를 병렬로 설치하면 각 카메라가 자체 반사 조명과 다른 카메라의 조명을 모두 수신하여 깊이 데이터에 간섭이 발생할 수 있습니다. 두 M4 카메라가 같은 방향을 향하면 병렬 간섭으로 측정 오차가 증가합니다.

<Frame>
  ![카메라 병렬 간섭](/images/products/m-series-m4-user-guide-parallel-camera-interference.avif)
</Frame>

병렬 간섭을 피하려면 카메라를 수평면에 대해 각도를 두고 설치하십시오. 수평면에 대해 0°로 설치해야 한다면 MRDVS에 사용자 지정 구성을 문의하십시오.

### 6.2 SDK 출력 순서

<img src="/images/products/m-series-m4-user-guide-sdk-output-order.avif" alt="SDK 출력 순서" /> 

그림 6.1. SDK 출력 순서

SDK는 구성된 해상도에 따라 깊이 데이터와 진폭 데이터를 각각 한 프레임씩 출력합니다. 각 프레임은 1차원 배열로 저장되며, 왼쪽 위 픽셀에서 시작하여 왼쪽에서 오른쪽으로 진행한 후 위에서 아래로 진행합니다. 그림 6.1은 x축 다음에 y축 방향으로 출력되는 순서를 보여 줍니다.

(x,y):(0,0)(0,1)(0,2)(0,…)(1,0)(1,1)(1,2)(1,…)(2,…)(3,…)(…,…).

깊이 이미지의 각 픽셀은 측정된 물체에서 카메라 평면까지의 거리를 나타내는 16비트 부호 없는 short입니다.

진폭 이미지의 각 픽셀은 반환된 신호 강도를 나타내는 16비트 부호 없는 short입니다.

### 6.3 IP 주소

M4 카메라의 기본 IP 주소는 192.168.100.82입니다. IP 주소를 변경하거나 DHCP를 활성화하려면 MRDVS에서 제공하는 데모 애플리케이션을 사용합니다.

### 6.4 데모 애플리케이션

### 6.4.1 IP 구성

전원 케이블을 연결한 다음 이더넷 케이블로 카메라를 컴퓨터에 연결합니다. 카메라의 출고 시 기본 IP 주소가 192.168.100.82이므로 컴퓨터를 192.168.100.x 서브넷(100.82 제외)으로 설정하고 서브넷 마스크를 255.255.255.0으로 지정합니다. **설정** → **이더넷** → **어댑터 옵션 변경**을 엽니다. **이더넷**을 마우스 오른쪽 버튼으로 클릭하고 **속성**을 선택한 다음 **인터넷 프로토콜 버전 4 (TCP/IPv4)**를 선택합니다. 예를 들어 IP 주소를 192.168.100.20, 서브넷 마스크를 255.255.255.0으로 설정합니다.

### 6.4.2 애플리케이션 열기

소프트웨어를 다운로드하여 설치한 다음 LxCameraViwer 데모 아이콘을 두 번 클릭합니다. 호스트 애플리케이션은 카메라가 한 대 연결되면 자동으로 열리고 카메라를 검색한 뒤 열어 데이터 수집을 시작합니다.

**참고: 처음 실행할 때 일부 시스템에서는 방화벽을 통해 애플리케이션을 허용해야 합니다.**

애플리케이션에는 기본 제어, 이미지 선택, 카메라 구성 및 카메라 정보 기능이 있습니다. 카메라 정보에는 IP 주소, ID, MAC 주소, 일련 번호, 소프트웨어 및 알고리즘 버전이 포함됩니다. 깊이, 진폭, RGB 또는 포인트 클라우드 확인란을 선택하면 중앙 패널에 해당 보기가 표시됩니다.

</Frame>

### 6.4.3 이미지 저장

**Save**를 선택하면 선택한 이미지가 설치 디렉터리의 `./data` 폴더에 저장됩니다. 터미널에도 경로가 출력됩니다. 예: `save path= ./data/<camera-ID>`.

저장된 파일명에서 `_a`는 진폭 이미지, `_d`는 깊이 이미지, `_r`은 RGB(MONO) 이미지를 나타냅니다. `.pcd`는 포인트 클라우드를 나타냅니다. 깊이 및 진폭 이미지는 PGM 형식, RGB 이미지는 PNG 형식, 포인트 클라우드는 PCD 형식을 사용합니다.
