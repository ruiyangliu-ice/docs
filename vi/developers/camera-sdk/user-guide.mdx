## Tổng quan

Hướng dẫn này dành cho nhà phát triển tích hợp thiết bị camera. Tài liệu bao quát các API Camera SDK cho các sản phẩm M4, M4 Mega, M4 Pro, V1 Pro, S2, S2 Max và dòng H3. SDK chạy trên x86 Windows và hệ thống x86 hoặc Arm Linux.

Camera SDK cung cấp các API thống nhất để truy cập thiết bị và cấu hình tham số. SDK hỗ trợ thu nhận đồng bộ và bất đồng bộ dữ liệu độ sâu, cường độ, đám mây điểm và RGB. Một số model camera còn cung cấp dữ liệu tránh chướng ngại vật, docking hoặc định vị.

<Info>
  Ví dụ và mô tả API dựa trên phiên bản SDK được cung cấp cùng sản phẩm. Các tham số khả dụng có thể thay đổi theo sản phẩm, firmware và phiên bản SDK.
</Info>

Các ví dụ chỉ nhằm hướng dẫn phát triển và có thể không bao quát mọi thiết bị hoặc trường hợp sử dụng.

#### Kết nối phần cứng

Camera được nối với nguồn điện 24V bên ngoài và kết nối với máy tính chủ bằng cáp mạng như minh họa trong Hình 2.1.

#### Cấu hình mạng

1. Phân đoạn mạng IP mặc định của camera là: 192.168.100.\*
2. Trên máy tính chủ, đặt địa chỉ IP của cổng mạng kết nối với camera thành địa chỉ thuộc phân đoạn mạng 192.168.100.x và đảm bảo không xung đột với thiết bị. Mặt nạ mạng con là 255.255.255.0 như minh họa bên dưới:

<Frame>
  ![Hình minh họa thiết lập môi trường mạng](/images/developers/camera-sdk-user-guide-network-environment-construction.avif)
</Frame>

3. Khi kết nối với camera, nên tắt tường lửa để tránh các gói dữ liệu của camera bị máy chủ chạy SDK chặn, như minh họa trong hình sau:

<Frame>
  ![Hình minh họa thiết lập môi trường mạng 2](/images/developers/camera-sdk-user-guide-network-environment-construction-2.avif)

4. Cấu hình mạng trên Linux giống với Windows. Lệnh tường lửa thay đổi tùy bản phân phối. Trên Ubuntu, chạy:

```bash
sudo systemctl stop ufw.service
sudo systemctl disable ufw.service
sudo ufw status
```

##### Linux

1. Giải nén gói và chạy script cài đặt:

```bash
tar xvf Lanxin-MRDVS-xxx.tar.gz
cd Lanxin-MRDVS
sudo su root
chmod +x install.sh
./install.sh
```

Script cài đặt SDK vào `/opt/Lanxin-MRDVS` và thiết lập biến môi trường cho người dùng hiện tại. Nếu chương trình chạy dưới người dùng khác, hãy chạy lại script cho người dùng đó hoặc thêm dòng sau vào `~/.bashrc` của người dùng đó:

```bash
export LD_LIBRARY_PATH=/opt/Lanxin-MRDVS/lib/:$LD_LIBRARY_PATH
```

Đối với các phiên terminal đã mở trước khi cài đặt, hãy chạy lệnh sau trước khi khởi động chương trình:

```bash
source ~/.bashrc
```

## Yêu cầu khi gọi

### Loại tham số và API tương ứng

1. Với các kiểu enum có tiền tố LX\_INT, sử dụng DcSetIntValue hoặc DcGetIntValue để đặt hoặc lấy tham số kiểu INT;
2. Với các kiểu enum có tiền tố LX\_FLOAT, sử dụng DcSetFloatValue hoặc DcGetFloatValue để đặt hoặc lấy tham số kiểu FLOAT;
3. Với các kiểu enum có tiền tố LX\_BOOL, sử dụng DcSetBoolValue hoặc DcGetBoolValue để đặt hoặc lấy tham số kiểu BOOL;
4. Với các kiểu enum có tiền tố LX\_STRING, sử dụng DcSetStringValue hoặc DcGetStringValue để đặt hoặc lấy tham số kiểu string;
5. Sử dụng DcSetCmd để thực thi lệnh cho các kiểu enum có tiền tố LX\_CMD;
6. Với các kiểu enum có tiền tố LX\_PTR, sử dụng DcGetPtrValue để lấy kết quả kiểu con trỏ;

### Điều kiện trước khi gọi API

<Warning>
  Khi luồng đang hoạt động hoặc khi `LX_INT_WORK_MODE` được đặt ở chế độ luôn bật, không được đặt các chức năng dưới đây.
</Warning>

**1. Khi luồng đã khởi động hoặc chế độ làm việc (LX\_INT\_WORK\_MODE) là chế độ thường mở, không được đặt các chức năng sau:**

- DcSetRoi
- LX\_INT\_3D\_BINNING\_MODE;
- LX\_INT\_2D\_BINNING\_MODE;
- LX\_BOOL\_ENABLE\_2D\_TO\_DEPTH;
- LX\_BOOL\_ENABLE\_MULTI\_EXPOSURE\_HDR;
- LX\_BOOL\_ENABLE\_MULTI\_MACHINE;
- LX\_INT\_TRIGGER\_MODE;
- LX\_INT\_CALCULATE\_UP;
- LX\_BOOL\_ENABLE\_HDR;
- LX\_BOOL\_ENABLE\_TOF\_DEPTH\_CALIBE;
- LX\_BOOL\_ENABLE\_SYNC\_FRAME
- LX\_INT\_SAVE\_PARAMS\_GROUP

**2. Không được đặt tham số ngay cả khi chế độ làm việc (LX\_INT\_WORK\_MODE) là chế độ thường mở:**

- LX\_INT\_TOF\_FREQMODE<br />

**3. Khi bật phơi sáng tự động 3D (LX\_BOOL\_ENABLE\_3D\_AUTO\_EXPOSURE), không được thao tác các enum chức năng sau:**

- LX\_BOOL\_ENABLE\_MULTI\_EXPOSURE\_HDR ;
- LX\_INT\_FIRST\_EXPOSURE;
- LX\_INT\_SECOND\_EXPOSURE;
- LX\_INT\_THIRD\_EXPOSURE;
- LX\_INT\_GAIN;<br />

**4. Khi tắt phơi sáng tự động 3D (LX\_BOOL\_ENABLE\_3D\_AUTO\_EXPOSURE), không được thao tác enum chức năng sau:**

- LX\_INT\_3D\_AUTO\_EXPOSURE\_LEVEL

Không được đặt giá trị lớn nhất (LX\_INT\_3D\_AUTO\_EXPOSURE\_MAX) và giá trị nhỏ nhất của phơi sáng tự động 3D

- (LX\_INT\_3D\_AUTO\_EXPOSURE\_MIN)

**5. Khi bật phơi sáng tự động 2D (LX\_BOOL\_ENABLE\_2D\_AUTO\_EXPOSURE), không được thao tác enum chức năng sau:**

- LX\_INT\_2D\_MANUAL\_EXPOSURE

<br />**6. Khi tắt phơi sáng tự động 2D (LX\_BOOL\_ENABLE\_2D\_AUTO\_EXPOSURE), không được thao tác enum chức năng sau:**

- LX\_INT\_2D\_AUTO\_EXPOSURE\_LEVEL;

<br />7.**Trong chế độ lọc đặc biệt, không được đặt các tham số sau:**

- LX\_INT\_FILTER\_SMOOTH\_LEVEL LX\_INT\_FILTER\_NOISE\_LEVEL
- LX\_INT\_FILTER\_TIME\_LEVEL

<br />8.**Khi bật khử méo 2D, trước tiên phải bật căn chỉnh RGB-D:**

- LX\_BOOL\_ENABLE\_2D\_TO\_DEPTH

<br />9.**Với thiết bị không thuộc loại S2, khi bật thuật toán tích hợp, trước tiên phải đặt thuật toán tof. Chỉ được đặt tham số thuật toán khi thuật toán tích hợp (LX\_INT\_ALGORITHM\_MODE) đã bật.**

- (LX\_STRING\_ALGORITHM\_PARAMS)

<br />10.**Để lấy dữ liệu đám mây điểm (LX\_PTR\_XYZ\_DATA), trước tiên phải bật bản đồ độ sâu**

- (LX\_BOOL\_ENABLE\_3D\_DEPTH\_STREAM)

## Kiểu dữ liệu

### 5.1 LX\_STATE

Chức năng: mã trạng thái giá trị trả về của hàm giao diện SDK

| Từ khóa | Mô tả |
| --- | --- |
| LX\_SUCCESS | Thực thi hàm thành công |
| LX\_ERROR | Thực thi hàm thất bại |
| LX\_E\_NOT\_SUPPORT | Camera đã kết nối không hỗ trợ chức năng này |
| LX\_E\_NETWORK\_ERROR | Lỗi giao tiếp mạng |
| LX\_E\_INPUT\_ILLEGAL | Tham số hàm truyền vào không hợp lệ |
| LX\_E\_RECONNECTING | Thiết bị đang kết nối lại |
| LX\_E\_DEVICE\_ERROR | Lỗi thiết bị |
| LX\_E\_DEVICE\_NEED\_UPDATE | Phiên bản thiết bị quá thấp, cần nâng cấp firmware |
| LX\_E\_API\_NEED\_UPDATE | Phiên bản API quá thấp, cần nâng cấp SDK |
| LX\_E\_CTRL\_PERMISS\_ERROR | Quyền điều khiển độc quyền thất bại (thiết bị chỉ có thể có một kết nối SDK tại một thời điểm) |
| LX\_E\_GET\_DEVICEINFO\_ERROR | Không lấy được thông tin thiết bị |
| LX\_E\_IMAGE\_SIZE\_ERROR | Kích thước ảnh không khớp, hãy mở lại camera |
| LX\_E\_IMAGE\_PARTITION\_ERROR | Phân tích ảnh thất bại |
| LX\_E\_DEVICE\_NOT\_CONNECTED | Camera chưa kết nối |
| LX\_E\_DEVICE\_INIT\_FAILED | Khởi tạo camera thất bại |
| LX\_E\_DEVICE\_NOT\_FOUND | Không tìm thấy camera phù hợp |
| LX\_E\_FILE\_INVALID | Lỗi tệp (sai tên, kiểu hoặc định dạng tệp) |
| LX\_E\_CRC\_CHECK\_FAILED | Xác minh crc hoặc md5 của tệp thất bại |
| LX\_E\_TIME\_OUT | Hết thời gian chờ |
| LX\_E\_FRAME\_LOSS | Thiếu khung hình |
| LX\_E\_ENABLE\_ANYSTREAM\_FAILED | Không mở được bất kỳ luồng nào |
| LX\_E\_NOT\_RECEIVE\_STREAM | Chưa nhận được dữ liệu luồng |
| LX\_E\_PARSE\_STREAM\_FAILED | Đã khởi động luồng nhưng phân tích dữ liệu luồng thất bại |
| LX\_E\_PROCESS\_IMAGE\_FAILED | Xử lý tính toán ảnh thất bại |
| LX\_E\_SETTING\_NOT\_ALLOWED | Không được phép đặt trong chế độ thường mở |
| LX\_E\_LOAD\_DATAPROCESSLIB\_ERROR | Lỗi tải thư viện thuật toán xử lý ảnh |
| LX\_E\_FUNCTION\_CALL\_LOGIC\_ERROR | Lỗi logic khi gọi hàm |
| LX\_E\_IPAPPDR\_UNREACHABLE\_ERROR | Không thể truy cập IP hoặc lỗi cấu hình mạng |
| LX\_E\_FRAME\_ID\_NOT\_MATCH | Lỗi lệch đồng bộ khung hình trong khoảng thời gian chờ |
| LX\_E\_FRAME\_MULTI\_MACHINE | Phát hiện tín hiệu nhiễu đa máy trong khung hình |

### 5.2 LX\_DATA\_TYPE

Chức năng: định dạng dữ liệu. Bản đồ cường độ 3D và bản đồ độ sâu có định dạng dữ liệu khác nhau. Để lấy con trỏ dữ liệu, cần sử dụng feature tương ứng.

| Từ khóa | Mô tả |
| --- | --- |
| LX\_DATA\_UNSIGNED\_CHAR | Kiểu ký tự không dấu |
| LX\_DATA\_UNSIGNED\_SHORT | Số nguyên short không dấu |
| LX\_DATA\_SIGNED\_SHORT | Số short có dấu |
| LX\_DATA\_FLOAT | Kiểu số dấu phẩy động |
| LX\_DATA\_OBSTACLE | Kiểu cấu trúc thuật toán tránh chướng ngại vật |
| LX\_DATA\_PALLET | Kiểu cấu trúc thuật toán pallet |
| LX\_DATA\_LOCATION | Kiểu cấu trúc thuật toán định vị trực quan |
| LX\_DATA\_OBSTACLE | Kiểu cấu trúc thuật toán tránh chướng ngại vật V2 |

Chức năng:
