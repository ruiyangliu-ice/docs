## Panoramica

Questa guida è destinata agli sviluppatori che integrano dispositivi fotografici. Copre le API di Camera SDK per i prodotti delle serie M4, M4 Mega, M4 Pro, V1 Pro, S2, S2 Max e H3. L’SDK funziona su Windows x86 e su Linux x86 o Arm.

Camera SDK fornisce API unificate per l’accesso ai dispositivi e la configurazione dei parametri. Supporta l’acquisizione sincrona e asincrona di dati di profondità, intensità, nuvole di punti e RGB. Alcuni modelli forniscono anche dati per l’evitamento degli ostacoli, l’aggancio o la localizzazione.

<Info>
  Gli esempi e le descrizioni delle API si basano sulla versione dell’SDK distribuita con il prodotto. I parametri disponibili possono variare in base al prodotto, al firmware e alla versione dell’SDK.
</Info>

Gli esempi sono indicazioni per lo sviluppo e potrebbero non coprire tutti i dispositivi o casi d’uso.

## Configurazione dell’ambiente

### Configurazione host consigliata

| Voce di configurazione | Configurazione consigliata |
| --- | --- |
| Sistema operativo | Windows 7, Windows 10 o Windows 11; Ubuntu 16.04 o versioni successive |
| Memoria | 4 GB o più |
| CPU | Cortex-A57 quad-core o equivalente e superiore |
| Scheda di rete | Gigabit Ethernet o superiore |

### Connessione e installazione

#### Connessione hardware

Collega la fotocamera a un’alimentazione esterna da 24 V e al computer host tramite un cavo di rete, come mostrato nella Figura 2.1.

<Frame>
  ![Illustrations correlato a hardware ambiente construction](/images/developers/camera-sdk-user-guide-hardware-environment-construction.avif)
</Frame>

Figura 2.1 Diagramma del collegamento della fotocamera

#### Configurazione di rete

1. Il segmento di rete IP predefinito della fotocamera è 192.168.100.\*.
2. Sul computer host, imposta l’indirizzo IP della porta di rete collegata alla fotocamera su un indirizzo del segmento 192.168.100.x e assicurati che non entri in conflitto con il dispositivo. La subnet mask è 255.255.255.0, come mostrato nella figura seguente:

<Frame>
  ![Illustrations correlato a network ambiente construction](/images/developers/camera-sdk-user-guide-network-environment-construction.avif)
</Frame>

3. Quando colleghi la fotocamera, ti consigliamo di disattivare il firewall per impedire che i pacchetti dati della fotocamera vengano intercettati dall’host su cui si trova l’SDK, come mostrato nella figura seguente:

<Frame>
  ![Illustrations correlato a network ambiente construction 2](/images/developers/camera-sdk-user-guide-network-environment-construction-2.avif)
</Frame>

4. La configurazione di rete di Linux è uguale a quella di Windows. I comandi del firewall variano in base alla distribuzione. Su Ubuntu, esegui:

```bash
sudo systemctl stop ufw.service
sudo systemctl disable ufw.service
sudo ufw status
```

##### Linux

1. Decomprimi il pacchetto ed esegui lo script di installazione:

```bash
tar xvf Lanxin-MRDVS-xxx.tar.gz
cd Lanxin-MRDVS
sudo su root
chmod +x install.sh
./install.sh
```

Lo script installa l’SDK in `/opt/Lanxin-MRDVS` e configura le variabili d’ambiente per l’utente corrente. Se il programma viene eseguito da un altro utente, esegui nuovamente lo script per quell’utente oppure aggiungi la riga seguente al relativo `~/.bashrc`:

```bash
export LD_LIBRARY_PATH=/opt/Lanxin-MRDVS/lib/:$LD_LIBRARY_PATH
```

Per le sessioni del terminale aperte prima dell’installazione, esegui il comando seguente prima di avviare il programma:

```bash
source ~/.bashrc
```

## Requisiti per le chiamate

### Tipi di parametro e API corrispondenti

1. For enumeration types prefixed con LX\_INT, utilizzare DcSetIntValue o DcGetIntValue a impostare o ottenere INT tipo parametri;
2. For enumeration types prefixed con LX\_FLOAT, utilizzare DcSetFloatValue o DcGetFloatValue a impostare o ottenere FLOAT tipo parametri;
3. For enumeration types prefixed con LX\_BOOL, utilizzare DcSetBoolValue o DcGetBoolValue a impostare o ottenere BOOL tipo parametri;
4. For enumeration types prefixed con LX\_STRING, utilizzare DcSetStringValue o DcGetStringValue a impostare o ottenere string tipo parametri;
5. Use DcSetCmd a execute instructions per enumeration types prefixed con LX\_CMD;
6. For enumeration types prefixed con LX\_PTR, utilizzare DcGetPtrValue a obtain pointer tipo risultati;

### Precondizioni delle API

<Warning>
  When streaming è active, o quando `LX_INT_WORK_MODE` è impostare a always-on mode, do not impostare il functions listed below.
</Warning>

- DcSetRoi
- LX\_INT\_3D\_BINNING\_MODE;
- LX\_INT\_2D\_BINNING\_MODE;
- LX\_BOOL\_ENABLE\_2D\_TO\_DEPTH;
- LX\_BOOL\_ENABLE\_MULTI\_EXPOSURE\_HDR;
- LX\_BOOL\_ENABLE\_MULTI\_MACHINE;
- LX\_INT\_TRIGGER\_MODE;
- LX\_INT\_CALCULATE\_UP;
- LX\_BOOL\_ENABLE\_HDR;
- LX\_BOOL\_ENABLE\_TOF\_DEPTH\_CALIBE;
- LX\_BOOL\_ENABLE\_SYNC\_FRAME
- LX\_INT\_SAVE\_PARAMS\_GROUP

**2. Settings sono not allowed even quando il working mode (LX\_INT\_WORK\_MODE) è normally aprire:**

- LX\_INT\_TOF\_FREQMODE<br />

**3. When 3D automatic exposure (LX\_BOOL\_ENABLE\_3D\_AUTO\_EXPOSURE) è turned on, il seguente funzione enumeration operations sono not allowed:**
