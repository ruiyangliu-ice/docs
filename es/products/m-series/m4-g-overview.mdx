M4-G es una cámara RGB-D iToF para percepción a corta distancia. Utiliza una interfaz GMSL2 y puede generar datos de profundidad, RGB y nube de puntos a una frecuencia típica de 30 fps dentro de un rango de 0,05–1 m. Entre sus aplicaciones habituales se incluyen muñecas robóticas, agarre sobre mesas y manipulación de precisión.

## Características principales

- **Detección de profundidad iToF a corta distancia:** genera datos de profundidad dentro de un rango de 0,05–1 m.
- **Salida RGB-D sincronizada:** proporciona mapas de profundidad, imágenes RGB y nubes de puntos con alineación RGB.
- **Rendimiento con poca luz:** la iluminación activa permite trabajar con objetivos con poca iluminación o textura limitada.
- **Transmisión GMSL2:** proporciona un enlace de datos de larga distancia y resistente a interferencias para la integración del sistema.

## Interfaz GMSL2

### Configuración del serializer

| Elemento | Parámetro |
| --- | --- |
| Serializer | MAX96717 |
| Dirección I²C | `0x40` (7 bits) |
| Velocidad GMSL | GMSL2, 6 Gbps |
| Modo de funcionamiento | Modo de píxeles |
| Sincronización de fotogramas | Controlada por MAX96717 MFP0 |

### Parámetros del flujo de vídeo

| Flujo | Resolución y formato | Tipo de datos | Control y canal virtual |
| --- | --- | --- | --- |
| ToF | 2560 × 960, RAW8 | `0x2A` | I²C reenviado por FPGA; VC0 |
| RGB | 1280 × 1080, YUV422, 8 bits | `0x1E` | I²C reenviado por FPGA; VC1 |

### Configuración de FPGA

| Elemento | Parámetro |
| --- | --- |
| Dirección I²C | `0x11` (7 bits) |
| Salida MIPI | 4 carriles, 1,2 Gbps |

## Iniciar la transmisión

La captura de imágenes requiere tanto la sincronización de fotogramas por hardware como el control del flujo.

<Steps>
  <Step title="Proporcionar una señal de sincronización de fotogramas">
    Configura la sincronización de fotogramas entre MAX96717 y el deserializer seleccionado según los manuales de hardware. MFP0 de MAX96717 se puede configurar como salida de disparo GPIO.

    <Frame>
      ![Transmisión de la señal de sincronización de fotogramas de la serie MAX96724](/images/products/m-series-m4-g-overview-2-max96724-f-r-frame-sync-signal-transmission.avif)
    </Frame>
  </Step>
  <Step title="Enviar el comando de inicio del flujo">
    Escribe `1` en el registro FPGA `0x2000` para iniciar la transmisión, o escribe `0` para detenerla.

    ```bash
    i2ctransfer -f -y 4 w3@0x11 0x20 0x00 1
    ```

    En este ejemplo, `0x11` es la dirección I²C de FPGA.
  </Step>
</Steps>
