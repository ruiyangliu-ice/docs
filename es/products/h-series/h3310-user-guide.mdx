## Términos y principio de funcionamiento

### Términos comunes

| Término | Descripción |
| --- | --- |
| Línea base | Distancia horizontal entre los centros ópticos de las dos unidades de captura estereoscópica. |
| Profundidad | Datos que representan la distancia desde cada píxel hasta la cámara. |
| FOV | Campo de visión, incluidos los ángulos horizontal, vertical y diagonal. |
| Cámara IR | Cámara utilizada para la captura de imágenes en el infrarrojo cercano. |
| Cámara RGB | Cámara de captura de imágenes en color. |
| Cámara de profundidad | Sistema de captura de imágenes que proporciona datos de profundidad, normalmente compuesto por unidades de proyección, captura de imágenes y procesamiento de profundidad. |
| SoC | System-on-chip utilizado para el procesamiento de imágenes, el cálculo de profundidad y los algoritmos de aplicación. |

## Descripción general del producto

H3310 es una cámara industrial RGB-D de luz estructurada que pesa 400 g. Puede instalarse en un robot compuesto o en un brazo robótico pequeño. En un rango de funcionamiento de 300–600 mm, la cámara proporciona datos de profundidad y RGB de alta precisión, además de una plataforma informática integrada para algoritmos de aplicación.

<Frame>
  ![Cámara H3310](/images/products/h-series-h3310-user-guide-h3310-camera.avif)
</Frame>

### Características

- Plataforma informática integrada de 6.0 TOPS para algoritmos de aplicación.
- Salida de imágenes de profundidad, RGB y amplitud.
- Interfaces abiertas para la integración con brazos robóticos y robots móviles.

</Warning>

## Preguntas frecuentes

<AccordionGroup>
  <Accordion title="La aplicación host no puede abrir la cámara">
    Confirma que el firewall del host no esté bloqueando la conexión y, a continuación, comprueba la alimentación de la cámara y la conectividad de red.
  </Accordion>

  <Accordion title="Aparecen varias direcciones IP en la lista de dispositivos">
    Puede haber varios dispositivos detectables en la LAN. Selecciona la dirección IP que corresponda a la cámara de destino.
  </Accordion>

  <Accordion title="La transmisión de datos es inestable">
    Utiliza un cable Ethernet Gigabit. Una red de 100 Mbps puede provocar inestabilidad inicial en la transmisión.
  </Accordion>

  <Accordion title="El software no puede ejecutarse después de la instalación">
    Si el software está instalado en un directorio restringido, comprueba los permisos de acceso a los archivos y de ejecución del programa.
  </Accordion>
</AccordionGroup>
