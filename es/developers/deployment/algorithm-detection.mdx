Esta guía cubre la implementación, calibración, configuración e integración de resultados de los algoritmos MRDVS de detección humana, de ubicaciones de almacenamiento y de volumen. El algoritmo se ejecuta en la cámara; la aplicación host del algoritmo se utiliza para la configuración, las actualizaciones y la inspección de resultados.

<Info>
  El firmware del algoritmo y la aplicación host del algoritmo se entregan por proyecto. Antes de instalar el firmware del algoritmo, confirma que la cámara ejecute una versión de firmware MDS. Obtén un paquete de instalación que coincida con el proyecto y el modelo de cámara.
</Info>

## Alcance compatible

### Componentes del sistema

| Componente | Función |
| --- | --- |
| Cámara 3D | Captura imágenes RGB y nubes de puntos y ejecuta el algoritmo de detección en la cámara. |
| Aplicación host del algoritmo | Configura algoritmos, calibra parámetros extrínsecos, muestra resultados y actualiza el firmware del algoritmo. |
| PC industrial o sistema de nivel superior | Ejecuta la aplicación host o lee resultados mediante una interfaz de red. |
| LiDAR | `mid360`, utilizado para la configuración de la solución original basada en radar. |

### Algoritmos y cámaras

| Algoritmo | Cámara compatible |
| --- | --- |
| Detección humana | M4 Pro |
| Detección de ubicaciones de almacenamiento | S10 Pro |
| Detección de volumen | S10 y S10 Pro |

Para obtener información del producto, consulta la [página del producto de la cámara 3D S10](/es/products/s-series/s10-overview).

## Implementación de hardware y red

### Instalar la cámara

Usa un soporte rígido para evitar movimientos o vibraciones después de la instalación. La detección humana normalmente utiliza una instalación horizontal o una instalación con un ángulo no superior a 30°.

<Frame>
  ![Ejemplos de instalación del soporte de la cámara](/images/developers/deployment-algorithm-detection-camera-installation-methods.avif)
</Frame>

### Conectar los dispositivos

<Steps>
  <Step title="Conectar la alimentación y la red">
    Alimenta la cámara con una fuente regulada de 24 V DC. Usa un cable Cat6A o Cat7 para conectar la cámara a un switch gigabit o a un controlador.
  </Step>
  <Step title="Implementar varias cámaras">
    Instala cada cámara a la altura y en la posición especificadas en el plano CAD. Conecta todas las cámaras mediante un switch gigabit y verifica el estado de alimentación y de enlace de cada una.
  </Step>
  <Step title="Preparar los objetivos de prueba">
    Coloca en la vista de la cámara las personas, los palés o las mercancías que se van a detectar antes de calibrar los parámetros extrínsecos y configurar las regiones.
  </Step>
</Steps>

### Configurar la red del host

Coloca el ordenador host y la cámara en la misma subred. El ejemplo original utiliza el siguiente plan:

| Elemento | Ejemplo |
| --- | --- |
| Dirección IP del host | `192.168.100.xxx` |
| Máscara de subred | `255.255.255.0` |
| Puerta de enlace predeterminada | `192.168.100.1` |

<Steps>
  <Step title="Abrir la configuración del adaptador">
    En Windows, abre **Panel de control → Centro de redes y recursos compartidos → Cambiar configuración del adaptador** y selecciona el adaptador Ethernet conectado a la cámara.
  </Step>
  <Step title="Configurar IPv4">
    Abre **Protocolo de Internet versión 4 (TCP/IPv4)**, selecciona **Usar la siguiente dirección IP** e introduce una dirección estática sin utilizar en la subred de la cámara.
  </Step>
  <Step title="Confirmar la conexión">
    Guarda la configuración, confirma que el enlace sea gigabit y utiliza la aplicación host para descubrir o abrir la cámara.
  </Step>
</Steps>

  </Frame>

</Warning>

## Instalar y actualizar el software

### Instalar las aplicaciones host

1. Obtén la aplicación host de la cámara desde la página de [descargas de software](https://zcnt5g3o2989.feishu.cn/wiki/Q8IYwGiGaiIvIyktiavczymanOe?from=from_copylink "Descargas de software").
2. Instala la aplicación host de la cámara fuera de la unidad del sistema.
3. Copia los archivos de la aplicación host del algoritmo entregados para el proyecto en la carpeta `Tools` del directorio de la aplicación host de la cámara. Reemplaza los archivos con el mismo nombre y, después, haz doble clic en el ejecutable para iniciarlo.

<Frame>
  ![Instalación de la aplicación host de la cámara](/images/developers/deployment-algorithm-detection-picture-2.avif)
</Frame>

Para actualizar solo la aplicación host del algoritmo, reemplaza su archivo `.exe` por la versión entregada.

### Actualizar el firmware del algoritmo

<Warning>
  La cámara se reinicia durante la instalación. No desconectes la alimentación ni la red y no cierres la aplicación host. El paquete debe coincidir con el modelo de cámara, la versión de firmware MDS y el algoritmo del proyecto.
</Warning>

<Tabs>
  <Tab title="Aplicación host de la cámara">
    1. Inicia `LxCameraViewer.exe` y abre la cámara.
    2. Selecciona **Herramientas básicas → Configuración de funciones → Actualización de firmware**.
    3. Elige el archivo de algoritmo de detección entregado y selecciona **Ejecutar**.
  </Tab>
  <Tab title="Aplicación host del algoritmo">
    1. Selecciona la cámara de destino en la lista de dispositivos.
    2. Selecciona **Actualizar firmware**, elige el archivo de algoritmo de detección y ábrelo.
    3. Espera a que la cámara vuelva a aparecer en la lista de dispositivos.
  </Tab>
</Tabs>

Cuando la cámara vuelva a aparecer después de reiniciarse, la instalación habrá terminado. Un fondo verde en la cámara dentro de la aplicación host del algoritmo indica que la cámara está conectada y que el algoritmo está disponible.

| Función | Descripción |
| --- | --- |
| RGB | Muestra la imagen RGB. |
| Nube de puntos | Muestra la nube de puntos. |
| Detener algoritmo | Detiene el algoritmo actual. No se reinicia automáticamente hasta que la cámara vuelva a encenderse. |

Si el fondo del dispositivo es amarillo, o es verde pero la imagen no se actualiza, activa la actualización automática para reanudar la adquisición de imágenes.

## Calibración extrínseca

### Configuración de la cámara

| Configuración | Descripción |
| --- | --- |
| Nombre de la cámara | Identifica una cámara en una implementación con varias cámaras. |
| Modo de simulación | Función interna; déjalo desactivado. |
| Modo de guardado de imágenes | Guarda los datos de imagen del algoritmo en la cámara. |
| Modo de adquisición de imágenes | `MDS` no ocupa el acceso a la cámara. `SDK` sí lo ocupa; la aplicación host no puede abrir la cámara mientras se ejecuta el algoritmo. |
| `x`, `y`, `z` | Posición extrínseca de la cámara; `z` es la altura de la cámara sobre el suelo. |
| `roll`, `pitch`, `yaw` | Ángulos de orientación extrínseca de la cámara. |
| Suelo ideal | Conserva el valor predeterminado. |
| Leer configuración de la cámara | Lee la configuración actual de la cámara. |
| Guardar y enviar | Escribe los cambios en la cámara. Los parámetros no guardados no tienen efecto. |
| Calibración extrínseca | Calibra la altura y la orientación de la cámara. |

## Implementar un algoritmo

Cambia al modo de nube de puntos y desplázate sobre el área de imagen para mostrar los datos de la nube de puntos.

### Detección humana

<Steps>
  <Step title="Calibrar una instalación horizontal">
    Alinea los ejes `X` e `Y` con la nube de puntos del suelo. El eje `Z` debe ser perpendicular al suelo y apuntar hacia arriba.
  </Step>
  <Step title="Configurar los parámetros globales">
    Abre **Detección humana**. Normalmente solo es necesario configurar **Detección de rotación**. La rotación horaria de la cámara admite `0°`, `90°`, `180°` y `270°`.
  </Step>
  <Step title="Crear la región de detección">
    Selecciona **Añadir región de detección**, establece los valores `X`, `Y` y `Z` mínimos y máximos y mueve la región sobre el objetivo. El ejemplo original utiliza una región de `1000 × 1000 × 2000 mm`.
  </Step>
  <Step title="Guardar y verificar">
    Selecciona **Guardar y enviar**, ejecuta una prueba de paso de una persona por el área y verifica el resultado en la barra de estado o en la reproducción histórica.
  </Step>
</Steps>

| Regla de coincidencia | Sin persona | Persona | Obstáculo | Persona y obstáculo |
| --- | --- | --- | --- | --- |
| Solo profundidad | `0` | `2` | `2` | `2` |
| Semántica más profundidad | `0` | `1` | `0` | `1` |

El modo de solo profundidad informa de todos los objetos de la región. El modo semántica más profundidad solo informa de los grupos clasificados como personas.

### Detección de ubicaciones de almacenamiento

<Steps>
  <Step title="Calibrar la cámara">
    Sigue el procedimiento de calibración extrínseca. Alinea `X` e `Y` con el suelo y mantén `Z` perpendicular y apuntando hacia arriba.
  </Step>
  <Step title="Configurar los parámetros globales">
    Configura **Comprobación de alineación**, **Ángulo de alineación** y **Cantidad mínima de puntos** para el sitio. Activa la comprobación de alineación cuando la carga deba colocarse con un ángulo definido.
  </Step>
  <Step title="Crear ubicaciones de almacenamiento">
    En el modo de nube de puntos, selecciona **Añadir ubicación de almacenamiento**, cambia a la vista superior y pulsa `X` para iniciar o detener el dibujo. Arrastra el rectángulo sobre el palé y ajusta los límites `X`, `Y` y `Z`. Pulsa `X` de nuevo para salir del modo de dibujo.
  </Step>
  <Step title="Guardar y verificar">
    Selecciona **Guardar y enviar**. Configura las ubicaciones en el modo RGB 2D o nube de puntos 3D y comprueba `Resultado` en la barra de estado.
  </Step>
</Steps>

<Frame>
  ![Dibujo de una región de ubicación de almacenamiento en modo de nube de puntos](/images/developers/deployment-algorithm-detection-point-cloud-mode-location-setting-4.avif)
</Frame>

| Estado de la ubicación de almacenamiento | `Resultado` |
| --- | --- |
| Vacía | `0` |
| Ocupada, u ocupada y alineada | `1` |
| Ocupada con un ángulo superior al umbral de alineación | `2` |
| Ocupada y fuera de los límites de la ubicación | `3` |

Para una disposición regular, utiliza **Copiar cuadro actual** para crear ubicaciones con una dirección y un espaciado fijos. Si se requiere verificación mediante código QR, usa **Calibración con código QR** para configurar las dimensiones de la ubicación y el rango de profundidad.

### Detección de volumen

<Steps>
  <Step title="Calibrar una instalación vertical">
    La detección de volumen funciona de arriba hacia abajo. Después de la calibración, el eje `Z` apunta hacia abajo y el plano `X`/`Y` es paralelo al suelo.
  </Step>
  <Step title="Configurar el plano de detección">
    Para mercancías colocadas directamente en el suelo, establece el plano de detección a la altura del suelo. Para medir solo mercancías sobre un palé, alinea el plano con la nube de puntos del palé.
  </Step>
  <Step title="Configurar las dimensiones mínimas y la región">
    Establece los valores mínimos de `X`, `Y` y `Z` para filtrar objetivos pequeños. Después, configura los límites de la región según el plano de detección y las dimensiones de la carga.
  </Step>
  <Step title="Guardar y verificar">
    Selecciona **Guardar y enviar**, coloca uno o varios objetos en la región y verifica la longitud, la anchura, la altura y la cantidad devueltas.
  </Step>
</Steps>

## Interfaces de comunicación

<Note>
  La dirección IP de los ejemplos es ilustrativa. Reemplázala por la dirección de la cámara en el sitio y, después, verifica la red, el estado del algoritmo y el formato de los resultados antes de integrarlos con un sistema de nivel superior.
</Note>

### Métodos de transporte

| Protocolo | Puerto | Solicitud | Uso |
| --- | --- | --- | --- |
| TCP | `14951` | `RESULT_UPDATE` | Obtiene el resultado actual del algoritmo. |
| UDP | `14950` | `RESULT_UPDATE` | Obtiene el resultado actual del algoritmo. |
| HTTP | `14952` | `RESULT_UPDATE` | Obtiene el resultado del algoritmo como JSON. |
| TCP/UDP | Puerto de resultados | `TM_TRIGGER` | Ejecuta una detección de volumen activada y devuelve el resultado. |
| Modbus TCP | `16502` | Leer registros de retención | Lee el estado de las ubicaciones de almacenamiento. |

### Solicitud de resultados HTTP

El sistema de nivel superior envía una solicitud de resultados al endpoint de visión, que devuelve una cadena JSON. Utiliza en tu cliente HTTP las cabeceras de solicitud entregadas para el proyecto y el siguiente cuerpo de solicitud.

<ParamField body="command" default="RESULT_UPDATE" type="string" required>
  Activa la cámara para que devuelva el resultado actual del algoritmo.
</ParamField>

### Campos de respuesta comunes

<ResponseField name="IP" type="string" required>
  Dirección IP de la cámara que generó los datos.
</ResponseField>

<ResponseField name="nick_name" type="string" required>
  Nombre de la cámara; cámbialo en la configuración de la cámara.
</ResponseField>

<ResponseField name="ret_code" type="integer" required>
  Código de retorno; `0` indica éxito.
</ResponseField>

<Tabs>
  <Tab title="Detección humana (SG)">
    <ResponseField name="SG" type="object" required>
      Objeto de estado indexado por el ID de la región de detección: `0` significa que no hay objetivo, `1` que se ha detectado una persona y `2` que un objeto se ha detectado solo mediante la regla de profundidad.
    </ResponseField>

    <ResponseField name="__object_details" type="string[]">
      Detalles de los grupos. Cada elemento es una cadena JSON que debe deserializarse de nuevo.

    <ResponseField name="SG_DATA_TIME" type="string">

### Modbus TCP (detección de ubicaciones de almacenamiento)

Los resultados se ordenan por ID de ubicación de almacenamiento; como máximo se devuelven las primeras 16 ubicaciones.

| Configuración | Valor |
| --- | --- |
| Puerto | `16502` |
| Dirección de escucha | `0.0.0.0` (todas las interfaces de red) |
| Cantidad de registros | `16` |
| Dirección inicial | `0x0100` |
| Orden de bytes | Big-endian |

| Registro | Contenido | Formato de datos |
| --- | --- | --- |
| `0x0100 + ID` | Resultados de detección de ubicación de almacenamiento y marcador | `uint16_t` de 2 bytes |
| 8 bits altos | Código de estado de la ubicación de almacenamiento | `0–2` |
| 8 bits bajos | Código de estado del marcador | `0–2`; esta función no está disponible actualmente, por lo que tiene el mismo significado que el código de estado de la ubicación. |

| Estado de la ubicación | Significado | Condición |
| --- | --- | --- |
| `0` | Vacía | No hay mercancía ni palé. |
| `1` | Ocupada normalmente | La mercancía está colocada según lo requerido. |
| `2` | Ocupada de forma anómala | El tamaño o la posición de la carga no cumplen el requisito. |

| Estado del marcador | Significado |
| --- | --- |
| `0` | Marcador no detectado. |
| `1` | Marcador detectado. |
| `2` | Error de detección del marcador. |

#### Leer la cuarta ubicación de almacenamiento

El siguiente ejemplo utiliza el ID de transacción `0x0001` para leer un registro de retención en la dirección `0x0104`. La respuesta contiene el estado `0x0002`.

```text
Request: 00 01 00 00 00 06 FF 03 01 04 00 01
Response: 00 01 00 00 00 05 FF 03 02 00 02
```

| Campo | Valor de solicitud | Descripción |
| --- | --- | --- |
| Identificador de transacción | `00 01` | Número de secuencia del cliente; la respuesta debe coincidir con él. |
| Identificador de protocolo | `00 00` | Valor fijo de Modbus/TCP. |
| Longitud | `00 06` | Cantidad de bytes de los campos de solicitud siguientes. |
| Identificador de unidad | `FF` | Modo de difusión o dirección del dispositivo. |
| Código de función | `03` | Leer registros de retención. |
| Dirección inicial | `01 04` | `0x0100 + 4`. |
| Cantidad de registros | `00 01` | Leer un registro. |

## Solución de problemas

| Síntoma | Comprobaciones prioritarias |
| --- | --- |
| No se encuentra la cámara | Confirma que el host y la cámara compartan una subred, que el adaptador de red sea gigabit y que los enlaces de alimentación y del switch estén en buen estado. |
| Los parámetros no tienen efecto | Confirma que se haya seleccionado **Guardar y enviar** después del cambio. |
| No hay resultados del algoritmo | Confirma que se haya instalado el firmware del algoritmo correcto, que el dispositivo esté en verde y que el algoritmo esté activado. |
| Nube de puntos vacía o desactualizada | Desplázate sobre el área de nube de puntos para mostrar los datos; activa la actualización automática si es necesario. |
| Resultados anómalos de ubicación o volumen | Vuelve a comprobar las direcciones de los ejes extrínsecos, el plano de detección y los límites de la región y, después, repite la prueba con objetos del sitio. |
