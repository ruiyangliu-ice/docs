## Descripción general

El SDK de cámara MRDVS para Linux incluye ejemplos de C/C\+\+, Java (servicio HTTP), ROS y ROS 2. Los ejemplos muestran el flujo de trabajo básico del SDK; añade la lógica específica de tu aplicación y el control de errores para tu proyecto.

Completa primero la configuración del entorno, el script de instalación y las comprobaciones del directorio de ejemplos. Después, sigue la sección de compilación y ejecución correspondiente a tu lenguaje de destino. El apéndice enumera métodos de instalación para dependencias comunes y paquetes de prueba.

Se admiten los siguientes sistemas Linux. A continuación se indican las versiones predeterminadas de los programas:

| Versión del sistema | Cmake/Gcc | Opencv | Pcl | Ros | Ros2 |
| --- | --- | --- | --- | --- | --- |
| Ubuntu16.04 | 3.5/Gcc-5 | 3.2.0 | 1.7.2 | Kinetic | Ardent、Bouncy |
| Ubuntu18.04 | 3.18/Gcc-7 | 4.5.1 | 1.9.1 | Melodic | Dashing、Eloquent、Crystal |
| Ubuntu20.04 | 3.22/9.3.0 | 4.5.1 | 1.12.1 | Noetic | Foxy、Galactic |
| Ubuntu22.04 | 3.22/11.3.0 | 4.6.0 | 1.12.1 | Ninjemys | Humble、lron |

Contiene 9 carpetas y 1 archivo Cmakelist; cada carpeta contiene un archivo cpp.

Las funciones implementadas aproximadamente por cada cpp son las siguientes:

- application\_pallet: obtiene datos del flujo de la cámara, activa el algoritmo de palés y muestra los resultados del algoritmo
- arm\_local\_camera: llama al SDK en la cámara \[ARM\] y obtiene los datos del flujo
- frame\_callback: utiliza el método de callback para obtener datos del flujo de la cámara
- multi\_cameras: abre varias cámaras y obtiene datos del flujo
- single\_camera: abre una sola cámara y obtiene datos del flujo
- single\_camera2: obtiene datos de fotogramas mediante una estructura

Puedes seleccionar distintos códigos de ejemplo para probarlos y modificarlos según tus necesidades.

### 4.4 Compilar y ejecutar el código de ejemplo de ROS 2

<Frame>

El nodo de ROS de ejemplo se compila mediante colcon.

Primero, instala las herramientas de compilación:

```bash
sudo apt install python3-colcon-common-extensions
```

<Frame>
  ![Ilustraciones relacionadas con la compilación y ejecución del código de ejemplo de ROS 2 2](/images/developers/camera-sdk-linux-examples-compiling-and-running-ros2-sample-code-2.avif)

Después de la instalación, entra en el directorio `lx_camera_node_ws` y compila el proyecto:

```bash
colcon build
```

Según el rendimiento del equipo, la compilación suele tardar entre 30 y 120 segundos. Tras una compilación correcta, se mostrará lo siguiente:

<Frame>

### 5.2 java

El ejemplo de Java solo proporciona un servidor HTTP, por lo que la descripción se limita a la interfaz y al formato de los mensajes. Usa Postman para abrir el archivo de ejemplo como se muestra a continuación:

<Frame>
  ![Iconos relacionados con java](/images/developers/camera-sdk-linux-examples-java.avif)
</Frame>

Todos los mensajes utilizan el método POST. Antes de enviar datos, recuerda cambiar la IP por la IP del servidor, pero no modifiques la URL. La URL está codificada internamente en el servidor. El formato y el contenido del mensaje de respuesta se encuentran en el cuerpo. La interfaz proporcionada en el ejemplo es la siguiente:

<Frame>
  ![Iconos relacionados con java 2](/images/developers/camera-sdk-linux-examples-java-2.avif)
</Frame>

1.DcGetApiVersion: obtiene el número de versión del SDK; no requiere parámetros de entrada

<Frame>
  ![Iconos relacionados con java 3](/images/developers/camera-sdk-linux-examples-java-3.avif)
</Frame>

2.DcSetInfoOutput: establece la ruta de salida de los registros del SDK. Los parámetros son los siguientes:

- log\_path: ruta de salida de los registros
- print\_level: nivel de impresión de los registros
- enable\_screen\_print: indica si los registros se imprimen en la consola

3.DcLog: escribe el registro en el registro del SDK. Todo el contenido introducido se imprimirá en el registro del SDK.

4.DcGetDeviceList: obtiene la lista de dispositivos; no requiere entrada y la entrada es JSON

5.DcOpenDevice: abre el dispositivo e introduce lo siguiente:

<Frame>
  ![Iconos relacionados con java 4](/images/developers/camera-sdk-linux-examples-java-4.avif)
</Frame>

- open\_mode: modo de apertura de la cámara
- param: parámetros para abrir la cámara

6.DcStartStream: hace que una cámara determinada comience a enviar datos de flujo. Los parámetros de entrada son los siguientes:

<Frame>
  ![Iconos relacionados con java 5](/images/developers/camera-sdk-linux-examples-java-5.avif)
</Frame>

- handle: identificador de la cámara, que se devuelve en DcOpenDevice

7.DcSetCmd: envía comandos a la cámara; introduce lo siguiente:

<Frame>
  ![Iconos relacionados con java 6](/images/developers/camera-sdk-linux-examples-java-6.avif)
</Frame>

- handle: identificador de la cámara que se va a configurar
- cmd: número del comando

8.DcGetPtrValue: obtiene datos de puntero (imágenes, parámetros, etc.); introduce lo siguiente:

- handle: identificador de la cámara que se va a configurar
- cmd: número del comando
