## Produktüberblick

### Zweck und Geltungsbereich

Dieses Dokument beschreibt die Spezifikationen der S10-Kamera und ausgewählte Designdetails für Entwickler, die das Produkt integrieren und verwenden.

### Terminologie

| RGB-D-Kamera | Eine Kamera, die synchronisierte und räumlich ausgerichtete RGB- und Tiefenbilder ausgibt |
| --- | --- |
| Tiefe | Ein Videostream ähnlich einem Farb- oder monochromen Stream, bei dem jedes Pixel seine Entfernung von der Kamera darstellt |
| FOV | Sichtfeld: der Winkelbereich einer von einer Kamera erfassten Szene, einschließlich horizontalem (HFOV), vertikalem (VFOV) und diagonalem (DFOV) Sichtfeld |
| IR-Kamera | Eine Infrarotkamera; bei diesem Produkt erfasst sie hauptsächlich das nahe Infrarotband |
| RGB-Kamera | Eine Farbkamera |
| Tiefenkamera | Eine Kamera, deren Tiefenmodul typischerweise einen Punktprojektor, eine IR-Kamera und einen Tiefenprozessor umfasst; das Farbmodul ist typischerweise eine RGB-Kamera |
| SoC | System-on-Chip für Bildverarbeitung, Tiefenberechnung und Anwendungsalgorithmen |
| dToF | Technologie zur Tiefenerfassung mittels direkter Laufzeitmessung |

### Funktionsprinzip

Dieses Produkt ist eine dToF-3D-Tiefenkamera mit großer Reichweite, guter Genauigkeit, hoher Störfestigkeit und stabilen Daten. Ein integriertes RGB-Modul erfasst Farbbilder. Die Kamera richtet RGB- und Tiefenbilder intern aus.

### Produktdetails

Diese kompakte industrielle RGB-D-Kamera liefert Tiefendaten von 0,3 m bis 8 m. Sie richtet RGB- und Tiefenbilder räumlich und zeitlich aus. Der integrierte SoC gibt Tiefen-, Intensitäts-, RGB-, Punktwolken- und Ergebnisse der Hinderniserkennung aus. Zusätzlich zu Ethernet schalten zwei I/O-Eingänge und zwei I/O-Ausgänge zwischen vier Hindernisvermeidungszonen um und geben Not-Aus-, Verlangsamungs- und Sicherheitszustandssignale aus.

## Erste Verwendung

### Verbindungstest

1. Verbinden Sie die Kamera mit einer 24V/2A-Gleichstromversorgung. Eine langsam blinkende blaue Betriebsanzeige bestätigt das normale Einschalten.
2. Verbinden Sie die Kamera über ein Ethernetkabel der Kategorie 6 mit dem Computer.
3. Die werkseitige Standard-IP-Adresse der Kamera ist 192.168.100.82.
4. Stellen Sie die Computer-IP auf das Subnetz der Kamera ein und deaktivieren Sie die Computer-Firewall.
5. Starten Sie die Host-Software, um die Kamerabilder anzuzeigen.
6. Wenden Sie sich an den Vertrieb oder technischen Support von MRDVS, um die Host-Software zu erhalten.

### Fehlerbehebung

| Nr. | Problem | Lösung |
| --- | --- | --- |
| 1 | Kamera reagiert beim Öffnen nicht | Prüfen Sie, ob die Firewall deaktiviert ist |
| 2 | Host-Software erkennt mehrere IP-Adressen | Ein anderes Gerät im LAN verwendet dieselbe IP-Adresse; wählen Sie die erforderliche IP-Adresse aus |
| 3 | Kameradaten sind nach dem Öffnen instabil | Verwenden Sie ein Gigabit-Ethernetkabel; über Fast Ethernet können die Daten anfangs instabil sein |
| 4 | Speicherort der Softwareinstallation | Eine Standardinstallation auf Laufwerk C kann durch Berechtigungseinstellungen beeinträchtigt werden |
