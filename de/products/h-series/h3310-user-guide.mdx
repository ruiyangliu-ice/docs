## Begriffe und Funktionsprinzip

### Allgemeine Begriffe

| Begriff | Beschreibung |
| --- | --- |
| Baseline | Horizontaler Abstand zwischen den optischen Zentren der beiden stereoskopischen Bildeinheiten. |
| Tiefe | Daten, die den Abstand von jedem Pixel zur Kamera darstellen. |
| FOV | Sichtfeld, einschließlich horizontaler, vertikaler und diagonaler Winkel. |
| IR-Kamera | Kamera für die Bildgebung im nahen Infrarotbereich. |
| RGB-Kamera | Farbbildkamera. |
| Tiefenkamera | Bildgebungssystem, das Tiefendaten ausgibt und typischerweise Projektions-, Bildaufnahme- und Tiefenverarbeitungseinheiten umfasst. |
| SoC | System-on-Chip für Bildverarbeitung, Tiefenberechnung und Anwendungsalgorithmen. |

## Produktübersicht

Die H3310 ist eine industrielle RGB-D-Kamera mit strukturiertem Licht und einem Gewicht von 400 g. Sie kann an einem Verbundroboter oder einem kleinen Roboterarm montiert werden. In einem Arbeitsbereich von 300–600 mm gibt die Kamera hochpräzise Tiefen- und RGB-Daten aus und stellt eine integrierte Rechenplattform für Anwendungsalgorithmen bereit.

<Frame>
  ![H3310-Kamera](/images/products/h-series-h3310-user-guide-h3310-camera.avif)
</Frame>

### Funktionen

- Integrierte 6.0-TOPS-Rechenplattform für Anwendungsalgorithmen.
- Ausgabe von Tiefen-, RGB- und Amplitudenbildern.
- Offene Schnittstellen für die Integration in Roboterarme und mobile Roboter.

## Häufig gestellte Fragen

<AccordionGroup>
  <Accordion title="Die Hostanwendung kann die Kamera nicht öffnen">
    Stellen Sie sicher, dass die Host-Firewall die Verbindung nicht blockiert. Überprüfen Sie anschließend die Stromversorgung der Kamera und die Netzwerkkonnektivität.
  </Accordion>

  <Accordion title="In der Geräteliste werden mehrere IP-Adressen angezeigt">
    Im LAN können mehrere erkennbare Geräte vorhanden sein. Wählen Sie die IP-Adresse der Zielkamera aus.
  </Accordion>

  <Accordion title="Der Datenstream ist instabil">
    Verwenden Sie ein Gigabit-Ethernetkabel. Ein 100-Mbit/s-Netzwerk kann anfänglich zu einem instabilen Datenstream führen.
  </Accordion>

  <Accordion title="Die Software kann nach der Installation nicht ausgeführt werden">
    Wenn die Software in einem Verzeichnis mit eingeschränkten Rechten installiert ist, überprüfen Sie die Berechtigungen für Datei- und Programmausführung.
  </Accordion>
</AccordionGroup>
