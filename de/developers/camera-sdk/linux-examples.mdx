## Übersicht

Das MRDVS Camera SDK für Linux enthält Beispiele für C/C\+\+, Java (HTTP-Service), ROS und ROS 2. Die Beispiele zeigen den grundlegenden SDK-Ablauf. Ergänzen Sie projektspezifische Logik und Fehlerbehandlung.

Schließen Sie zuerst die Einrichtung der Umgebung, die Ausführung des Installationsskripts und die Prüfung der Beispielverzeichnisse ab. Folgen Sie anschließend dem Abschnitt zum Kompilieren und Ausführen für die gewünschte Sprache. Der Anhang enthält Installationsmethoden für häufig verwendete Abhängigkeiten und Testpakete.

### 5.2 java

Die Java Beispiel provides nur an HTTP Server, so die Beschreibung ist nur a Beschreibung von die interface und Nachricht format. Use Postman zu öffnen die Beispiel Datei wie shown below:

<Frame>
  ![java zugehörig Abbildungen](/images/developers/camera-sdk-linux-examples-java.avif)
</Frame>

Die Nachrichten sind alle in post mode. Before sending, remember zu change die IP zu die Server's IP, but do not modify die URL. Die URL ist hard-coded internally in die Server. Die response Nachricht format und content sind both in die body. Die interface provided in die Beispiel ist wie folgt:

<Frame>
  ![java zugehörig Abbildungen 2](/images/developers/camera-sdk-linux-examples-java-2.avif)
</Frame>

1.DcGetApiVersion: Get die Version Nummer von die SDK, no Parameter Eingabe

<Frame>
  ![java zugehörig Abbildungen 3](/images/developers/camera-sdk-linux-examples-java-3.avif)
</Frame>

2.DcSetInfoOutput: Set die Pfad für SDK log Ausgabe. Die Parameter sind wie folgt:

- log\_path: Pfad von log Ausgabe
- print\_level: log printing level
- enable\_screen\_print: whether die log ist printed on die console

3.DcLog: Output die log zu die SDK log. Any Eingabe content wird be printed zu die SDK log.

4.DcGetDeviceList: Get die Gerät Liste, no Eingabe, Eingabe ist JSON

5.DcOpenDevice: Open die Gerät und öffnen die folgende:

<Frame>
  ![java zugehörig Abbildungen 4](/images/developers/camera-sdk-linux-examples-java-4.avif)
</Frame>

- öffnen\_mode: öffnen die Kamera mode
- param: Parameter für opening die Kamera

6.DcStartStream: Let a certain Kamera starten pushing streaming Daten. Die Eingabe Parameter sind wie folgt:

<Frame>
  ![java zugehörig Abbildungen 5](/images/developers/camera-sdk-linux-examples-java-5.avif)
</Frame>

- handle: Die handle von die Kamera, which wird be returned in DcOpenDevice

7.DcSetCmd: Issue Befehle zu die Kamera, öffnen wie folgt:

<Frame>
  ![java zugehörig Abbildungen 6](/images/developers/camera-sdk-linux-examples-java-6.avif)
</Frame>

- handle: die handle von die Kamera zu be festlegen
- cmd: Befehl Nummer

8.DcGetPtrValue: Get pointer Daten (Bild, Parameter, etc.), öffnen wie folgt:

- handle: die handle von die Kamera zu be festlegen
- cmd: Befehl Nummer

9.DcSetIntValue: Set die Kamera int Typ Parameter, Eingabe wie folgt:

<Frame>
  ![java zugehörig Abbildungen 7](/images/developers/camera-sdk-linux-examples-java-7.avif)
</Frame>

- handle: die handle von die Kamera zu be festlegen
- cmd: Befehl Nummer
- Wert: die Wert zu be festlegen

10.DcGetIntValue: Get die int Typ Parameter von die Gerät, Eingabe wie folgt:

- handle: die handle von die Kamera zu be festlegen
- cmd: Befehl Nummer
