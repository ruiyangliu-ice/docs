Diese Seite beschreibt die Weboberfläche der reinen V2-Lokalisierung. Vergewissern Sie sich vor dem Erstellen oder Wechseln von Karten sowie vor einer Relokalisierung, dass Fahrzeug, Kamera und LiDAR ordnungsgemäß funktionieren.

<Warning>
  Das Wechseln von Karten, das Aktualisieren der Firmware und der Neustart der integrierten Anwendung beeinflussen die Lokalisierungsdienste. Führen Sie diese Vorgänge nur bei angehaltenem Fahrzeug, in einem sicheren Arbeitsbereich und mit verfügbarer Wiederherstellungsprozedur aus.
</Warning>

## Übersicht über die Oberfläche

| Bereich | Inhalt |
| --- | --- |
| Menüleiste | Funktionen für Kartierung, Relokalisierung, Kartenverwaltung und Wartung. |
| Kartenansicht | Die geladene 2D-Konturkarte und das Lokalisierungssymbol des Fahrzeugs. |
| RGB-Ansicht | Das Live-RGB-Bild der Top-View-Kamera. |
| Statusbereich | Relokalisierungssignalstärke, Fahrzeugkoordinaten, Geschwindigkeit und Cursor-Koordinaten. Die Signalqualität wird von der besten bis zur schlechtesten Qualität als Grün, Blau und Rot angezeigt. |

## Karte erstellen

### Karte erstellen

<Steps>
  <Step title="Kartierung starten">
    Klicken Sie in der Weboberfläche auf **Kartierung starten**.

    <Frame>
      ![Schaltfläche zum Starten der Kartierung in der Oberfläche der reinen V2-Lokalisierung](/images/developers/v2-localization-pure-localization-guide-1-starting-to-build-a-map.avif)
    </Frame>
  </Step>
  <Step title="Kartennamen eingeben">
    Ein Kartenname darf nur Buchstaben, Zahlen und Unterstriche enthalten und muss mit einem Buchstaben beginnen.

    <Columns cols={2}>
      <Frame>
        ![Dialog zur Eingabe des Kartennamens](/images/developers/v2-localization-pure-localization-guide-1-starting-mapping-2.avif)
      </Frame>

      <Frame>
        ![Seite zum Starten der Kartierung](/images/developers/v2-localization-pure-localization-guide-1-starting-mapping-3.avif)
      </Frame>
    </Columns>
  </Step>
  <Step title="Bereich erfassen und Kartierung beenden">
    Fahren Sie den AGV durch den Zielbereich. Wenn die Erfassung abgeschlossen ist, klicken Sie auf **Kartierung beenden** und warten Sie, bis die Verarbeitung abgeschlossen ist. Die Verarbeitungszeit hängt von der Größe des erfassten Bereichs ab.
  </Step>
  <Step title="Karte bestätigen">
    Öffnen Sie nach erfolgreicher Kartierung die **Kartenverwaltung** und bestätigen Sie, dass die neue Karte aufgelistet ist.
  </Step>
</Steps>

### Inkrementelle Kartierung

Verwenden Sie die inkrementelle Kartierung, um einen Bereich zu einer vorhandenen Karte hinzuzufügen. Führen Sie vor dem Start eine Relokalisierung durch und wechseln Sie zu der Karte, die Sie erweitern möchten.

<Info>
  Die inkrementelle Kartierung wird mit einer manuellen HTTP-Anfrage unter [http://192.168.100.201:9998/tool/rob/sendCMD](http://192.168.100.201:9998/tool/rob/sendCMD) gestartet und beendet.
</Info>

<Tabs>
  <Tab title="Inkrementelle Kartierung starten">
    ```json
    {
      "cmd": 904,
      "attach": {
        "sub_command": 0,
        "param": ""
      }
    }
    ```
  </Tab>
  <Tab title="Inkrementelle Kartierung beenden">
    ```json
    {
      "cmd": 905,
      "attach": {
        "sub_command": 0,
        "param": ""
      }
    }
    ```
  </Tab>
</Tabs>

Nach Abschluss des Vorgangs wird der neu erfasste Bereich in die aktuelle Karte geschrieben. Starten Sie den Lokalisierungsdienst neu, damit die Änderung wirksam wird.

<Frame>
  ![Inkrementelle Kartierung in der Oberfläche der reinen V2-Lokalisierung](/images/developers/v2-localization-pure-localization-guide-1-starting-mapping-4.avif)
</Frame>

## Relokalisierung

### Manuelle Relokalisierung

Klicken Sie auf **Relokalisierung** und ziehen Sie anschließend in der Kartenansicht, um eine ungefähre Fahrzeugpose anzugeben, damit die LiDAR-Punktwolke mit der Konturkarte übereinstimmt. Der Fehler **Lokalisierungs-Timeout** verschwindet nach erfolgreicher Relokalisierung.

<Frame>
  ![Manuelle Relokalisierung in der Oberfläche der reinen V2-Lokalisierung](/images/developers/v2-localization-pure-localization-guide-3-relocation.avif)
</Frame>

### AprilTag-Relokalisierung

Sie können beim Erstellen einer Karte AprilTags an ausgewählten Positionen platzieren. Wenn ein vollständiger Tag in das Sichtfeld des Geräts gelangt, identifiziert das System seine Karte und Pose, wechselt bei Bedarf die Karte und führt automatisch eine Relokalisierung durch.

- Erstellen Sie Tags mit [dem AprilTag-Generator](https://chaitanyantr.github.io/apriltag).
- Tag-IDs müssen innerhalb des sichtbaren Bereichs eines Geräts eindeutig sein.
- Verwenden Sie die feste Tag-Familie aus dem Oberflächenbeispiel.

<Frame>
  ![Konfiguration der AprilTag-Relokalisierung](/images/developers/v2-localization-pure-localization-guide-3-relocation-2.avif)
</Frame>

## Wartung

### Firmware aktualisieren

Importieren Sie auf der Aktualisierungsseite ein lokales Firmwarepaket, um die Firmware des Chassis, des Aktuators oder der Kamera zu aktualisieren. Ein Wiederherstellungspaket speichert die Version vor der letzten Aktualisierung und kann zum Zurücksetzen verwendet werden.

<Warning>
  Kamera-Firmware, die über den standardmäßigen Hostcomputer-Workflow aktualisiert wurde, kann nicht zurückgesetzt werden. Prüfen Sie das Paket und die aktuelle Version vor der Aktualisierung.
</Warning>

### Integrierte Anwendung anhalten oder neu starten

Verwenden Sie die Steuerelemente der integrierten Anwendung, um die Anwendung anzuhalten oder neu zu starten. Halten Sie die integrierte Anwendung an, bevor Sie LxCameraViewer mit der Kamera verbinden; andernfalls kann das Fahrzeug die Kontrolle über die Kamera behalten und die Kommunikation verhindern.
